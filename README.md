Power your favorite coding agents (Claude Code, Codex, OpenCode, and more) with your Poe subscription—**no need to handle multiple providers/accounts.** Poe Code routes everything through the [Poe API](https://poe.com/api) .

Configure an agent once and use its normal CLI or desktop app, or spawn one-off prompts through Poe. Installing or updating Poe Code leaves your skills untouched.

## Quickstart

### Set it as your default (works with CLIs and desktop apps)

This updates the provider’s config files and continue using your tools normally.

```bash
# Start the interactive setup
npx poe-code@latest configure

# Setup a specific agent
npx poe-code@latest configure codex # (or claude, opencode, goose)
```

### Unconfigure (remove overrides)

```bash
npx poe-code@latest unconfigure claude
```

## Authentication

Poe Code uses your [Poe API key](https://poe.com/api) for authentication. On first run, you'll be prompted to log in via your browser (OAuth). You can also provide your key directly:

```bash
# Interactive login (opens browser)
npx poe-code@latest login

# Or pass your API key directly
npx poe-code@latest login --api-key <your-key>

# Or set it as an environment variable
export POE_API_KEY=<your-key>
```

Credentials are stored locally in `~/.poe-code/`. Use `poe-code auth status` to check your login state.

```bash
# Remove all configuration and credentials
npx poe-code@latest logout
```

## Utilities

Utilities are especially useful for scripting and CI/CD.

#### Spawn a one-off prompt

```bash
npx poe-code@latest spawn codex "Say hello" --mode read
```

`--mode` is the permission mode: `yolo | auto | edit | read`.

#### Spawn against a GitHub repository

```bash
npx poe-code@latest spawn codex "Fix the failing tests" --cwd github://owner/repo --mode edit
npx poe-code@latest spawn codex "Review the auth module" --cwd github://owner/repo#main:packages/auth --mode read
```

#### Spawn a prompt via stdin

```bash
echo "Say hello" | npx poe-code@latest spawn codex --mode read
```

Stdin is piped here, so there is no TTY to prompt on — `--mode` is required.

#### Review a GitHub pull request

```bash
npx poe-code@latest code-review install
npx poe-code@latest code-review run "https://github.com/owner/repo/pull/123"
npx poe-code@latest code-review commit "https://github.com/owner/repo/pull/123" --dry-run
```

#### Test a configured service

```bash
npx poe-code@latest test codex
```

### Install agent CLIs

```bash
# Claude Code
npx poe-code@latest install claude-code

# Codex
npx poe-code@latest install codex

# OpenCode
npx poe-code@latest install opencode

# Goose
npx poe-code@latest install goose
```

### Optional flags

- `--dry-run` – show every mutation without touching disk.
- `--yes` – accept defaults for prompts.

## Usage & Billing

Check your compute points balance and review usage history.

```bash
# Show current balance
poe-code usage

# Show usage history (20 entries, then prompts to load more)
poe-code usage list

# Show a specific number of entries without prompting
poe-code usage list --limit 100

# Filter by model name
poe-code usage list --filter claude
```

## Models

List available Poe API models and filter them by provider, capabilities, modalities, and supported API endpoint.

```bash
# List all models
poe-code models

# Show only models that support the Responses API
poe-code models --endpoint /v1/responses

# Show only models that support Chat Completions
poe-code models --endpoint /v1/chat/completions

# Search by provider or model id
poe-code models --search claude
```

ImageMagick `-complex Add`, `-complex Subtract` and `-complex Multiply` (also selected by properties such as `%[op]` set with `-set option:op Add`) combine real/imaginary image pairs in their working channels, including CMYK, preserving the first operand’s alpha when the matching operand has no alpha channel. `-complex Divide` divides real/imaginary pairs and accepts `-define complex:snr=VALUE` to regularize the denominator. `-complex Conjugate` (or `Undefined`) preserves the first real image and negates its imaginary image, retaining negative samples for subsequent arithmetic. ImageMagick `+monochrome` preserves loaded pixels, including earlier `-monochrome` conversion. ImageMagick `-blue-shift factor` adjusts RGB tones while preserving unmasked transparency and discarding disassociated alpha; it requires a current image and preserves the destination when none is loaded. With `-region`, blue shift matches native alpha and protected-pixel blending. `+blue-shift operand` consumes and ignores its operand, applying the default factor of 1.5. ImageMagick `-sepia-tone` preserves 16-bit color and alpha, including channel-selected normalization. CMYK sepia toning keeps black and alpha separate. ImageMagick `-combine` produces sRGB pixels from HSL, Lab and linear RGB source intensities, including the alpha plane. ImageMagick reorientation, crop and trim discard disassociated alpha; zero-degree rotations retain it. On RGB inputs without alpha, `-alpha Disassociate` adds a zero alpha channel before scaling colors, matching native ImageMagick. ImageMagick reads PSD composites and layers, including `input.psd[0]` selection. ImageMagick `-colorspace CMYK -channel K -separate` extracts black ink as grayscale; `Black` is an alias, and alpha remains independent. Appending CMYK images preserves all four ink channels and keeps alpha independent. CMYK `-gamma` and `+gamma` correct selected ink channels, including black, independently of alpha. Gamma also corrects selected extra channels from `-combine`, preserving unselected planes. ImageMagick `-cdl grade.cc` reads XML color grades from the shell filesystem, with slope, offset, power and saturation controls. ImageMagick `-kmeans` reduces image colors by iterative clustering. ImageMagick `-equalize` honors explicit `Sync` in channel selections and preserves 16-bit results from 8-bit inputs. ImageMagick `-interpolative-resize` uses the selected interpolation method and preserves scaled page geometry. ImageMagick `-adaptive-resize` uses native mesh interpolation and preserves scaled page geometry. ImageMagick `json:` destinations write JSON image descriptions, including intermediate `-write` output. It also provides [Graphviz rendering](packages/safe-bash-command-dot/README.md) through `poe-code/safe-bash/graphviz`, [local audio/video inspection (including codec names, AMR mono layouts, MIME codec strings, H.264 chroma and AVC configuration, and Y4M stream descriptors) and WAV editing](packages/safe-bash-command-audio/README.md) through `poe-code/safe-bash/commands/audio`, [recursive file search with `rgrep`](packages/safe-bash-command-rgrep/README.md), and [structural code search and rewrites with `ast-grep` / `sg`](packages/safe-bash-command-ast-grep/README.md). AMR-WB audio in 3GP inputs decodes to mono 16 kHz PCM. ADTS AAC output supports optional trailing APE metadata with `-write_apetag 1` (off by default). MPEG-TS output starts elementary PIDs at 256, including audio-only output; `-mpegts_start_pid` selects a different starting PID. MPEG-TS output repeats PAT/PMT every 0.1 seconds; `-pat_period` sets the interval in seconds. FFmpeg `image2pipe` input reads concatenated PNG, PPM, PGM, BMP, QOI and MJPEG frames from files or stdin using the selected input decoder. FFmpeg QOI output honors `-pix_fmt rgb24` to discard alpha and `-pix_fmt rgba` to retain or add it. FFmpeg output `-t` and `-to` limit the video timeline after filters, including repeated `loop` frames. FFmpeg `loop=-1` stops at a finite output frame/time limit or downstream `trim`, counting only frames retained by `select` toward `-frames:v`. FFmpeg `crop` rejects unknown options with exit code 8, invalid booleans with 234, and unsupported `enable` with 176, preserving existing output. FFmpeg `metadata=delete:key=NAME` removes one video frame tag; omit `key` to clear all tags while preserving frames. FFmpeg `pan` accepts the `LFE2` layout with numbered channels, but rejects `LFE2` speaker names in equations. FFmpeg `aformat` accepts quad and 5.1 targets on stereo input, preserving front left/right samples and silencing the other speakers; layout alternatives retain the input layout when allowed. FFmpeg `asendcmd` truncates command times to microseconds and compares them against rounded frame timestamps. FFmpeg `asendcmd` can update `silenceremove` channel modes (`start_mode` and `stop_mode`) at audio frame boundaries. FFmpeg `asendcmd` can change a named `adelay` filter’s `enable` expression at an audio frame boundary, preserving delay history and the tail. FFmpeg `blackframe=75:32` detects nearly black frames without changing pixels, exposes `lavfi.blackframe.pblack`, and supports downstream `metadata=print` or `metadata=select` by key. FFmpeg `weave` pairs successive fields into frames with double height and half the frame rate; `weave=first_field=bottom` selects bottom-field-first output. FFmpeg `extractplanes=y`, `extractplanes=u`, and `extractplanes=v` extract one 8-bit YUV plane as grayscale, preserving its samples and subsampled dimensions. FFmpeg `tblend=all_mode=difference` subtracts native YUV samples directly, preserving zero-valued differences and source timestamps. `tblend=all_expr=A` uses the current frame, `all_expr=B` uses the preceding frame, and `c0_expr` through `c3_expr` select individual components; expressions run for each pixel. Its `all_opacity` and `c0_opacity` through `c3_opacity` options control blending globally or per component. FFmpeg `tblend=all_mode=addition` adds successive frames with saturation at the channel maximum. FFmpeg `-mpegts_flags +pat_pmt_at_frames` repeats PAT/PMT before every video frame. Explicitly mapped SubRip stream copies to MPEG-TS preserve cue payloads and timestamps as private data; player subtitle recognition is not guaranteed. Invalid `-set page` values preserve the existing canvas; `-page nonsense` before input sets a zero canvas. The output prefixes `r:`, `g:`, `b:`, `a:`, `k:`, `c:`, `m:`, `y:` and `o:` write the same grayscale samples as `gray:`. Raw unsigned `-depth 32` and `-depth 64` output writes full-width samples: 32-bit samples honor `-endian`, while 64-bit samples use most-significant-byte-first order, matching native ImageMagick. `tblend=c0_mode=difference` (also `tblend=difference`) blends only luma; `c1_mode` and `c2_mode` select the chroma planes. Unspecified components retain the current frame, and `all_mode` overrides component modes. RGB components follow planar GBR order.

Use `poe-code` programmatically in your own code:

```typescript
import { spawn, getPoeApiKey, getPoeAuthIdentity } from "poe-code";

// Get stored API key
const apiKey = await getPoeApiKey();

// Fetch the authenticated Poe account identity
const identity = await getPoeAuthIdentity();

// Run a prompt through a provider
const result = await spawn("claude-code", {
  prompt: "Fix the bug in auth.ts",
  cwd: "/path/to/project",
  model: "claude-sonnet-4-6"
});

// Spawn against a GitHub repository
const { events, result: ghResult } = spawn("codex", {
  prompt: "Review the auth module",
  cwd: "github://owner/repo#main:packages/auth"
});

console.log(result.stdout);
```

Agent spawn activity timeouts and parallel concurrency limits are optional; set `activityTimeoutMs` or `maxConcurrent` explicitly when needed. Autonomous spawn retries have no ceiling unless `maxTimeoutRetries` is supplied.

For plugin-first agent composition, import the public agent builder from the
`poe-code/agent` subpath. In Cloudflare Workers, pass `agent({ fs, cwd, homeDir })`
with a SafeFS provider and configure an explicit API key or model. The agent and
`poe-code/memory` exports support Workers without `nodejs_compat`; host subprocesses
require an injected runner where supported:

```typescript
import { agent, openaiResponsesPlugin, systemPromptPlugin } from "poe-code/agent";

const run = await agent()
  .model("gpt-5.5")
  .use(openaiResponsesPlugin())
  .use(systemPromptPlugin())
  .run("Summarize the current repository", {
    cwd: process.cwd()
  });

console.log(run.output);
```

### `spawn(service, options)`

Runs a single prompt through a configured service CLI.

- `service` – Service identifier (`claude-code`, `codex`, `opencode`, `goose`)
- `options.prompt` – The prompt to send
- `options.cwd` – Working directory or workspace locator (optional). Supports local paths and `github://owner/repo[#ref[:subdir]]` locators. See [@poe-code/workspace-resolver](packages/workspace-resolver/) for the full locator syntax.
- `options.model` – Model identifier override (optional)
- `options.mode` – Permission mode: `yolo`, `auto`, `edit`, or `read` (optional; defaults to `auto`. Agents without an auto mode fail clearly)
- `options.args` – Additional arguments forwarded to the CLI (optional)

Returns `{ stdout, stderr, exitCode }`.

### `spawn.pretty(service, options)`

Same as `spawn()`, but renders the ACP event stream to stdout with colored, formatted output — matching the CLI's visual style.

```typescript
import { spawn } from "poe-code";

const result = await spawn.pretty("codex", "Fix the bug in auth.ts");
console.log(result.exitCode);
```

Returns `Promise<{ stdout, stderr, exitCode }>`.

### `getPoeApiKey()`

Reads the Poe API key with the following priority:

1. `POE_API_KEY` environment variable
2. Credentials file (`~/.poe-code/credentials.enc`)

Throws if no credentials found.

### `getPoeAuthIdentity()`

Fetches the Poe account identity for the resolved API key.

```typescript
import { getPoeAuthIdentity } from "poe-code";

const identity = await getPoeAuthIdentity();
console.log(identity.name, identity.handle);
```

Uses `POE_API_KEY` or the stored credential and honors `POE_BASE_URL`. Throws an API error when Poe rejects the credential.
