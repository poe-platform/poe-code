# SDK `runExperiment` Drops Per-Attempt Log Routing

## Summary

The public SDK `runExperiment()` adapter discards the per-attempt `logDir` and `logFileName` supplied by `@poe-code/experiment-loop` before invoking `spawn.autonomous()`. Experiment attempts executed through the SDK therefore bypass the experiment loop's dedicated run-log destination.

## Reproduction

Create a disposable Vitest probe at `src/sdk/__probe__.test.ts`:

```ts
import { beforeEach, describe, expect, it, vi } from "vitest";
import type { ExperimentRunOptions } from "@poe-code/experiment-loop";

const runExperimentLoopMock = vi.hoisted(() => vi.fn());
const spawnAutonomousMock = vi.hoisted(() => vi.fn());

vi.mock("@poe-code/experiment-loop", async (importOriginal) => {
  const actual = await importOriginal<typeof import("@poe-code/experiment-loop")>();
  return { ...actual, runExperimentLoop: runExperimentLoopMock };
});

vi.mock("./spawn.js", () => ({
  spawn: Object.assign(vi.fn(), { autonomous: spawnAutonomousMock })
}));

import { runExperiment } from "./experiment.js";

describe("SDK experiment log routing", () => {
  beforeEach(() => {
    runExperimentLoopMock.mockReset();
    spawnAutonomousMock.mockReset();
  });

  it("drops per-attempt log routing supplied by the experiment loop", async () => {
    runExperimentLoopMock.mockImplementationOnce(async (options: ExperimentRunOptions) => {
      await options.runAgent?.({
        agent: "codex",
        prompt: "Improve metric",
        cwd: "/repo",
        logDir: "/repo/.poe-code/logs/experiment/plan",
        logFileName: "20260525-011500-000-experiment-1-codex.jsonl"
      });
      return {
        stopReason: "max_experiments",
        docPath: "/repo/plan.md",
        experimentsCompleted: 1,
        experimentsKept: 0,
        totalDurationMs: 1
      };
    });
    spawnAutonomousMock.mockResolvedValue({ stdout: "", stderr: "", exitCode: 0 });

    await runExperiment({ cwd: "/repo", homeDir: "/home/test", docPath: "/repo/plan.md" });

    expect(spawnAutonomousMock).toHaveBeenCalledWith("codex", {
      prompt: "Improve metric",
      cwd: "/repo",
      model: undefined,
      mode: "yolo"
    });
  });
});
```

Run:

```sh
npm exec -- vitest run src/sdk/__probe__.test.ts --reporter verbose
```

The probe passes:

```text
✓ src/sdk/__probe__.test.ts > SDK experiment log routing > drops per-attempt log routing supplied by the experiment loop
```

## Observed Behavior

`packages/experiment-loop/src/run/loop.ts:435` through `packages/experiment-loop/src/run/loop.ts:447` calls its configured agent runner with a generated `logDir` and attempt-specific `logFileName`. When the public SDK supplies that runner, `src/sdk/experiment.ts:72` through `src/sdk/experiment.ts:85` creates the `spawn.autonomous()` options object without either property. The reproduction observes an autonomous spawn containing only prompt, working directory, `model: undefined`, and `mode: "yolo"`, despite receiving valid experiment log routing fields in its runner input.

## Expected Behavior

The public SDK adapter should forward `input.logDir` and `input.logFileName` into `spawn.autonomous()` so experiment attempts retain the log routing explicitly generated by the experiment loop, just as the spawn API supports these fields.

## Impact

SDK consumers lose experiment-scoped agent execution logs or have them written to generic/default destinations instead of alongside the experiment run. This breaks per-attempt traceability for debugging, comparisons, audits, and tooling that expects generated experiment log filenames to exist.
