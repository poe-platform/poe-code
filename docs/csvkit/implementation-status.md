## Maintained design and public ownership

`poe-code/csvkit` and `@poe-code/csvkit` export `execute`, `run`, `OwnedArguments`,
`parseArguments`, immutable command metadata, `readCsv`, `writeCsvRow`, the UTF-8
codec, finite limits and explicit execution/provider interfaces.
`poe-code/safe-bash/commands/csvkit` exports `createCsvkitCommands` and
`csvkitCommands`. The plugin is opt-in; it does not enter default agentCommands.
The root package ships the domain's dist and license. Safe-bash imports the
public self-package SDK route, so packed consumers need no private workspace
install. Its guarded build admits that exact public declaration closure.

`execute(name, context)` owns original raw argv parsing. `run({command,
settings}, invocation)` applies defaults and validates setting applicability and
basic cardinality without rebuilding argv. Both dispatch the same descriptor
operation. SDK settings now use a generated command-specific discriminated union
and runtime validation. Exhaustive SDK request admission is still unqualified.
Config/metadata are immutable across invocations; supplied
env, limit and provider arrays are snapshotted. Capabilities are trusted host
JavaScript, not a hostile-code sandbox.

Build-time inventory discovery derives static command and format import graphs
from one descriptor file each. Format guessing/applicability/dispatch use
descriptor metadata; in2csv format choices derive from the same inventory.
Provider additions require a maintained build to regenerate inventories.
No provider-ID switch is used. Format operations live outside the declarative
provider files. One declarative file per frozen SQLAlchemy dialect supplies
identifier and text-DDL metadata; `databaseDialects` and
`DatabaseDialectDescriptor` expose that metadata through the SDK. These are not
DBAPI drivers and do not establish actual database access or compatibility.

Implemented counters cover argv, input, output, conservative cumulative
retained-buffer/selected-operation admissions, codepoints, records, columns,
field characters, work, inflation and DB result rows. This is not a measured
bound on total JS heap or injected-provider allocations. Regex/Decimal/
archive counters remain future gates associated with blocked operations. JSON lexical numeric text now enforces Decimal digit/exponent budgets, without implementing typed Agate Decimal operations. The frozen CPython integer conversion limit is 4,300 digits. JSON nesting beyond depth 256 and escaped unpaired surrogates remain explicit refusals; the latter prevents silent UTF-8 replacement until strict output error behavior is implemented. Interpreter admission and injected cooperative checkpoints enforce maxInterpreterWork; opaque guest execution cannot be preempted or counted automatically.
Cleanup is enrolled before cooperative acquisition, drains admitted resources,
shares completion and observes close failures. Primary thrown reasons, including
falsey reasons and cancellation, survive cleanup failures. Output writes await
backpressure; safe-bash adapts its owned-output cancellation boundary.
