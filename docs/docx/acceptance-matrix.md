# DOCX acceptance matrix

Verified 2026-09-15. Levels below are the actual discovery-declared bounded
subsets, corroborated by maintained DOCX checks and linked feature evidence;
they do not certify every schema node or every document. Read returns snapshots,
edit changes admitted structures, preserve retains unrelated opaque payloads,
and reject means the declared operation has no execution support. An overall
family level never grants its unsupported subfeatures.

[Usage](usage.md) and the [complete contract capture](usage-contracts.json) record
all options and operation support. [Whole API acceptance](whole-api-acceptance.md)
remains blocked; inherited members, enums, collections, helpers and public
underscore owners remain in its denominator. Downloaded documents are disposable
QA inputs, never canonical unit fixtures. Original behavioral adaptations and
small authored/memfs cases are tracked by the existing test maps and feature
records; this documentation task adds no product test or copied binary asset.

The current capture includes unowned packing edits. Packing metadata is recorded
for accuracy but this task does not qualify or commit their implementation.
Other unowned working-tree changes likewise remain outside this task's ownership.
No new per-family independent renderer/corpus acceptance was performed.

## Verification gates

Imports and seven commands: checked by public workspace exports/parser, retained
in [verification](usage-verification.json). Schema/help closure: 1,517 operations,
50 feature families; exhaustive declared option capture, not 1,517 passing edits.
Maintained selected workspace build, DOCX unit tests, schema tests, lint and owned
Markdown/JSON format checks are recorded in the
[owned plan](../plans/docx-usage-documentation.md). Current-tree checks cannot be
attributed exclusively to already committed code. No code fix, new TDD cycle,
README modification, push or release is authorized in this task. Later product
implementation and whole API acceptance tasks remain pending.
