# Async live-model capability boundary

Scope: `sdk-async-capabilities`, existing live Styles/formatting and admitted
Image types only. The task remains open because Document and its other live
owners are absent. Later tasks remain pending. No complete-object/API claim is
made, and no style-only object is relabeled Document.

## Exact JavaScript and security mappings

| Boundary                  | Executed mapping                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Existing style opener     | `openDocumentStyleModel(input?: DocumentModelInput \| null, context?: DocumentModelContext)` always returns a Promise. Omission, undefined and null create the original template. Bytes, cooperative byte sources and explicit capability-bearing VFS paths load through the existing admission engine.                                                                                                                                                                                                                                                                                                                                                    |
| Model context             | Optional explicit limits and signal use maintained finite package defaults and a fresh nonaborted signal. Supplied ceilings are validated. Timestamp is a copied UTC Date at whole-second precision; omission uses `1980-01-01T00:00:00Z`. Author and initials default to empty strings; null initials remains absence. Invalid identity/time/signal values reject asynchronously. No clock, identity or fonts are discovered.                                                                                                                                                                                                                             |
| Metrics                   | `DocumentFontMetrics.measure(text, font, points): number` is an explicit capability. Its shape is validated and ordinary style creation/formatting never calls it. No metric-dependent live owner or layout behavior is claimed. Omission provides no metric capability.                                                                                                                                                                                                                                                                                                                                                                                   |
| Context data              | Plain or null-prototype data records admit explicit callbacks. Own accessors, inherited contexts and nested limit/resolver/metrics accessors reject without invocation. Resolver capability and method are validated, copied and bound before admission. This is a deliberate finite-data mapping, not unrestricted host object traversal.                                                                                                                                                                                                                                                                                                                 |
| Input bytes and streams   | Uint8Array admission copies before the first caller-controlled await. Stream chunks are owned before advancing; source errors propagate and cancellation closes the cooperative iterator. Existing DocumentIo lifetime handling is reused.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| VFS paths                 | Canonical absolute path plus nonempty capability identifier requires the matching injected resolver. Path fields are captured before awaiting. Resolver receives signal and byte ceiling. No ambient path access or network fallback. This read capability does not infer publication authority or file identity.                                                                                                                                                                                                                                                                                                                                          |
| Image                     | Existing `Image.from_blob` and `Image.from_file` stay always async, including invalid inputs and already supplied bytes. ImageModelContext uses the shared typed defaults. The prior 64 MiB default image/media ceiling is preserved; document default member capacity is 32 MiB. Image properties and scaled_dimensions remain synchronous and owner-free. Explicit source method receivers are preserved.                                                                                                                                                                                                                                                |
| Styles and formatting     | Existing live Styles, BaseStyle/returned inherited types, Font, ColorFormat, ParagraphFormat and tab operations stay synchronous. Their neutral method spellings, null/false distinctions, creating getters and stale handles are retained.                                                                                                                                                                                                                                                                                                                                                                                                                |
| Sink save                 | `save(sink: ArchiveSink): Promise<void>` always awaits validated publication; malformed sinks reject as neutral input errors. Byte ownership remains enforced by the existing publication engine.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| VFS publication           | Existing async `publish(options: PublicationOptions, context: PublicationContext)` uses the same conditional staging engine as CLI. Admission and caller cancellation combine; effective limits use the tighter ceilings. Supplied budgets must share the admitted reservation ledger (including lowered views); unrelated ledgers reject with unsupported-publication instead of bypassing cumulative reservations. Omitted caller budgets contribute validated ceilings while the admitted ledger remains charged. Caller provides explicit filesystem, identity and output/in-place/force intent. No path authority is inferred from the read resolver. |
| Stale live publication    | A changed model revision before commit rejects with conflict and no publication. If staging was acquired, its cleanup runs and unrelated destination bytes remain. At final sink/VFS/staged-session handoff, synchronous live mutations reject with conflict until the awaited commit settles. Locks release on success and failure.                                                                                                                                                                                                                                                                                                                       |
| Internal staged operation | Existing staged sessions honor cancellation before staging and carry the same final-handoff lock. This internal symbol hook is absent from the public barrel and cannot be supplied through CLI operation JSON. It does not hide any inventoried public type.                                                                                                                                                                                                                                                                                                                                                                                              |
| CLI/SDK                   | Existing style/Image batch and command routes still call these same types. Context normalization was extended on both batch adapters. No command path, common flag, selector, envelope or exit convention changes; no competing editor or new CLI alias.                                                                                                                                                                                                                                                                                                                                                                                                   |

## Inventory and documentation drift

The complete inventories were parsed: 920 source API records (65 types, 320
functions, 458 properties, 19 enum types, 11 aliases, two attributes, 37 protocols
and eight documentation errors), 1,609 unit variants and 650 expanded BDD cases.
The API map retains all 1,337 rows and twelve guides. Existing historical source
passes and unimplemented adaptation dispositions were not rewritten.

The audit's byte-only, required-context description of the bounded style opener
is superseded only by the exact signature above. Its bounded live-model status
remains accurate. The shared SDK's required Document factory is still absent;
this milestone does not satisfy that promise or introduce an alias for it.

The async obligations of Document/Run.add_picture, Document/DocumentPart.save,
Package/OpcPackage.open/save, the inherited Part/XmlPart.load paths, other
part-owner loaders, comment dates/authors and all returned live document owners
remain visible and pending. Public underscore-prefixed owners, inherited members,
collections, helpers, enums and APIs without source tests are not excluded.
This evidence supplements [API reconciliation](upstream-api-reconciliation.md)
and [the API audit](upstream-api-audit.md); it is not a denominator reduction.

## Original executed evidence

[The original tests](../../packages/docx/src/async-model-capabilities.test.ts)
use memfs and small authored inputs, with no publisher documents, cloned binary
fixtures, native decoder, host font discovery or networking. New cases cover
context defaults and UTC Date races, bytes/chunks/path capture, asynchronous
failures, synchronous live formatting, tighter publication limits, both borrowed
signals, internal-stage cancellation, stale identity/staging cleanup, final commit
locking, failure unlock, explicit receivers and unused metric capability.

The agent procedure, exact red/green receipts, final maintained checks and local
commit delivery are recorded in [the owned plan](../plans/docx-async-model-capabilities.md).
No CLI presentation changes require new screenshots; the existing maintained
command/guide checks execute the real SDK-backed command engine.
