# DOCX owned capability data

Eleven original failing tests reproduced ambient metadata, input/output methods,
path fields and missing admitted authority being inherited from Object.prototype.
The [receipt](async-owned-capabilities.json) records the exact JavaScript/security
mappings and final verification separately from the save-protocol improvement.

Finite context and input/output records now capture own data into null-prototype
snapshots. Missing optional capabilities stay absent after admission. Accessors
are rejected without invocation; intrinsic metadata defaults remain deterministic.
Core-property alias lookup also uses own keys. This closes the demonstrated author
getter path without changing the neutral public spelling.

Sink method lookup retains explicit instance/class inheritance and receiver
binding, but stops before Object.prototype. Resolver and metrics functions retain
their supplied receivers while their methods are captured. No class is hidden,
no unsupported API is reclassified as private and no second model is introduced.

These cases use original small in-memory inputs and memfs output. Prototype
modifications are restored in finally blocks. No downloaded fixture, ambient host
I/O, native document runtime or implicit network is involved. Existing shared
SDK-backed CLI behavior and the inspected help screenshot remain unchanged.

Final maintained package verification passed 245 files/5,083 cases with two
workers, unchanged timeouts, no retries and no skips. Package lint (one existing
type-only warning), the fresh selected workspace build closure and all eight
built SDK/plugin Shell cases passed. An earlier full one-worker run had two
timeouts; both affected files then passed directly (99 cases), and the final
complete run passed. This history is retained in the receipt.
