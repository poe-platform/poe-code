# OPC/XML/image adaptation evidence

This record qualifies only `adapt-upstream-opc-xml-images`. The exact 369-row
ledger is [the case map](opc-xml-image-case-map.json); execution receipts are
retained separately. Historical inventories, the 1,609 native unit passes and
counterpart format results remain research denominators, not TypeScript passes.
Full public API, format, decoder and rendering parity are not claimed. Later
text/style/document adaptation and other pipeline tasks remain pending.

The selected file families contain 371 crosswalk identities. Two core-property
accessor rows in `tests/opc/test_package.py` are explicitly owned by the separate
`typed-document-properties` task, so this overlay retains its established 369-row
denominator. The completion receipt records both exclusions; neither is counted
as a pass here or silently reclassified as private.

The original memfs inputs contain authored XML, inert payloads and bounded raster
header records. No downloaded document or cloned binary is a dependency. No QA
fixture was downloaded or deleted during this increment. Existing standalone
legal notices remain intact. Source expressions and parameter provenance remain
in `test-case-source-evidence.json` and `test-case-map.json`; product tests never
import those catalogs. No source snippets, incidental asset names or reference
project identities are emitted by the product or retained in tests.

## Exact language and security mappings

- Admitted Package/Part/XmlPart views replace detached Python proxy/mocked factory
  objects. Factories and publication always return Promises; properties and
  in-memory model edits are synchronous. Identity assertions concern a cached
  owner or keyed handle, not an upstream mock call order. Lifecycle hooks observe
  stable ownership and graph validation. XML `.part` belongs to XmlPartView;
  XmlElementView exposes owned element observations without inventing a `.part`
  alias. Internal DocumentPackage is a type-only public barrel export; internal
  graph tests import its implementation directly without expanding public API.
- Neutral spellings (`partname`, `content_type`, `target_ref`, `relate_to`,
  `load_rel`, `drop_rel`, `rels`, `related_parts`, `next_partname`) are retained.
  PackURI is a validated immutable JS value, not a String subclass; explicit
  `toString()`/JSON supply its string behavior. Collections use explicit iterable,
  length, indexed or keyed access. Null means absence; a missing required key
  throws a typed failure. External targets are inert strings and never acquired.
- Native physical-directory and ZIP-reader/writer classes map to explicit
  DocumentIo capabilities and bounded archive admission/serialization, not ambient
  directory inference. Cleanup is awaited and idempotent, producer fragments are
  copied and unrelated memfs entries remain intact. Optional relationship XML
  maps to an empty noncreating collection, not a fabricated relationship member.
- Content-type cases retain default/override distinction, priority, missing
  mappings and ASCII case variants. Serialized output is checked by owned bytes
  and expanded XML names/content. Native declaration/prefix/empty-element spelling
  is not imposed on newly authored XML; untouched member bytes remain exact.
  Invalid TargetMode rejects under the maintained package contract rather than
  inheriting a native fallback to internal. Required Target omission is consumed
  by actual package admission, not merely by a test-local constructed string.
- XML descriptor class injection maps to observable owned reads, absence,
  insertion order, selected removal and idempotent ensure behavior using the
  admitted editor. No Python metaclass or generated property injection is claimed.
  Prefix aliases compare by expanded names, attributes as unordered observations,
  and content in order. Native test-only line comparison maps to complete original
  XML observations. Significant whitespace, comments and processing instructions
  remain observable; native blank stripping is superseded by retention.
- Nullable style/latent priorities are nonnegative safe integers. Core revision
  writes are positive safe integers. Eight static declarations had advertised
  generic numbers despite stricter model behavior; direct, SDK, batch and JSON
  schema declarations now agree. Inherited BaseStyle/CharacterStyle/ParagraphStyle,
  public `_TableStyle`/`_NumberingStyle` and `_LatentStyle` setters remain explicit;
  underscore names do not make them private or exempt them from API accounting.
- Relationship deletion scans the owning XML part, all descendants and admitted
  relationship-namespace attributes, including Strict, Transitional and legacy
  office `relid`. Zero references permit removal; one or two reject before graph
  publication. This deliberately supersedes the native private threshold that
  removed an edge with one reference. Foreign attributes, text/comments and the
  same ID in a different owner do not create false references. Drop, delete,
  clear, pop and popitem share the transactional guard and cumulative budgets.
- Standalone Image remains an immutable admitted value. Bytes, VFS basenames and
  explicit byte streams replace file/seek objects; admission copies fragments and
  awaits cleanup. Format dispatch follows bytes, not filename authority. SHA-1
  is compatibility metadata; provenance/identity uses SHA-256. Header admission
  does not decode pixels or imply a valid renderable compressed pixel stream.
- Binary helper reads preserve endian ordering, value 42 and nonzero backing
  offsets. TIFF constructor dimensions 111/222 and densities 333/444, LONG value
  42, SHORT/LONG/rational/ASCII variants and all density-unit variants have
  independent original records. Private entry factories map to bounded traversal
  of valid field types; inert unknown values grant no public mutation authority.
- Native sizing uses independent physical axes: 150x75 at 72/200 DPI yields
  1,905,000/342,900 EMUs. All four explicit width/height scaling variants retain
  their logical values. Each missing density axis independently falls back to
  72. Fractional pixels-per-metre conversion uses exactly 0.0254, followed by
  checked shared EMU rounding. Original PNG/BMP integer encodings nearest to
  nominal DPI retain precise converted values: 3780 -> 96.012, 5906 -> 150.0124,
  11811 -> 299.9994. These are precision mappings, not native rounded equality.
- Private JPEG seek offsets 0/1/2/3/4/6/8 map to complete original bounded fill,
  segment and terminal-truncation traversal. No arbitrary seek API is invented.
  JFIF/Exif, missing optional segments, frame requirements, PNG chunk roles and
  both TIFF endian forms are observed via admitted metadata or typed rejection.

The shared CLI remains SDK-backed: plural resources, `text replace`, selectors,
common flags, version 1 JSON, schema/capabilities and documented exit statuses
remain authoritative. The new paired tests exercise fixed typed batch IDs,
checked named receivers, zero publication on dry-run/failure and unchanged input.
Whole public API accounting still includes inherited members, enums, helpers,
collections and APIs without native tests. The historical proposed inventory is
not rewritten or used to silently hide unsupported functionality.
