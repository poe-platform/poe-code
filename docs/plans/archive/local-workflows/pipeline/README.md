# Archived Pipeline Plans

This folder holds historical local pipeline plans moved out of `.poe-code`.
They are retained as workflow examples and provenance only.

At this cleanup, there are no active pipeline plan markdown docs. New durable
plans belong in `docs/plans/`; `.poe-code` is for runtime state and workflow
config.

Older YAML plans were converted to markdown with pipeline frontmatter during
this cleanup. There are 35 archived pipeline markdown plans here.
