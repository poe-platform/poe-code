# Archived Ralph Plans

This folder holds historical Ralph/TUI verification plans moved out of
`.poe-code`. Files prefixed with `legacy-` were flattened from an older nested
`archive/archive` folder during the documentation cleanup.

At this cleanup, there are no active Ralph plan markdown docs. New durable plans
belong in `docs/plans/`; `.poe-code` is for runtime state and workflow config.

This archive contains 33 Ralph markdown plans.
