## Design

1. Establish small native-Bash differential RED tests on unchanged production.
2. Share the existing formatter, preserving ordinary printf behavior. The shell
   execution path owns its bounded variable-output sink and publishes through the real
   scalar/indexed assignment APIs, never `context.env` or a global callback.
3. Preserve local/prefix restoration and isolated child scopes; validate lvalues,
   errors and partial assignment, NUL/invalid bytes, limits and cancellation.
4. Run only focused source-based checks with the supplied Node toolchain,
   `TSX_DISABLE_CACHE=1` and the base pointer's temporary directory. Record exact
   results and semantic limits here before handoff.

The existing indexed framework accepts literal nonnegative decimal subscripts
through 2147483647 and stores text, not arbitrary byte payloads. Do not broaden
its grammar/storage APIs or introduce host evaluation. Lossless scalar bytes
and explicit refusal of unrepresentable indexed bytes are the scoped design.

## Semantics and limits

- Accept `-v NAME`, `-vNAME`, repeated `-v` options (validate each; last wins),
  and `--` before the format. Assignment targets are shell identifiers or
  `NAME[N]` with canonical decimal N in 0..2147483647. Quoting the whole lvalue
  is supported. Runtime subscript strings containing quotes, arithmetic,
  negative indices, leading-zero numbers, variables or substitutions are
  explicitly refused with status 2; they are never evaluated.
- Publish using existing `writeVariable`, `assignVariable`, `arrayAssignment`,
  value arenas, indexed ownership and prefix-restoration APIs. Locals remain
  dynamically scoped; subshell, pipeline and invoked snapshots stay isolated.
  Successful same-name prefix publication survives while preserving the prior
  export attribute. OPTIND continues through its existing storage hook.
- Invalid options/targets or missing format return 2 without assignment.
  Numeric errors assign the formatter's result and return 1. Invalid/unsupported
  formatting assigns accumulated output and returns 1. Readonly refusal returns
  1 and keeps the prior binding; formatting diagnostics can precede refusal.
  Existing ordinary printf error/status behavior is not changed.
- Variable output truncates at the first NUL without substitution warnings;
  formatting still completes, including errors after that NUL. Trailing newlines
  and non-UTF-8 scalar bytes are preserved with owned immutable byte values.
  Indexed storage remains text-only: reject non-UTF-8 output and lossy promotion
  of a byte scalar whose index-zero value must survive. Overwriting index zero
  with valid text is allowed. No claim of general arbitrary-byte indexed arrays.
- Capture and copies reserve through the existing ValueArena before ownership
  copies; generated bytes (including discarded post-NUL output) are bounded by
  maxExpansionBytes. Retained values, intermediate fragments and copies share
  byte/slot budgets; indexed publications keep existing array-ledger limits.
  Variable output is not stdout and does not consume maxOutputBytes, but actual
  diagnostics/output still do. Existing formatter width/precision restrictions
  remain, and no new conversion/dynamic-width/time-format support is claimed.
- Invocation cleanup is registered before capture allocation. Checks precede
  capture writes and publication; falsey cancellation and cleanup failures retain
  identity. Completed effects are not promised to roll back after cancellation
  or cleanup failure. Logical storage accounting is not a native-RSS guarantee.

- Added three in-memory browser-export tests before production changes. The
  stub delegates actual decoding and replaces fatal decoding failures with a
  plain platform-shaped `TypeError` having no `code`. All three were RED:
  bare indexed assignment, indexed-element assignment and preservation of an
  existing byte scalar during promotion emitted a generic shell diagnostic
  instead of the documented explicit non-UTF-8 refusal. Status 1 and binding
  preservation already held in these probes; no corruption is claimed.

  standard `TypeError`. Decoder construction, byte materialization and storage
  reads stay outside the catch; unrelated TypeErrors cannot be relabeled as
  invalid UTF-8. Cancellation is checked before classifying the error. No global
  mutable decoder callback, new dependency, host access or new helper file.
- Added a storage-read TypeError control and four falsey cancellation controls.
  Each platform-shaped failure case also checks valid UTF-8/BOM success with the
  same stub. Final decoder-specific cohort: **8/8 pass**.
