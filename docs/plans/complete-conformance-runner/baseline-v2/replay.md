# Reproduce and inspect the complete baseline

Use the Node/ICU runtime and exact frozen workspace source/dist hashes in `manifest.json`, together with Test262 revision `419d3e0a2273ba01a3bfcbec423f2801425b8e93`. The source revision is local `f314e261c96e444b8fc983117864462171db5bc4` plus the recorded task runner working-tree contents and preserved unrelated workspace changes. A clean checkout at the Git SHA alone is not the full source identity; the manifest's per-file hashes and aggregate source hash are mandatory. This is not a measurement of the newer remote-main runtime.

The original uncompressed manifest and reports remain available locally. To inspect a delivered archive in a fresh directory, use `gzip -dc manifest.json.gz > manifest.json` and verify both compressed and decompressed SHA256 values against `manifest-archive-receipt.json`. Restore batch-report archive members into a fresh `batches/` directory, checking the archive receipt's per-member hashes. Do not overwrite original evidence.

`refined-batch-schedule.json` records all 126 exact maintained npm command arrays, corpus path, offsets, limits, report paths, unchanged 3,000 ms timeout and expected variant counts. Adapt only filesystem locations to the restored workspace. Each report path must be new: the runner creates reports exclusively and will not overwrite or append to old passes. Execute bounded selections with a modest process cap; record host load and all exit codes. The observed run used four concurrent selections initially, then five. It never changed a variant timeout or budget.

`aggregate-command.json` records the exact maintained CLI aggregation command over only the refined schedule's selected report paths. Aggregation freshly enumerates current source/corpus/runtime identity and rejects stale revisions, mixed manifests, missing or duplicate variants, incomplete summaries and wrong counts. Run it before any source revision/content change. A complete report may still return exit 1: success requires every enumerated selected variant to pass.

The root first cohort and `excluded-refinement-attempts/` are immutable historical attempts. Never include them, smoke probes, or diagnostic replays in the final aggregate. The final inventory retains raw statuses and separately classifies unqualified rejection policy, host capability boundaries, load/deadline limitations and semantic candidates. A timeout under recorded shared-machine load is not proof of an ECMAScript semantic defect.
