# Complete pinned Test262 baseline

The complete baseline is recorded: **216 disjoint selections, 53,876 JavaScript files and 102,926 unique variants**. Results are **93,157 passed, 6,451 failed and 3,318 unsupported**. All selected reports have terminal summaries; there are no omitted or duplicate variants, metadata errors or file execution errors. The maintained CLI aggregate correctly returned **exit 1**, `complete: true`, `success: false`. Runner success requires every selected variant to pass. See [aggregate receipt](aggregate-receipt.json), [independent inventory](inventory-summary.md) and [historical replay receipt](historical-replay-receipt.json).

The corpus is pinned to Test262 `419d3e0a2273ba01a3bfcbec423f2801425b8e93`. Enumeration includes 294 JavaScript fixtures, 20 other dependency assets, 44 harness files and 198 observed feature names. The variant census is 52,031 sloppy, 50,022 strict, 32 raw and 841 module variants. File content, fixture dependencies, harness content and individual variant identities are hashed. Unsupported module/agent requirements remain visible.

## Qualification and remaining work

Runner repairs have 145 passing fast conformance tests across ten files, with focused TypeScript and ESLint checks passing. Tests cover modes and negatives, harness adapters, async accounting, hard worker deadlines, exact selection and aggregation provenance. Two reproduced runner defects required withdrawing earlier cohorts and rerunning the entire corpus: an unbounded host operation and falsely qualified dynamic-import rejection tests. V3 admits none of the 1,153 non-parse script variants requiring the four unqualified module-loading features; all are explicit module nonpasses. The related 729 parse-negative variants pass. Historical cohorts contribute no V3 passes.

The [mismatch inventory](inventory-summary.md) retains all **9,769 nonpasses**, source/variant hashes, feature metadata, category owners and neighboring observed passing controls. [Reduced examples and primary contracts](../mismatch-samples.md) separate semantic candidates from capabilities, backend limitations and missing evidence. There are 4,546 external wall-timeouts and 191 budget guard failures; 74 rejection-policy nonpasses (50 synchronous, 24 asynchronous) remain unqualified runner/host policy, including six with secondary assertion diagnostics. Module loading, agents/shared memory, IsHTMLDDA and GC capabilities remain explicit gaps. Neither raw failed status nor absence of an intentionally withheld host capability proves an ECMAScript defect.

The maintained package unit route completed with **29,049 passed, 7 failed and 47 skipped** tests. Its seven preserved exploratory failures concern ISO calendar/backend behavior and Promise symbol admission; this package run predates the final runner repairs. The passing focused runner suite does not make the package suite green. See [package receipt](../package-checks.md) for commands, controls and skip disposition.

## Recovery, reproduction and delivery

An ENOSPC interruption left two incomplete selection reports and one zero-variant bootstrap log. Their original process exit statuses were unavailable and were not invented. Incomplete reports are archived and excluded; the two complete ranges were rerun under fresh report paths in [the final resume schedule](resume-batch-schedule.json). All 189 already complete reports were independently validated and retained unchanged. Only verified redundant task-owned raw copies were removed to recover space. A later storage checkpoint was verified and fully restored before aggregation. No unrelated source was deleted, no timeout or budget was relaxed and no partial prefix was salvaged as a pass. See [interruption](enospc-interruption.json), [recovery cross-check](resume-schedule-independent-crosscheck.json) and [restoration](completed-report-restoration.json).
