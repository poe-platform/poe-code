## Language security and drift decisions

The [exact mapping record](../docx/opc-xml-image-adaptation.md#exact-language-and-security-mappings)
is authoritative for this bounded increment. Neutral SDK spellings are retained;
immutable PackURI values replace string inheritance, async admission/publication
uses explicit byte/VFS capabilities, and returned package/XML objects are live
owned views. External targets remain inert. Sequences and keyed collections keep
distinct protocols; null, false and zero remain distinct. Source-private mock
identities map to observable ownership, graph, serialization or rejection
invariants rather than public callback or metaclass injection.

Image headers use original records for every selected parameter variant, including
both TIFF endiannesses, JPEG traversal and density/scaling boundaries. Independent
axis DPI and shared checked rounding supersede source defects (D13/D15). SHA-1 is
compatibility metadata; evidence uses SHA-256. Header characterization is not pixel
decoding or renderer qualification. XML observations use expanded names and
ordered content; significant whitespace/comments/processing instructions remain
observable, and untouched member bytes remain exact.

Public inherited, collection, helper, enum and underscore-prefixed APIs remain
explicit obligations. This task does not promote unrelated historical API rows or
resolve whole-public-API coverage. The pinned inventories and standalone MIT
notices remain intact; no reference identities belong in product tests or code.
