# Extraction/layout candidate QA

Execute these steps as an agent against the built portable parser entry. Use
original in-memory controls without native PDF oracles or ambient font assets.

1. Run maintained pdf-parser unit, lint/typecheck and selected workspace build
   routes. Require zero failing or cancelled cases.
2. Import the built entry in Node; supply a tiny Type1 font with explicit widths
   and text-content bytes from an independent VM realm. Require byte admission
   and the expected mapped glyph.
3. Position A at PDF (20,70), choose box (10,20,210,120), and rotate -270 degrees.
   Require rotation 90, display origin (50,10), original origin (20,70) and
   geometryComplete true.
4. Supply an imitation byte object with a length property. Require fatal
   ARGUMENT rather than structural byte authority.
5. Abort from the explicit font lookup capability with an object reason.
   Require that exact reason to propagate unchanged.
6. Inspect built layout imports and manifest: local first-party modules only,
   empty runtime dependencies. Confirm no dependent command gate is enabled.
7. Record results and remove only task-owned verification logs. No visual CLI
   changes require screenshots.

Local execution: checks 1–6 passed on Node 22.22.2. Built-entry controls qualified
foreign byte realms, crop/rotation, original geometry, byte admission and exact
capability cancellation. Browser/workerd/Bun, installed safe-bash bundling and
replay remain unverified independent gates.
