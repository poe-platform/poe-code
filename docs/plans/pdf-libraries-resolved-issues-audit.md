# Upstream PDF Libraries Resolved Issues Audit & Hardening (`@poe-code/pdf-ast` & PDF Tooling)

This document catalogs the systematic audit of resolved issues across `pdf-lib`, `pypdf`, `qpdf`, `pdf.js`, `poppler`, and `exiftool`, verifying `@poe-code/pdf-ast` and our unified PDF tooling packages (`safe-bash-command-qpdf`, `safe-bash-command-pdfinfo`, `safe-bash-command-pdftotext`, `safe-bash-command-exiftool`, `safe-bash-command-soffice`, `safe-bash-command-wkhtmltopdf`, and `@poe-code/pandoc`) against real-world reproduction cases.

## 1. Package Removal (`safe-bash-command-tesseract`)
- **Commit**: `23895efce` (`chore(safe-bash): remove safe-bash-command-tesseract`)
- Removed `packages/safe-bash-command-tesseract/`, `packages/safe-bash/src/commands/tesseract/index.ts`, and `docs/plans/safe-bash-tesseract.md`.
- Updated root and workspace configurations so all PDF/document tooling packages remain lightweight and zero-external-OCR-dependency.

## 2. Audited Upstream Issues & Fixes by Subsystem

### Batch 1 — Page Merging, Inherited Attributes, AcroForm Fields & Redaction (`#10`, commit `255898292`)
| Upstream Reference | Root Cause in Upstream / PDF Spec Edge Case | Resolution & Reproduction Test in `@poe-code/pdf-ast` |
| --- | --- | --- |
| `pdf-lib #1579`, `#1686`, `#1332`, `pypdf #4078` | Copying pages from a source PDF whose `/Resources`, `/Rotate`, `/MediaBox`, `/CropBox`, `/BleedBox`, `/TrimBox`, or `/ArtBox` are defined on ancestor `/Pages` nodes drops fonts/images/rotation, or `/Annots` widget `/P` and `/Parent` pointers clone the entire unselected document tree. | `PdfDocument.copyPagesFrom` (`packages/pdf-ast/src/document.ts`) now materializes inherited `/Resources`, `/Rotate`, and all five page boxes from ancestor `/Pages` nodes before cloning, strips `/Parent` on page nodes while preserving `/Parent` on AcroForm widgets, and remaps widget `/P` references only to selected pages. |
| `pdf-lib #1585`, `qpdf #1056` | Hierarchical AcroForm fields with anonymous widget `/Kids` emit duplicate `unknown` fields; checkboxes with custom on-state names (e.g. `/Agree`, `/Yes`, `/1` in `/AP /N`) fail when hardcoded to `/Yes`; setting `/V` without updating child widget `/AS` leaves visual appearance un-toggled. | `getDocumentFormFields` & `setDocumentFormField` (`packages/pdf-ast/src/edit/forms.ts`) skip anonymous widget `/Kids` when the parent field defines `/FT` and `/T`, inspect `/AP /N` keys to discover custom checkbox on-values, and propagate `/AS` to all widget `/Kids`. |
| `pypdf #4062` | Redacting text inside transformed coordinate spaces (`cm` inside `state-op` or nested `q ... Q` `graphics-group` nodes) miscalculates glyph bounding boxes in page coordinates. | `redactPageContentAst` (`packages/pdf-ast/src/edit/redact.ts`) tracks the cumulative transformation matrix (`CTM`) across both top-level and nested `graphics-group` nodes. |
| `pdf-lib #1075`, `#1082`, `#1541` | Appending drawing operations (`drawText`, `drawRect`, `drawImage`) to an existing page with an unbalanced or transformed content stream (`cm`, clipping paths) distorts newly drawn content; mutating inherited `/Resources` corrupts sibling pages. | `PdfPage` (`packages/pdf-ast/src/page.ts`) clones inherited `/Resources` dictionaries when detaching onto a page and wraps pre-existing page content streams in `q ... Q` before appending new drawing operations. |

### Batch 2 — Floating-Point Serialization, Inline Images, Predictors & Page Scaling (`#11`, commit `2e25c59b1`)
| Upstream Reference | Root Cause in Upstream / PDF Spec Edge Case | Resolution & Reproduction Test in `@poe-code/pdf-ast` |
| --- | --- | --- |
| `qpdf #1079`, `pdf-lib #1184` | Rotated `drawText` (`90°`/`180°`/`270°`) produces `Math.cos(Math.PI / 2) = 6.123233995736766e-17`, and JavaScript `String(number)` emits exponential notation (`1e-7`) which violates ISO 32000-1 Section 7.3.3 real-number syntax. | Added `formatPdfNumber` in `packages/pdf-ast/src/ast.ts`, `cos/writer.ts`, and `content/serializer.ts` (clamping `\|n\| < 1e-12` to `0` and formatting fixed decimals without scientific notation), plus `CosByteLexer` recovery for malformed upstream PDFs containing `e`/`E` numbers. |
| `pypdf #3922`, `pdf.js #14210` | Uncompressed or binary inline images (`BI ... ID <bytes> EI`) frequently contain the byte pair `0x45 0x49` (`EI`) followed by whitespace inside pixel data, prematurely terminating the inline image parser. | `packages/pdf-ast/src/content/parser.ts` computes the expected uncompressed inline image byte length from `/W`, `/H`, `/BPC`, and `/CS`, consumes `\r\n` after `ID` as a single delimiter, and validates that `EI` is followed by a valid content stream operator or `EOF`. |
| `pdf-lib #1496`, `pypdf #3845` | FlateDecode streams with PNG (`10–15`) or TIFF (`2`) predictors that include trailing zero-padding bytes or partial final rows fail or drop the final scanline. | `packages/pdf-ast/src/stream/predictor.ts` processes all complete scanlines and tolerates trailing padding bytes. |
| `pdf-lib #991`, `#1035`, `pypdf #4062` | Scaling a page (`scale(x, y)`) must scale page boxes, prepend `x 0 0 y 0 0 cm` to content streams (`scaleContent`), and scale `/Annots` `/Rect` arrays (`scaleAnnotations`); rotated text (`Tm` with non-zero `b`/`c`) requires Euclidean glyph scaling `hypot(a, b)` during text extraction. | Added `PdfPage.scale(x, y)`, `scaleContent(x, y)`, and `scaleAnnotations(x, y)` in `packages/pdf-ast/src/page.ts` and Euclidean `hypot` font size/direction calculation in `packages/pdf-ast/src/extract/text.ts`. |

### Batch 3 — COS Indirect `/Length`, Scaled `Tm` Evaluator, `/AcroForm /DR` & Surrogate CMap (`#12`, commit `6be1c2964`)
| Upstream Reference | Root Cause in Upstream / PDF Spec Edge Case | Resolution & Reproduction Test in `@poe-code/pdf-ast` |
| --- | --- | --- |
| `pdf.js`, `qpdf` stream length recovery | When a stream dictionary specifies `/Length N G R` (an indirect object reference defined later in the file) or an inaccurate `/Length` integer, naive `indexOf("endstream")` can overshoot into a subsequent object's stream if `endstream` is missing. | `packages/pdf-ast/src/cos/parser.ts` resolves indirect `/Length N G R` values via `scanIndirectNumberValue` and bounds fallback `endstream` scanning by the next `endobj` boundary. |
| `pypdf #4116`, `pypdf #3983` | Content streams setting `/F1 1 Tf` with font size in the text matrix (`12 0 0 12 tx ty Tm`) had glyph advances computed with `fontSize = 1` instead of `12`, collapsing word spacing; pages referencing fonts defined only in `/Root -> /AcroForm -> /DR -> /Font` missed ToUnicode CMaps. | `packages/pdf-ast/src/content/evaluator.ts` scales text matrix advances properly without double-multiplying `state.fontSize` and falls back to `/Root -> /AcroForm -> /DR -> /Font` when resolving page fonts. |
| `pdf.js` / `pypdf` UTF-16BE `bfrange` | `beginbfrange` CMap ranges spanning supplementary Unicode planes (e.g. mathematical symbols `U+1D400` encoded as UTF-16BE surrogate pairs `<D835DC00>`) incremented `charCodeAt(length - 1)` in 16-bit units instead of full Unicode code points. | `incrementStringCodePoint` in `packages/pdf-ast/src/fonts/cmap.ts` uses `String.fromCodePoint` and `codePointAt` to advance full Unicode code points across surrogate pairs. |

### Batch 4 — `safe-bash-command-qpdf` Overlays, AcroForm Flattening & Nested Form XObject Images (`#13`, commit `1c5ebe983`)

| --- | --- | --- |

| `qpdf #949`, `qpdf #1039` | `--flatten-annotations` dropped widget annotations that lacked an `/AP /N` stream even when `/V` (text value) was present, failed to select the active `/AS` sub-stream when `/AP /N` was a state dictionary, and deleted `/Subtype /Link` hyperlink annotations. | `flattenAnnotations` (`packages/safe-bash-command-qpdf/src/index.ts`) preserves `/Subtype /Link` annotations, selects `/AP /N -> /AS` state streams, and synthesizes text appearances from `/V` (or parent `/V`) when `/AP /N` is absent. |
| `qpdf #909` | `--show-pages --with-images` only inspected top-level `/Resources -> /XObject` entries, missing images nested inside `/Subtype /Form` XObjects. | `collectImagesFromResources` recursively traverses `/Subtype /Form` XObjects with cycle protection. |

### Batch 6 — `safe-bash-command-pdftotext` & `safe-bash-command-exiftool` (`#15`, commit `f5437935e`)

| --- | --- | --- |
