# Animation authoring domain receipt

Scope: F46 and section 6.6, package-local authoring with no host I/O, network, playback or native runtime. Owned implementation files are `packages/pptx/src/animation-editing.ts` and its original in-memory test file. Root coordinator owns object lifecycle regressions and CLI agent owns command normalization/schema/public wiring. No README edits or fixtures are included.

Implemented appear, opacity fade entrance/exit, and one pulse cycle with explicit 100% → 110% → 100% scale phases. Integer milliseconds include an odd-duration split without rounding the total. Timing root, main sequence, click groups, effect and behavior nodes allocate distinct IDs above every existing timing ID. Each click starts a parallel group; dependent effects inside that group reference their preceding effect's begin/end. The next click advances the sequence. Targets resolve uniquely to slide objects; original locations and tokens remain valid across the bounded atomic animation batch because slide/object identity does not change.

Only the documented canonical simple sequence is reconstructed. Unknown sibling nodes remain untouched. Unknown attributes, text, extensions, media and complex timing within the main sequence cause `unsupported-edit`; ordinary reads remain available. Removing a referenced effect or behavior/group identity is rejected. A batch can first change the dependent trigger to on-click and then remove the earlier effect; failure returns no package to publish. Empty batches validate and return the unchanged source. Batches are capped at 1000 operations and retain per-operation metadata rather than all intermediate archives.
