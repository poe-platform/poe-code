# Presentation corpus gap acquisition

Scope: documentation and evidence only; no product implementation, pipeline,
README, push or release. Preserve all pre-existing changes.

## Agent procedure

1. Review the format, shared CLI/SDK contracts, source test/API inventories and
   existing mapping registers. Verify exact source-row accounting; keep semantic
   adaptation and implementation gaps explicit, including inherited and returned
   underscore-prefixed APIs. Keep reference identities in research/legal notices.
2. Target the measured zero-chart, zero-content-CJK and zero-signature gaps with
   public publisher listings. Download only explicitly linked HTTPS decks, with
   no credentials, access-control bypass or relationship-target requests.
3. Use sequential transfers (maximum allowed two), 20-second connection timeout,
   120-second total timeout, five HTTPS-only redirects and 64 MiB per new deck.
   Total `.cache/pptx-corpus` budget is 768 MiB including existing files and partial
   transfers. Check available budget before each transfer and enforce byte limits.
   The historical large-media exception remains separately named
   `large-media-acquisition-512MiB`; it does not raise product defaults and is not
   used for new acquisitions in this campaign.
4. Keep downloads in ignored cache only. Record URLs, actual UTC acquisition time,
   SHA-256, bytes, content type, rights uncertainty and bounded CRC/XML census.
   Do not extract or execute embedded objects, resolve external entities, fetch
   linked resources or validate signatures by contacting remote services.
5. Reduce meaningful observations and unavailable features into small original
   TypeScript arrange/action/assert designs with authored in-memory assets.
   Synthetic designs are neither downloaded decks nor executed regressions.
6. Run maintained scoped Prettier and whitespace checks, verify manifest/cache
   hashes and census totals, and inspect ledger/API coverage and notice retention.
   Commit explicit owned documentation paths on main only.
