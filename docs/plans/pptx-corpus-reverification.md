## Agent procedure

1. Read root/scoped instructions, format/shared contracts, inventories and existing
   case/API/command registers. Preserve unrelated working-tree changes.
2. Rehash every manifest-listed cached download before and after inspection.
   Stream ZIP members through CRC verification, count actual expanded bytes and
   rehash every listed media part. Compare these measurements to the manifest.
3. Parse bounded XML with declarations/entities denied. Record explicit zeroes
   for missing chart, diagram, comment, Strict and signature indicators; inspect
   text direction/language, media relationships and unusual layout indicators.
   Counts cover all parts and MCE branches, not rendered slides or supported edits.
4. Record elapsed host inspection time separately from animation timing-node
   counts. It is a single preparation measurement, not a product benchmark.
5. Review primary publisher landing pages and terms. Preserve acquisition dates
   and hashes; distinguish local byte verification from a fresh HTTP download.
   Do not infer asset-specific clearance from a publisher's general media policy.
6. Keep default-limit predictions separate from the raised census profile.
   Record original small regression designs for meaningful structural risks;
   actual red/green tests and independent rendering remain implementation work.
7. Run installed maintained Prettier on owned Markdown/JSON and git diff --check;
   check document identities, measurements, evidence links and unchanged source
   hashes. Stage explicit owned documentation paths and commit locally.
