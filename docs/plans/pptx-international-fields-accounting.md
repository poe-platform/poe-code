## QA procedure

Use only caller-supplied in-memory package bytes for permanent unit evidence.
If the coordinator performs disposable document QA, choose fixtures from
`docs/pptx/corpus-manifest.json`, verify their hashes and keep binaries ignored.
Do not download assets for unit tests or run the whole pipeline. A meaningful
metadata/cache finding becomes a small original regression with independent
XML/text expectations. Visual layout or complex shaping claims require actual
application screenshots; structural metadata tests cannot establish them.
