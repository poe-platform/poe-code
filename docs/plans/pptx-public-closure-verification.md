- API worker: central public API register and its current closure receipt.

## Agent verification procedure

1. Read the API/test inventories and reconciled language/security mappings.
   Validate each newly reported issue with original tests before editing code.
2. Run the maintained PPTX package unit and lint routes and selected workspace
   build closure. Review the exact exports from the built public package.
3. Execute the maintained safe-bash PPTX command-family tests against the build;
   these use original memfs virtual files and explicit capabilities.
4. Inspect focused changes, retained denominator and evidence. Mark unsupported
   public behavior explicitly; source/runtime export presence alone is not a pass.
5. Commit each verified improvement with only its owned source/tests/evidence and
   relevant plan. Report local hashes separately from remote delivery.
