## Scope and independent acceptance

- Patch the selected palette/font slots without flattening overrides or modifying unrelated theme payloads. Cover a contrast-relevant dk1 change and all six font slots.

- Compare generated XML using an independent SAX reader and independent ZIP decoder, including unchanged member bytes. Unit fixtures are original and held in memfs; no downloads, native runtime or host file writes.

J02 maps property reads/setters to JS access/assignment with owner identity: background fill access that creates a definition remains an explicit future model behavior; read-only backgrounds.get/list must not create it. J04 preserves typed enum symbols/aliases and immutable XML values. J05 distinguishes null/absent/noFill, six-digit RGB and exact finite validation. J06 requires async byte/resource admission with explicit capabilities, never ambient paths or network. J07 requires supplied metrics/time rather than ambient discovery. J08 maps errors to neutral stable categories. J09 maps element/part to bounded XML/package views; no arbitrary XML runtime.

D07: the documented follow_master_background setter is an additive obligation despite the pinned source getter-only implementation.
