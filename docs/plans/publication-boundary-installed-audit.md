# Publication boundary installed audit

Preserve the 16 command plans, PDF metadata → text/layout → lossless sequencing,
source exclusions, held evidence and archive admission. This audit does not
qualify broader command compatibility or authorize default registration.

## Manual QA

1. Inspect the guarded Safe Bash builder, opt-in exports, integration boundaries,
   package-lint, declaration rewriting and release-safe publication candidates.
2. Reproduce transitive private installation admission with an independent
   lockfile negative control. Require rejection before imports and consumer
   cleanup; retain a similar-name public helper positive control.
3. Run publication suites, maintained package-lint tests, syntax and focused
   ESLint. Run complete `npm run build`, `npm test` and `npm run lint`.
4. Prepare and pack only safe-fs, safe-js and safe-bash. Install those tarballs
   outside the checkout with scripts and workspace resolution disabled.
5. Execute maintained publication-boundary and registration fixtures with empty
   PATH. Compile strict installed private-command and registration consumers.
6. Independently bundle browser and workerd conditions from installed packages;
   execute each in a VM without Buffer, process or require. Check canonical
   constructors, carrier admission, byte ownership and actual Shell invocation.
   These cells do not certify native browser/workerd execution.
7. Inspect installed locks, owner licenses and runtime/declaration entries.
   Purge task-owned packing scratch and temporary consumers after verification.

No visible CLI change is involved; screenshots are not applicable. No release
is performed locally, and local verification is distinct from remote delivery.

## Local verification, 2026-09-19

The existing checkout already contained declarative command publication recipes,
private-owner asset/license packing, declaration rewriting, privacy lint and
installed command fixtures. Those edits were preserved. Release-safe publishes
only safe-fs, safe-js and safe-bash; no command publication job was added.

an installed command, scoped engine or contracts package could pass verification
despite being a private runtime installation. The verifier now rejects these
entries before imports. All three controls pass, including attempt-directory
cleanup, and a similar-name public helper remains accepted.
