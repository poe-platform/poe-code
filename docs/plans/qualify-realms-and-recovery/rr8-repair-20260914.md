synchronous shared writes through exported collection entries and named/symbol

## Repair and supported envelope

Argument export already traverses supported graph edges with its existing
budget and admission checks. Its shared-buffer callback now supplies the host
journal with storage reached through Maps, Sets and named/symbol properties.
There is no second reflective traversal and no new getter invocation. Historical
argument digests and their block order remain unchanged. Additional exported
blocks are deduplicated by storage identity and appended after digest blocks.
Aliases, cyclic Maps and different export/digest block orders have controls.

New records needing these additional edges carry `sharedGraph: true` together
with `sharedRegistry: true`. Malformed marker values are rejected. An older
record without this marker remains admissible if its registry already covered
the extra blocks; otherwise recovery rejects before the affected host operation
or later effects. This marker records graph coverage, **not ownership of arbitrary
future shared writes**. Host-call recovery still uses the declared re-issue or
external-reconciliation policy. Calls first reached after a pending recovery
receive new coverage records.

The [authentic pre-repair v8 fixture](rr8-repair-20260914/legacy-graph-v8.json)
was captured from clean remote source before applying the repair. SHA-256:
`5b5f4fe8faf9355ac8c7e5913718fb17cb29179e5f02ddbf525ff0d254d7c6a6`.
It is rejected before effects, without relabeling its version or recomputing its
historical digest. A separate pre-repair dirty-v9 fixture was also captured and
used locally; that fixture is not evidence of remote jobs-v9 support.

Custom guest descriptors/prototype links remain unsupported on this plain host
argument projection path and reject before host invocation. This does not limit
the separately supported internal heap descriptor transport. No arbitrary
live-realm interoperability, native-stack capture, deterministic weak lifetime,
unobserved shared-memory history or exactly-once external effects is claimed.

## Remaining blockers and recovery path

The queued-write witness still returns **7 originally / 0 after accepted pending
and completed return-only replay**, with `replayError: null`. With a later effect,
pending recovery produces **[7,0]** and completed recovery detects the mismatch
only later. Synchronous direct controls remain **7/7/7**. Its observer exits zero
because observation completed, not because recovery passed. Graph discovery
alone cannot establish capture ownership of retained raw shared storage.

SM-REPLAY-1/2 needs an explicit ownership/history design and legacy admission
rules that reject unsupported histories before resumed effects. Bun needs a
runtime-supported shared-wrapper transport or an equivalent implementation that
preserves shared storage; copying bytes into an ordinary ArrayBuffer would not
satisfy the contract. Full runtime/artifact qualification is not inferred from
these focused controls. The 57 clean-main transport/rejection nonpasses also require separately
validated integration of the inherited repairs. These blockers prevent completion of
`qualify-realms-and-recovery` even if this narrower repair is published.
