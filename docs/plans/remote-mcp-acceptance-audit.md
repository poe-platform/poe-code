## Public option inventory

The facade is typed in `src/index.ts`; management factory options use the same
SDK option interfaces. JSON data can persist in configuration/artifacts;
functions, abort signals, stores and fetch/browser implementations are supplied
again by the host. SDK parity does not make those executable values serializable.

| Surface | Caller configuration | Management/tool command equivalent | Remaining question |
| --- | --- | --- | --- |
| Registry | name, url, transport, tools, instructions, protocolVersion | Static registry supplied to management factory; init/config outputs preserve it | No editor import/add/remove or URL/name inference. |
| Credentials | headers env references, bearer token reference, OAuth clientMode/clientName/profile/tokenEndpointAuthMethod and credential references/fallbacks | Empty init env template and command environment binding | Runtime literals only through explicit environment/store APIs. |
| Discovery | requestTimeoutMs, maxPages, maxTools, maxResponseBytes | `generation.schema`; generate --timeout-ms, --max-pages, --max-tools and --max-response-bytes override SDK values | Tool limit also applies to resolved/supplied configuration. |
| Tool execution | requestTimeoutMs and transport limits; maxInputBytes/maxOutputBytes, yes, schemaValidation | Before tool: --timeout-ms, --max-response-bytes, --max-input-bytes and --max-output-bytes; after tool: --yes, --raw and schema-derived exact flags | Exact same-named tool fields remain schema-owned. Input/output policies can tighten host ceilings; timeout/response policies override host defaults. -- selects literal dash-prefixed tools. Compiler hooks remain host dependencies. |
| Explicit auth | requestTimeoutMs, maxResponseBytes, noBrowser, reset | auth --timeout-ms, --max-response-bytes, --browser none/host, --no-browser, --reset, --json | OAuth metadata/token byte limits remain native policies. Inherited maxPages/maxTools have no auth listing operation. Binding limits are host-owned ceilings. |
| Reset | timeoutMs, binding/persistence | reset --timeout-ms and --json; auth --reset | Reset reads no credential values and performs no network. |
| Import | requestTimeoutMs, timeoutMs, maxImportBytes, binding/fetch/cache | import --timeout-ms, --lock-timeout-ms, --max-import-bytes, --file or stdin, --json; credentialImport settings | Virtual input collection respects the smaller selected import budget and management maxInputBytes. |
| Resources | operation, URI/cursor, requestTimeoutMs, maxInputBytes and transport limits | resource URI, --cursor, --templates, --timeout-ms, --max-input-bytes and --max-response-bytes; resources settings | One complete page is intentional. Host command input limit also applies. |
| Artifacts | maxConfigurationBytes/maxTools/maxArtifactBytes, schemaRegistry, binding/schema options | generation settings; generate --format json/config/module, --max-configuration-bytes, --max-tools and --max-artifact-bytes | JSON-only external registries are host-supplied and archived. |
| Host integration | signal, fetch, oauthDiscoveryCache, onWarning, onElicitationRequest, env, credential size policy, stores/locks/browser/clock | Typed management suboptions and command/runtime context | These cannot be represented as arbitrary textual executable values. Host owns persistence and UI. |
