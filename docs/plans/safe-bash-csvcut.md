## Observed release controls

These observations are from csvkit 2.2.0, agate 1.14.2, Python 3.9. They do not prove parity for every source-snapshot feature. Escaped strings preserve final newline distinctions; status is the process exit code.

- **cut-default**: argv `[]`; input `"a,b\n1,2,3\n4\n"`; stdout `"a,b\n1,2\n4,\n"`; status 0.
- **cut-duplicate**: argv `["-c","a,a"]`; input `"a,a\n1,2\n"`; stdout `"a,a\n1,1\n"`; status 0.
- **cut-order**: argv `["-c","2,1,2"]`; input `"a,b\n1,2\n"`; stdout `"b,a,b\n2,1,2\n"`; status 0.
- **cut-exclude-unknown**: argv `["-C","missing,99"]`; input `"a,b\n1,2\n"`; stdout `"a,b\n1,2\n"`; status 0.
