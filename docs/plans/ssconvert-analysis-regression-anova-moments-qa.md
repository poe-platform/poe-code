## Property audit

The existing source-authenticated catalog is shared by CLI `toolTest` and SDK `toolTest`. Generic tools consume `data`, grouped by row/column/area/bin and optionally remove a leading label. Regression consumes explicit `x`/`y`; generic `data` is not its input. `multiple-regression` selects detailed output, `multiple-y` selects the dependent-series side only in simple output, `intercept` selects the model constant and `residual` selects detailed residual diagnostics. Regression and ANOVA use alpha default0.05. Descriptive output has four independent enabled-by-default section flags, confidence default0.95, median/SSMEDIAN selection and independent rank defaults1. ANOVA2 uses replication default1 and removes both a label row and column. Correlation/covariance/PCA expose only grouping and labels. There is no writable property named `detailed-statistics` in this release; the applicable switch is `multiple-regression`.

ANOVA2 retains relative range axes unlike GenericAnalysisTool: native unqualified `data:A1:B4` relocates source references by each output cell. Absolute `data:$A$1:$B$4` provides the mathematical fixed input. This behavior was reproduced with a failing command test and is preserved, rather than replacing released behavior with textbook results.
