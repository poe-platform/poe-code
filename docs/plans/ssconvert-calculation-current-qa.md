# Calculation dependency and numeric regression QA

This procedure extends `ssconvert-calculation-core-qa.md` for the live dirty
candidate. Preserve all preexisting edits and evidence. No README edits, native
product dependency, commits, push or publication are part of this execution.

1. Rehash the retained official 1.12.61 archive before inspecting source only in
   `out/ssconvert-calculation-current`. Check `value_new_float`, TABLE registration
   and evaluation, and computed-reference dependency linking. Keep source-derived
   checks distinct from native observations; unavailable exact oracle is unverified.
2. Run original in-memory regressions before repairing negative zero, TABLE absent
   headers, computed-range cache invalidation, syntax/name depth, recursive dirty
   flags and numeric formula text notation. Use typed
   exact assertions; apply no numeric tolerance or text normalization.
3. Independently stress the repaired evaluator with another agent. Cover named,
   relative, shared and array dependencies, sparse literal updates, cancellation,
   retry/rollback, missing header authority, cycles and combined depth/visit budgets.
   Unit tests use memory/memfs; never native subprocesses, file writes or LLMs.
4. Verify real Shell and SDK execution of `--set B1=8` inside a computed range.
   Require matching output bytes, zero diagnostics, unchanged input/namespace,
   retained exact cache, and identical output from a reloaded checkpoint. This
   checks workbook cache replay, not an unimplemented VM checkpoint facility.
5. Run fresh maintained ssconvert build/test/lint, safe-bash integration test/lint
   and typecheck, and selected safe-bash build closure. Run broad root test/lint/
   build gates for this shared graph change. Investigate every failure without
   erasing other workers' changes or weakening guards. Separate final candidate
   passes, failed prerequisites, skips and incomplete gates.
6. Create an ad hoc driver only in `out`, exercising the built Shell command:
   computed-range update output 12, canonical zero, absent TABLE output zero,
   and an unsupported function that leaves an existing destination unchanged.
   Use the repository screenshot route and inspect the image. Preserve channel
   and status assertions separately from the screenshot presentation.
7. Bind final live source/tests to a complete canonical UTF-8 byte-sorted inventory
   and SHA-256 before/after final checks. Report dirty source rather than an
   immutable Git revision. Record mismatches, unverified runtime/profile cells,
   nondeterminism and host policy refusals explicitly. Purge only task-owned
   temporary evidence after reducing the results into the verification document.
8. Independently attempt a QA-only native oracle rebuild from authenticated
   libgsf 1.14.53, GOffice 0.10.61 and Gnumeric 1.12.61 archives. Keep all source,
   build and installed prefixes under `out/ssconvert-calculation-native` (`/out`
   in the container). Capture compiler, actual dependencies, activated plugins,
   binary hash, C locale and UTC timezone as a new profile. Historical profiles
   remain unchanged. Exercise original scalar/array/IF/TABLE and numeric-domain
   cases separately from canonical unit tests. Record unsupported variants and
   unavailable runtime cells; source archive/version alone is not runtime parity.
9. Separate automatic native import calculation from an explicit `--recalc`:
   preserve both outputs for cached cycles and iteration caps. Compare the
   evaluator with equivalent one-phase and two-phase memory workflows, rather
   than treating native import as a transparent loader. Measure number-to-text
   formula concatenation at the binary64 notation boundaries and with a fixed
   seeded corpus. Preserve exact text differences and minimized inputs without
   numeric tolerance; a fixture numeric exporter is not product CSV coverage.
10. Import the built public `poe-code/ssconvert` export. Check exact cycle and
    concatenated text values, owned null-prototype result records, zero resolver
    calls in an inactive branch, unchanged original input and workbook-cache
    replay. Treat ordinary-prototype expectations as a harness ownership mistake,
    not a reason to weaken the existing data-admission policy.

11. Use original scalar and array volatile TABLE headers to check copied header
    identity: corner `IF(header=E1,1,0)` must return 1. Verify independent header
    caches survive unrelated input substitutions; a header depending on the column
    input recalculates before its copied row value. Check sparse inputs and rollback.
    Require command/SDK exact bytes and unchanged original/namespace. Native RNG
    draw counts remain unmeasured; injected draws establish repeatable tests only.
