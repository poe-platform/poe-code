It does not implement generic PO escaping.

## Remaining mismatches and unmeasured cases

- A concrete font-overflow differential remains: the original hidden-axis fixture with wrapping removed produces 461 native bytes versus 449 JavaScript bytes for `latex_table`. Native Pango spans extend the export extent through D; JavaScript currently uses populated cells, occupied merges and objects. The profile retains the exact source and both base64 outputs. Full LaTeX and visible fragments share this extent limitation. No approximate font-width heuristic was added.
- Native glossary execution is unavailable in this captured no-Python plugin profile and its source uses legacy Python APIs. UTF-8 entry construction is verified against source-defined expectations only. Native Unicode write-length/encoding behavior, Python dictionary printing to stdout, plugin error wording/status and orphan-definition behavior are unqualified. JavaScript deliberately requires an injected clock and reports a typed error for a definition without a preceding term; these are bounded implementation behavior, not measured native parity. The native profile does not list PO; the explicitly implemented JavaScript provider does.
- Nondefault LaTeX UTF-8 configuration, every font/locale/timezone, font-dependent narrow-column render clipping, formula-display views, every border connector/alignment/font combination, hidden-sheet iteration and overlapping partial-style overrides are unmeasured. The mixed-border golden is not proof of every connector combination. Glossary language basenames with encoded/non-ASCII URI components and non-UTC timestamp abbreviations are unmeasured.
- The full Safe Bash public-consumer typecheck remains blocked as described above. No full-repository lint/test or release qualification is claimed. No commit, push or publication was performed, and no README was edited.

Unsupported and unmeasured cases are not passes. These exporters are implemented and integrated, but the known overflow differential and unavailable native glossary oracle prevent a claim of complete Gnumeric parity.
