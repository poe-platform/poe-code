## Source reasoning and regression

The authenticated Psiconv source assembles a `u32` pixel with individual shifts of at most eight bits, even when depth exceeds 32. For color depths 33–47, channel widths are `ceil(depth / 3)`, `ceil(depth / 3)` and the remainder. Every mask shift is below 31 and the red pixel shift stays below 32 (31 at depth 47). Depth 48 reaches an undefined 32-bit shift. Unknown nonzero color markers use native color fallback. Grayscale depths above 32 remain unqualified. Gnumeric discards the embedded image's pixel arrays, so this reader validates structure and work admission without retaining pixels.

Seven new cases failed on the blanket unsupported-depth error before the repair. Their first post-repair run exposed a wrong expected message for the test-only Binary cursor's truncated trailer; correcting it to the cursor's actual `truncated binary data` diagnostic yielded 27/27 focused passes. This helper diagnostic does not establish native Psiconv diagnostic parity.
