# Legacy text candidate QA procedure

1. Authenticate the official 1.12.61 archive under `out/ssconvert-lifecycle`; compare Oleo integer-pointer advancement and SC label validation/fetch ordering directly with released source. Preserve inherited reference profile and evidence.
2. Run original in-memory malformed-coordinate regressions before repair. Independently stress invalid labels, dimensions, unsupported directives, expression translation, cell bounds and cancellation with a different agent.
3. Use the explicitly separate `ssconvert-statistics-qa` oracle via Docker's `colima` context, C locale, UTC and the dependency paths recorded in the reference profile. Put inputs/checkpoints only in `out/legacy-text-candidate` inside the oracle. Compare original Oleo malformed coordinates followed by a cached formula through CSV, XML checkpoint and reopened CSV. Compare malformed SC labels followed by a valid cell, and an invalid label followed by a fatal target. Inspect XML dimensions and exact diagnostics/statuses.
4. Execute maintained uncached selected workspace builds and fresh ssconvert workspace tests/lint. Run the registered ssconvert virtual-command suites, including original/checkpoint/replay. Inspect an ad hoc terminal screenshot from the maintained screenshot route. Purge only candidate temporary files after extracting results.
5. Record the candidate source hashes, actual gates, failed expectations and their investigation, skips and unmeasured runtime/profile cells separately in the verification record. No README edits, Git commits, push or publication.
