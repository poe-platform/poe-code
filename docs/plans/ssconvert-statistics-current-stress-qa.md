measurements. Do not push, publish, change README files or use native utilities
inside unit tests. Root owns integration, exports, evidence and Git.

2. Ask a separate agent to inspect interpolation, random and queueing edge cases.

   a CLI screenshot. This does not measure real-format codecs or native fallback.
