# XLSX independent stress procedure

Use the different-agent review against the shared ssconvert SDK engine, with small original ZIP fixtures and injected memfs byte I/O. Unit tests never run native utilities or touch host files. Root owns product integration and Git; coordinate validated product repairs before edits.

1. Capture the native QA-only Gnumeric 1.12.61 binary, library, active importer and locale identities in the retained `ssconvert-statistics-qa` Docker container. Verify the official archive SHA-256 and inspected reader/include file identities. This oracle is never a product dependency or fallback.
2. Construct original tiny OOXML packages under `out/ssconvert-xlsx-independent`; cover `.xlsx`, `.xltx`, XML workbook under macro suffix, genuine binary workbook member, unknown XML, unknown extension with/without URI, protection, VBA bytes, bogus/encrypted container, namespaces and malformed parts. Capture exact native argv/status/stdout/stderr and uncompressed Gnumeric output.
3. Exercise the actual shared SDK engine using equivalent original fixtures in memory. Verify normal/shared/array formula spelling and caches, missing caches, scoped names, worksheet order, cancellation and owned bytes. Test malformed relationships, namespace boundaries, row/address/member limits, XML entities, byte and operation budgets. Require concrete failing assertions before repairs.
4. Report diagnostics and unsupported feature differences separately from value/schema matches. Native warnings, dropped records, preserved raw records and correctly interpreted features are different claims. Do not count unsupported or unmeasured cases as passes.
5. Run focused uncached maintained tests/lint/build through root's maintained task closure. Record actual checks and source hashes in `docs/ssconvert/xlsx-independent-verification.json`; remove owned disposable logs/fixtures only after reducing captures. Preserve preexisting oracle sources and profiles.

Native graphical rendering, every supported beta namespace, full chart/pivot fidelity, every encryption scheme and full ZIP-bomb equivalence require separate measurements; this procedure's small cohort does not establish these outcomes.

## Execution receipt

The different-agent review captured 30 original native cases against the separately profiled Gnumeric 1.12.61 oracle, then read/exported those same inputs with the shared SDK engine and injected byte I/O. The source hashes were unchanged before/after the final SDK cohort. Original fixture ZIP bytes, exact native diagnostics and generated Gnumeric outputs are retained in `docs/ssconvert/xlsx-independent-verification.json`.

The independent unit suite initially reproduced seven defects, then five additional defects and the native odd-header/footer default-section mismatch. Root repaired reader/integration defects; this reviewer added the declarative 17-table recognition schema and native-matched style/rich-text helper. Final focused checks passed 23 independent/helper tests, ESLint for the four reviewer-owned source/test files, and the ssconvert test TypeScript project. Root owns the maintained uncached cross-workspace build/test/lint and visual integration checks; these focused results do not claim a complete package or release gate.

The historical pre-followup SDK read/write cohort had 29/30 equivalent statuses and 26/30 equivalent diagnostics. These measurements precede the final integration follow-up below and do not describe the current conversion cohort. These are separate metrics, not a 30-case native-fidelity pass. Explicit measured comments, hyperlink, custom filter, margins, scaling, paper/orientation, odd header/footer and page-break records match. Native default metadata/scaffolding differs. Remaining observed duplicate-sheet, invalid-name diagnostics, foreign/strict-root wording and shared-expression export representation differences are recorded alongside unsupported/unmeasured validations, conditional formatting, chart/image/drawing/pivot/extension fidelity, genuine encryption/macros, advanced print/style/locale behavior and malformed-input recovery.

Raw retained XML records are not evidence of functional native import or lossless Excel editing. Reviewer-owned disposable files under `out/ssconvert-xlsx-independent` are removed only after reduction; preexisting oracle sources, binaries and profiles remain untouched.

The complete ssconvert source TypeScript inventory was unchanged before/after this final cohort. Previous read/write capture hashes, cases and differing outcomes remain historical evidence; final conversion records supersede them explicitly. The same 23 focused independent/helper tests passed again. Shared formula export representation and native default scaffolding still differ; all earlier unsupported/unmeasured semantic categories remain unqualified. The follow-up used no host fixture files and its one temporary capture was purged after reduction.
