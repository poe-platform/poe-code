# Live chart graph evidence

The format package now provides titles and rich text, legend layout and font,
category/date/value axes, gridlines, tick labels, plot categories and hierarchy,
series/points, data labels and markers. It reuses the shared text, font, fill,
line, shadow and color engines. All sixteen OOXML chart plot families remain
locally editable, including imported families whose creation is unsupported.
The independent imported chart classifier enumerates all 73 chart enum symbols.

The member ledger records all 372 retained graph API rows, inherited members,
neutral JS signatures, nullable setters, defaults, collection operations and
explicit capability mappings. Owner callbacks are kept off returned instances.
Removed titles and series cannot silently retarget or resurrect; series data
replacement invalidates handles by retained identity/data signatures.
Read-only scalar and point/marker/label/gridline inspection is noncreating;
title, rich-text, font and drawing-property creation retains explicit getter
side effects. CLI list/get continues through noncreating operation readers.

The original graph tests contain 32 cases, including 16 plot-family variants and
three axis types; ten separately authored adversarial review cases cover strict
namespaces, sparse categories, duplicate cache indexes, deleted series, collection
membership/numeric access, and bounded gradient stop XML ownership. They use
in-memory XML and injected callbacks. No publisher document, binary, native
runtime, filesystem access or network request is part of these domain tests.

The complete graph source-case ledger contains 729 entries. It names the original
behavior assertion groups but does **not** claim fixture-for-fixture parity:
the retained inventory has opaque fixture names without their payloads or exact
expected results. Every such entry remains explicitly uncertified at that level.
This limitation does not hide a public member as private or unsupported.

Passed focused verification: chart-model-objects.test.ts (32),
chart-model-review.test.ts (10), chart-model.test.ts (4), and chart command
integration tests run by the root coordinator. Root owns maintained package-wide
checks, common schema/CLI changes, public exports and the atomic local commit.
