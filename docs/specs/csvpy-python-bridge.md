# csvpy PythonSession object bridge

The csvpy JavaScript engine uses `@poe-code/safe-python`'s maintained, synchronous Python interpreter. It does not invoke CPython, import installed csvkit, or evaluate a JavaScript replacement language.

## Supported maintained boundary

- `PythonSession.value` constructs primitive guest values (`null`, booleans, bigint integers, number floats, strings).
- `list` and `tuple` accept session-owned value handles and copy the sequence into interpreter-owned storage. `dictionary` accepts pairs of owned key/value handles and preserves normal guest key ordering and equality.
- `createNamespace`, `exec(source, { globals })`, and `eval` support source-defined Python functions, classes, iterators, generators and retained state. Namespaces expose opaque handles rather than host objects.
- `interactive(source, options)` compiles parser-backed single input and returns `{status: "incomplete"}` without executing unfinished input, or the normal execution result. The caller owns the source buffer, prompts and EOF behavior. Tokenizer/parser metadata identifies open brackets, triple strings and explicit continuations; the parsed AST identifies compound statements requiring a real terminal newline and rejects multiple separate top-level logical statement lines. Semicolon expressions each invoke the scoped default display operation: canonical guest `repr`, explicit output capability, newline, and `builtins._` retention for non-None results. Ordinary exec and called function bodies retain normal expression-discarding behavior. String expressions remain executable rather than becoming module docstrings.
- `registerModule(name, namespace)` wraps the live guest namespace as a real interpreter module and inserts it into this session's import registry. Existing registered modules cannot be replaced through this API. The module receives `__name__` if its namespace has none; other metadata is the caller's responsibility. Namespace and module mutations remain mutually visible. Registration does not make a dotted module's parent a package: callers must register parent modules and explicitly supply guest `__path__` when package behavior is needed.
- `registerModuleAlias(name, module)` adds an import name for an already registered, session-owned module. It preserves module identity and live namespace mutations; it rejects foreign values, unregistered values, existing names, invalid component names, reentry and closed sessions. Registry traversal and registration use the interpreter budget. It grants no ambient module discovery or host-object access.
- `callable(callback)` explicitly injects a positional-argument synchronous host service as a guest callable. Argument handles are frozen as a sequence; their primitive values and kinds may be inspected during the callback. The callback may construct guest primitives/containers and must return an owned value. It cannot reenter source execution, inspect/mutate namespaces, register modules or close the running session. Async/thenable results are rejected as capability failures. Host errors and foreign handles terminate execution; expected CSV failures should be represented as guest data and raised by the source-defined reader. Interpreter operations remain metered, and cancellation is checked when the service returns; injected host code must itself remain bounded and cooperative.
- Input and output capabilities are synchronous and explicit. Python execution uses cumulative allocation/step/depth limits, cancellation, no ambient filesystem, network, randomness, clock or stdin. The owner must close the session; all guest handles are invalidated by `close`.

The bridge regression reproduces the previously missing list/dictionary/module APIs, then exercises class installation in a separate library namespace, a retained iterator over guest rows, import lookup, isolation between sessions, storage ownership, and invalidation. The existing public-session regressions cover cancellation, output/input services, code diagnostics and guest exceptions.

## Qualification and explicit limits

PythonSession implements a Python language/runtime subset rather than the frozen CPython executable. Its existing bundled import library focuses on codecs/encodings; it does not already supply agate, csvkit, `csv`, `code`, `traceback`, datetime, decimal, the full Python standard library, or IPython. Registering a scoped module does not claim any of those implementations are complete. The interactive API provides maintained single-input parsing/execution and default display behavior; it does not provide an imported `code.interact` implementation, a configurable `sys.displayhook`, retained `codeop.CommandCompiler` future-feature state, or exact CPython diagnostic/traceback arbitration. Those require separate qualification against the frozen reference. The existing guest `compile` builtin's extended modes are a separate API; adding `interactive` does not claim complete `compile(..., "single")` support there.

The object bridge does not expose arbitrary host objects or streams to guests. Only explicitly registered callables may cross the service boundary. Source-defined readers can obtain rows lazily through those synchronous callbacks. Asynchronous Python input/output is not supplied by these APIs. The csvpy adapter must qualify any buffering, CSV dialect, Agate object/type, exception, representation, `code.interact` or IPython mismatch independently. Unmeasured cases remain blockers rather than reference passes.

The scoped guest reader implementation lives in `packages/csvkit/src/python/readers.ts`. Reader forwards its raw iterator and read-only `line_num`/dialect properties; guest mutation of `line_numbers` and `header` affects physical row numbering. DictReader has independent CPython fieldnames/rest-cell ordering rather than inheriting the Agate Reader wrapper. The fieldnames getter synchronizes line_num on every access, even after a header was already supplied. Agate exception classes preserve their source inheritance and the FieldSizeLimitError constructor. Config defaults use the frozen `C` locale's `en_US_POSIX`; mutations remain session-local. Canonical `agate.csv_py3`, exception/config modules and top-level config aliases are installed as interpreter objects.

Five complete, selected non-TTY `code.interact` transcripts are compared byte-for-byte in `csvpy.test.ts` against `docs/csvkit/csvpy-object-reference.json`. This qualifies those expressions only. `docs/csvkit/csvpy-public-object-census.json` records the much larger source/native public namespace; its BLOCKED entries are not implemented API claims. See `csvpy-public-object-contract.md` for the library and interpreter blockers.
