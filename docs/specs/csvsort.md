# csvsort 2.2.0 executable contract

The literal engine and exact parser descriptor live together in `packages/csvkit/src/commands/csvsort.ts`. The existing fourteen-name registry and safe-bash opt-in command plugin dispatch this same engine; SDK `run({ command: "csvsort", settings }, context)` uses identical settings and execution.

The compatibility target is csvkit 2.2.0 source archive SHA-256 `147318a8dbaec07c0bbb9291c14b78de5fa32ed3d4a5c2396e52a83c0a30df6b`, interpreted under `darwin-cpython-3.14.2-csvkit-2.2.0` in `docs/csvkit/reference-profile.json` and its hash-pinned runtime lock. No database drivers are used by csvsort. Native measurement is development research only, never a product or canonical-test fallback.

Local flags are `-n/--names`, `-c/--columns`, `-r/--reverse`, `-i/--ignore-case`, `-y/--snifflimit`, `-I/--no-inference`. The exact inherited flag inventory is asserted independently in `csvsort.test.ts`; flags such as exclusion columns and output quoting are absent. In particular `-r` means reverse, `-i` ignore-case, and `-I` no-inference. Header names exit via the common raw helper before table inference, normalization and row materialization.

Normal execution casts the full table using common Agate type inference, selects ordered column indices (all by default), materializes key tuples once, and sorts row indices stably. Reverse reverses key comparison while retaining original order for equal keys. NullOrder sorts after all values ascending and before them descending, independently at each tuple position. Comparisons use canonical arbitrary-precision Decimal strings, Boolean false/true order, date/datetime temporal values and duration microseconds. Decimal NaN raises the measured InvalidOperation only when a selected key comparison reaches it; an unselected NaN or singleton row still serializes. Mixed aware/naive datetime comparison retains the measured TypeError. Output uses common typed CSV serialization and datetime ISO `T` normalization.

Ignore-case uppercases only string keys, leaves original values unchanged, and compares Unicode scalar values. `unicode-upper-profile.ts` contains every nonidentity mapping from CPython 3.14.2 `str.upper()` (Unicode16), including expansions. Host ICU, locale collation, lowercasing and natural sorting do not determine ordering.

Header normalization follows Agate `deduplicate(column_names=True)` in source order, including existing suffixed names and generated unnamed headers. The host optionally injects `columnWarnings: { utilsPath, suppressWarnings }` on CsvkitContext or CsvkitCommandsOptions. `utilsPath` identifies the frozen Agate deployment for exact warning bytes; the source line numbers/text are pinned to Agate1.14.2. Suppression may omit the path. Without suppression or a path, inputs requiring warnings remain explicit status78 blockers. Default filtering deduplicates repeated warning messages within the invocation.

Existing common inference, encoding, sniffing and diagnostic qualification boundaries still apply. Unsupported locales, unqualified verbose traceback deployment, Unicode temporal inference hypotheses and other documented shared limits remain blockers. No complete fourteen-command suite, every type/domain, interactive behavior or release acceptance is inferred from this csvsort cohort.
