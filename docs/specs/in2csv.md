# in2csv source contract

Baseline: csvkit 2.2.0 PyPI source SHA-256 `147318a8dbaec07c0bbb9291c14b78de5fa32ed3d4a5c2396e52a83c0a30df6b`. Reference deployment, CPython, Agate, SQLAlchemy, locale and drivers are frozen in `docs/csvkit/reference-profile.json`. Additional observations in `docs/csvkit/in2csv-reference.json` use its CPython 3.14.2 profile. Workbook fixtures are reference-generated XLSX and the baseline source archive's `examples/dummy.xls`; canonical tests only load frozen bytes into memfs.

The executable remains `in2csv`, among the original fourteen separately registered safe-bash commands. Its existing descriptor retains the upstream help, argument destinations and inherited/redeclared flags; the implementation of source dispatch lives in `packages/csvkit/src/commands/in2csv.ts`. CLI argv and SDK destination settings share this engine. Workbook parsing uses the pinned JavaScript ESM reader `@e965/xlsx@0.20.3`, receives bytes only, and exposes no workbook-writing command. ZIP payload validation uses the existing bounded office-package codec. No subprocess, Python fallback, ambient filesystem, database or network is used.

Format choice is explicit `-f`, nonempty schema, nonempty key, then the source's last-period extension algorithm. Only csv/dbf/fixed/xls/xlsx are recognized directly, json/js imply JSON, and a path with no period implies fixed. GeoJSON, NDJSON and compressed-inner extensions are never inferred. Piped stdin needs an explicit/implied format. Forced formats include exactly csv, dbf, fixed, geojson, json, ndjson, xls and xlsx. ODS and XLSB are excluded.

CSV uses the raw streaming reader only with `-I`, headers present, zero skipped lines and `-y0`. Other CSV paths use the shared Agate table model, header normalization, sniffing and inference. Fixed input uses the schema parser and ignores inference/header/line-number options. JSON/NDJSON flatten ordered records, union columns and run table inference; header/skip-lines options are ignored. GeoJSON follows its separate converter and ignores writer/inference options. DBF uses descriptor fields and Agate's default inference, ignoring csvkit inference/header/skip-lines flags.

Excel `-n` returns names and ignores selection/export options. XLS defaults to its first worksheet; XLSX uses the active tab. `--sheet` is a name, including numeric-looking strings. Only comma-separated `--write-sheets` entries become indices through Python's Unicode isdigit/int semantics; a literal `-` requests all names. All selected side tables are converted before the first side file is opened. Duplicate sheet selections overwrite the table value while retaining its original order. Side indices enumerate the emitted tables from zero; they are independent of `--zero` and worksheet positions. Main stdout drains before side conversion/writes. Named workbooks reopen through injected I/O; streamed workbook bytes are cached as owned input. `--use-sheet-names` changes the filename suffix; the base is source splitext(path), or `stdin`. Output is LF-separated UTF-8 for the frozen locale, independent of input encoding; BOM applies only to stdout, while line numbers restart for every side table. No filename sanitization, collision prevention or rollback is invented.

XLSX dimensions are trusted except explicit reset or the upstream automatic A1 reset. Cached formula values are used. XLS encoding overrides apply to legacy encoded records; Unicode BIFF8 cells do not require an encoding lookup. Other workbook flags retain their source applicability.

The reader receives raw cached serials (`cellDates: false`), which are normalized against native reader semantics rather than displayed format text. XLSX serial zero and positive fractions below one produce time values independently of the date style; the 1900 fake leap day and 1904 epoch follow openpyxl conversion. Elapsed styles produce native duration text. Native datetime headings retain midnight time, while XLS headings expose raw xlrd serials. XLS mixed raw cell types retain their source string conversion instead of uniformly converting styled numeric cells to dates.

OOXML workbook paths are derived from package content types and worksheet relationships; `xl/workbook.xml` is not a mandatory literal filename. The manifest gate accepts the native XML sheet/macro-sheet/template/macro-template main-part types, including names-only reads. XLSB and ODS are rejected with their measured native errors instead of being accepted by the broader JavaScript library. Namespace prefixes do not determine element identity. Bounded streamed SAX parsing records only explicit ISO `t=d` cell values, preserving date/time/datetime provenance otherwise lost by the reader's serial API. Explicit and implicit cell coordinates are supported. ISO lexical fractions follow openpyxl's millisecond truncation. A names-only reopen retains previously admitted ISO cache values for side exports. These observations are frozen in `docs/csvkit/in2csv-workbook-package-reference.json`, with exact argv/SDK and actual safe-bash side-file comparisons. UTF-8 XML is the measured metadata profile; other XML encodings and unusual package/parser structures remain unqualified.

The injected cleanup hook enrolls resources before acquisition. Its optional destination `"invocation"` retains sibling side-file resources when stdout closes; omitted destination enrolls a stdout producer. Both scopes remain registered with invocation cleanup. Side-file writes await each sink write, preserve truncation and earlier partial effects, and share idempotent close completion. XLSX validation consumes every bounded decompressed ZIP entry instead of trusting archive size declarations. GeoJSON admits its complete header against the column limit even without data rows.

Compatibility qualification is limited to measured cases. Unsupported field types, encodings, parser diagnostics, interpreter behavior and shared inference gaps must remain blockers, never counted as successful compatibility cases. See `docs/csvkit/in2csv-validation.md` for outstanding qualification gaps.

Agate converts decoded XLSX datetimes on 1904-01-01 into times when the format contains neither lowercase `d` nor lowercase `y`, under either workbook epoch. This also applies to ISO datetime cells, but not headings. Native time objects force Text inference; numeric/ISO times therefore retain `00:00:00`, while text time strings may infer TimeDelta and elapsed formats retain duration semantics. Twelve native observations covering both epochs and these distinct cell types are frozen in `docs/csvkit/in2csv-workbook-epoch-reference.json`.

Additional user-edge observations in `docs/csvkit/in2csv-user-edge-reference.json` establish fixed-schema error evaluation order, scalar JSON/selected-key non-iterable diagnostics (including JSON non-finite constants), and DBF numeric boundaries. DBF N fields attempt exact integer conversion before floating conversion; F fields always use floating conversion. Outer asterisk padding is removed without discarding interior asterisks. Float spelling preserves signed zero and Python scientific thresholds before Agate inference. Invalid measured ASCII numeric payloads report the upstream bytes diagnostic. Non-ASCII numeric diagnostics and arbitrary malformed DBF structures remain unqualified.
