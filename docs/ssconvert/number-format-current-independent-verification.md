# Independent scientific precision verification

The different-agent review verified 287 original native differential cases: initial cohort 144/144 and independent edge cohort 143/143. Both native exporter invocations exited 0 with empty stderr. Exact fixtures, output bytes, case expectations, source hashes and the dirty candidate revision are captured in `number-format-current-independent-profile.json`. Execute the Markdown procedure in `../plans/ssconvert-formatting-current-review-qa.md` to reproduce them.

The first cohort exposed 56 mismatches after removal of the greater-than-100 precision guard. Division into a binary64 mantissa discarded original input digits; an inherited 128-decimal rejection also disagreed with native output. Seven in-memory tests failed before the rational repair. A subnormal power neighbour then failed before exponent selection changed, and two ordinary power neighbours failed before carry detection stopped coercing an exact decimal mantissa back into binary64.

Scientific output now rounds the original binary64 rational with its decimal exponent once. Exponent selection uses seventeen significant digits, and carry detection checks the rounded decimal integer width. The second cohort also measured GOffice's unsigned-byte printf precision operand: at 256 placeholders the numeric precision wraps to zero while placeholder emission retains 256 decimal places. Native `TEXT(2.5,256 decimal places)` therefore emits `3.` followed by 256 zeroes. The source confirms single-byte operands in `ADD_OP2/ADD_OP3` and `const guchar *prg` execution in GOffice 0.10.61 `go-format.c`; fixed and scientific formatting reproduce that behavior.

The focused maintained formatter/TEXT run passed 192 tests in nine files, including 16 new independent cases. Workspace lint exited 0 and covered ESLint plus source/test TypeScript. Negative checks verified exact output-byte admission and one-less rejection, cancellation reason identity at the twentieth scanning tick, host work failure at the thirtieth tick, and no use of ambient Intl formatting.

These are deterministic semantic measurements, without performance/RSS qualification. Arbitrary locales/custom formats, scientific integer widths of 256 or more, finite-font preserve rendering, and interruption during synchronous BigInt work remain unmeasured or unsupported.
