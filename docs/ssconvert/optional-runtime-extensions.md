# Trusted JavaScript optional providers

`EngineConfig.runtimeFunctions` registers invocation-owner-supplied JavaScript ports. The same config is accepted by safe-bash `ssconvertCommands`; command calculations and direct SDK conversions use the same engine and evaluator. No ambient plugin discovery, native module loading, source-language subprocess or native fallback is introduced.

Import `RuntimeFunction`, `RuntimeFunctions`, `RuntimeFunctionResult`, `snapshotRuntimeFunctions`, `perlSampleFunctions`, `pythonSampleFunctions` and `createPythonSampleFunctions` from the ssconvert public entry. Explicitly provide `runtimeFunctions: { ...perlSampleFunctions, ...pythonSampleFunctions }` to enable the bounded sample ports. Python includes PY_BITAND, PY_PRINTF and PY_CAPWORDS; Perl includes PERL_ADDER, PERL_DATE and PERL_SED. PY_CAPWORDS uses frozen CPython Unicode 16 titlecase, contextual lowercase and whitespace splitting, including U+001C–U+001F. Use `createPythonSampleFunctions({ unicodeVersion: "15.0.0" })` for frozen Unicode 15 casing and `%r` printable-character rules, or `"16.0.0"` for the default profile. The selector changes Unicode rules only; it does not select or execute a Python runtime. Punctuation does not start a new word; a digit at the start keeps subsequent letters lowercase. Scalar booleans, numbers and blanks retain the activated loader's Python AttributeError results; spreadsheet errors propagate. Text stops at the first NUL, matching native C-string acquisition; visible unpaired UTF-16 surrogates refuse before output. Invalid UTF-8 byte strings retain an explicit refusal: the activated native Python loader crashes when such acquisition leaves a NULL tuple item. Wider profiles and remaining loader/service boundaries still require qualification. These bindings do not execute the original loaders or arbitrary source-language modules. Qualified cohorts and remaining obligations are recorded in the gap-resolution ledger.

A provider maps canonical uppercase function names to `{ signature, implementation(args, host) }`. Signatures accept `f`, `s`, `b`, `E`, `r`, `A`, `?` and one optional `|` separator in the shared typed argument convention. `snapshotRuntimeFunctions` validates and freezes a registration; the engine and virtual command also capture registrations at construction. The evaluator applies its existing argument evaluation, coercion, error propagation and array iteration before calling the implementation. Ports return a `RuntimeFunctionResult`: a scalar `CellValue`, a rectangular nonempty `{ kind: "matrix", rows }` of scalar values, or a `{ kind: "range", sheets, firstRow, lastRow, firstColumn, lastColumn }` reference. Matrix rows use the evaluator's row orientation; a native Python list uses columns and must be transposed by its explicit port. The engine validates, copies, freezes and bounds scalar/matrix data through workbook admission; sparse/ragged/empty arrays and accessors are refused. Matrix axes use the supported workbook maximum (16,384 columns and 16,777,216 rows), independently of the legacy default sheet grid; configured cell budgets still apply. Reference members must be actual sheets of the current host workbook or its admitted detached sheets, with valid in-bounds coordinates and bounded total area. Foreign sheets with matching public IDs are refused. Returned range dependencies remain in the in-memory workbook model so later dirty precedents trigger recalculation. Formula recalculation after a format checkpoint rebuilds them; Gnumeric XML does not serialize the computed dependency table. Raw Python RangeRef/CellRef relative axes and pointer representation require separate source-language port qualification. The active RangeRef.get_tuple method returns two CellRef wrappers; CellRef exposes col,row,sheet,col_relative,row_relative, while its get_tuple method is commented out in the released source. Built-in/intrinsic collisions are rejected rather than replaced. Registration is snapshotted; functions are not discovered from workbook input. Namespaces belong to the configured engine/invocation and are not process-global. Cancellation/work admission occurs before and after calls; providers must cooperate with `host.tick()` inside loops and explicitly respect `host.context.signal`.

The host object exposes the current workbook, evaluation position and explicit capabilities. Providers are **trusted host JavaScript**, not an untrusted-code sandbox: a supplied closure can access whatever its author captures, block without ticking or modify host-visible data. The owner must supply cooperative, deterministic, invocation/realm-owned implementations and explicit mocked or replay-compatible external capabilities. This contract does not make arbitrary third-party JS safe or replayable. No global registry, clock, filesystem, network, interpreter or configuration is granted implicitly.

`createDatabaseFunctions(query)` supplies optional EXECSQL and READDBTABLE registrations through the same `runtimeFunctions` config. The cooperative host receives a frozen `{ dsn, username, password, sql, readOnly: true }` request and the calculation host; READDBTABLE constructs `SELECT * FROM <table>` exactly as the pinned GDA source does. String arguments stop at NUL. Return `{ kind: "recordset", rows }` with preconverted spreadsheet scalar cells, `{ kind: "empty" }`, `{ kind: "connection-error" }`, or `{ kind: "query-error", message }`. Empty records become blank, connection errors retain the source-defined message, query diagnostics remain exact strings, and a row count at or above the current sheet maximum returns `Too much data returned`. Shared runtime admission bounds, owns and freezes rectangular results. The host owns connection selection, read-only enforcement, single-statement SQL parsing, execution, cancellation and database-type conversion; this helper supplies no SQL parser, database engine, ambient credentials or GTK dialog. A host may maintain its own explicit invocation-owned connections. Native GDA first-connection GUI behavior and typed/date/formatted results remain separately unqualified.

Workbook format extensions use the existing explicit `EngineConfig.codecs` registry; these are distinct from formula functions. The explicit `EngineConfig.datasource` capability supplies invocation-owned sample datasource transports: `open(context)` returns a session transport, `poll(signal)` returns a finite available byte batch and `close()` releases it. Default successful solver processing reads one batch before applying results; custom solvers can service `context.datasource.poll(book)`. `ATL_LAST` retains tag values and partial records, updates watched cells and their dependents, and removes edited/deleted tag links. Ordinary conversion opens/closes without polling. Undefined transport stays unfilled. This capability is separate from formula registration; source-language array conversions, other loader lifecycles, diagnostic streams and environment effects still require appropriate ports and qualification. Wider native datasource timing/numeric/raw/lifecycle behavior remains in the ledger. GOffice rendering/plot/image/component extensions also require explicit JS ports through the appropriate rendering/service APIs. A native/Python/Perl/Guile plugin must be ported; its module name is not accepted as a provider. There is no finite predeclared feature list for arbitrary external plugins.

The pinned source census, finite profile definitions and unresolved capabilities are recorded in optional-runtime-extension-coverage.json and reference-profile.json. Profiles are specifications until exact optional activation, dependency identities and command differential observations are captured. Implemented unit behavior is not matching-profile native coverage or full parity. The Python glossary is a file saver, not GUI-only; Excel's shipped plugin manifest contains format services, while the commented excelplugins build entry has no shipped service manifest. GUI service declarations alone do not qualify module initialization as having no command effect. Guile's configure block is disabled in the release, while external Guile ports remain an open extension boundary.
