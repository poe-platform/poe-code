# @poe-code/maestro-tui

Read-only TUI package for browsing maestro task lists.

## Public API

- `runMaestroTui()`
- `buildMaestroExplorerConfig()`

These APIs are stubs for the initial package scaffold. Later tasks will wire them
to maestro workflow loading, task list discovery, and the design-system explorer.

## Configuration

This package does not introduce any config options yet.

## Environment Variables

This package does not introduce any environment variables yet.
