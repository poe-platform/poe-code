# `safe-bash-command-imagemagick`
`magick input.xwd output.png` decodes version-7 X11 window dumps with 8-bit palettes or 24/32-bit true-color pixels, preserving scanline padding and byte order.

`-colorspace HCL` and `HCLp` convert RGB into hue, chroma and luma for channel operations; PNG output converts back to RGB.

ImageMagick (`magick`, `convert`, `mogrify`, `composite`, `montage`, `compare`, `identify`) command-line tools for `safe-bash`, powered by `@poe-code/image-ast`. Read saved MPR registers with frame selectors (`mpr:Seq[1]`, `mpr:Seq[2-0]`) or crop geometry (`mpr:Saved[1x1+1+0]`); ranges preserve the requested order. `.xwd` and `XWD:` outputs write version-7, 24-bit RGB XWD for true-color or indexed inputs, including `-write`; alpha is omitted.

`-copy 2x1+0+0 +2+1` copies a pixel rectangle within each image. Overlapping copies follow native scan order, so earlier writes can become the source of later pixels. Geometric transforms (`-roll`, `-flip`, `-flop`, `-transpose`, `-transverse`, `-rotate`) require a current image: place them after the input, as in `magick in.png -roll +1+1 out.png`. Without a current image they fail without replacing the output.

`+remap` builds a shared palette across loaded images using the current `-colors` limit and dithering settings. `pattern:NAME` renders the requested built-in ImageMagick tile, including stripes, crosshatches, bricks and gray density patterns. Use `-size 32x17 pattern:vertical out.png` to repeat it across a canvas; without `-size`, the native tile dimensions are used. Unknown names fail without replacing the output.

`-seed` preserves 64-bit integer precision, including negative seeds, and reads the leading decimal integer: `1e1` uses 1, `0x11` uses 0, and `17.5` or `17x2` uses 17. Invalid seeds fail without replacing the output. `+seed` takes no argument and resets the seed to the current Unix timestamp in seconds; a later `-seed` overrides it, including in `mogrify`. `-seed 123 -size 64x64 plasma:fractal out.png` creates reproducible plasma noise. Use `plasma:red-blue` for a color gradient with plasma displacement; changing the seed changes the pixels. `in.png -seed 17 -spread 2 out.png` randomly samples nearby pixels using the chosen radius, interpolation and virtual-pixel settings; radius zero selects the native automatic radius.

PNG iTXt comments preserve the actual UTF-8 text when a translated keyword is present. This intentionally differs from ImageMagick 7.1.2-31/35, which reads and rewrites the comment `hello` with translated keyword `Title` as `itle`. Language tags alone do not change the comment. PNG round trips and `-sample` preserve XMP profile bytes; `-thumbnail`, `-strip`, `+profile xmp`, and `+profile "*"` remove XMP.

Legacy PNG Latin-1 `tEXt` comments are rewritten as valid UTF-8 `iTXt`: `café` ends in bytes `c3 a9`. This intentionally differs from ImageMagick 7.1.2-31/35, which copies byte `e9` into `iTXt` despite its UTF-8 requirement. The character is preserved; ASCII comment bytes agree.

Use `-adaptive-resize GEOMETRY` for native mesh interpolation, preserving scaled virtual canvas dimensions and offsets. Use `-interpolative-resize GEOMETRY` for bilinear resizing, or select `nearest-neighbor`, `integer`, `average`, or `bilinear` with `-interpolate`; scaled virtual canvas dimensions and offsets are preserved. Use `-filter` to select a resize or non-right-angle rotation filter, including `Lanczos`, `Lanczos2`, `LanczosSharp` and `Lanczos2Sharp`; `+filter` clears that selection and restores automatic default filtering. `-filter Point -thumbnail WxH` applies thumbnail reduction stages before selecting pixels; ordinary `-filter Point -resize WxH` selects pixels directly. Rotation defaults to Robidoux; Point uses bilinear interpolation by default, and right-angle rotations preserve pixels and indexed color without resampling. Arbitrary rotations promote indexed images to direct color before subsequent channel operations. Rotation and shear fill exposed pixels using the image’s stored background color unless `-background COLOR` overrides it; images without a stored background use white. Use `-define filter:blur=1.5` to widen the filter, `-define filter:lobes=2` to select its lobe count, or `-define filter:support=1.5` to override its support radius. Support takes precedence over lobes; `+define filter:blur` (or the corresponding key) clears an override. Cubic-family filters include `Catrom`, `Cubic` (also `Spline`), `CubicSpline`, `Hermite`, `Quadratic`, `Robidoux` and `RobidouxSharp`, each using its native resize weights. `Gaussian`, `Jinc`, `Lagrange`, `Sinc`, `SincFast`, `MagicKernelSharp2013` and `MagicKernelSharp2021` also use their own filter weights and support. Tune BC cubic weights with `-define filter:b=B` and `-define filter:c=C` (an omitted coefficient follows `B + 2C = 1`), or Gaussian width with `-define filter:sigma=S`. `-define filter:window=Hann` selects a windowed Sinc filter; supported windows are Box, Bartlett, Blackman, Bohman, Cosine, Hamming, Hann, Kaiser, Parzen, Welch, Sinc and SincFast. `+define filter:b`, `+define filter:c`, `+define filter:sigma` and `+define filter:window` clear individual overrides.

Montage defaults to centered tiles in 120×120 cells, shrinking oversized images without enlarging smaller ones, with 4-pixel horizontal and 3-pixel vertical padding. Use `-geometry` to override the tile dimensions and spacing. `-frame 2x2+1+1` sets frame dimensions and bevels, and `+frame` removes frames. Grayscale frames use the matte’s blue component for gray and preserve matte alpha, even with `PNG32:` output. `-mode Frame` adds beveled frames and soft shadows; `-mattecolor` sets the frame color, and `-mode Unframe` restores ordinary tiles. Use `-shadow` to add shadows without frames and `+shadow` to disable them. Montage supports `-label` for subsequent images and `-set label` for images already read. Labels and titles use bundled bitmap glyphs. Explicit `-font` selections return an unsupported-font error because host fonts and custom font files are unavailable.

`-shade 30x45` renders grayscale directional relief from image intensity, with azimuth and elevation in degrees.

`-enhance` reduces noise with a weighted 5×5 filter that averages similar colors while retaining sharp differences. `-statistic Maximum 3x3` applies a local maximum filter. Invalid statistic geometry such as `x3` or `bad` fails without replacing the output. Use `-morphology Dilate:2 Diamond:1` to run two dilation passes, or `Erode:2` for two erosion passes. Nonnegative integer method counts also apply to compound methods and convolution; zero leaves the image unchanged. `Smooth` applies opening followed by closing. Compound methods repeat each primitive in order (`Open:2` erodes twice, then dilates twice). `DilateIntensity`, `ErodeIntensity`, `OpenIntensity`, and `CloseIntensity` (also `DilateI`, `ErodeI`, `OpenI`, and `CloseI`) select whole pixels by Rec.709 intensity instead of taking separate channel extrema. Negative convergence counts are unsupported. Explicit flat kernels such as `3x1+0+0:1,nan,1` preserve their dimensions and origin; `nan` cells are excluded. `HitAndMiss` matches explicit kernels with `1` for foreground, `0` for background, and `nan` for ignored cells; for example, `3x3:0,0,0,0,1,0,0,0,0` detects an isolated white pixel. `Ring:inner,outer` selects pixels outside the inner radius and within the outer radius, leaving the center out. `-morphology Distance Manhattan:1,64!` computes an interior Manhattan distance map; background pixels stay black. Manhattan radius 1 supports the default Q16 step of 100, an explicit step, or `!` scaling by `65535 / (scale + 1)`. Other distance kernels are unsupported. `Thicken` adds hit-and-miss matches while preserving existing foreground; `Thinning` subtracts them using explicit `0`/`1`/`nan` kernels or the four sequential `Edges` kernels.

## Quickstart

```ts
import { Shell, createMemoryFileSystem } from "@poe-platform/safe-bash";
import { imagemagickCommands } from "@poe-platform/safe-bash/commands/imagemagick";

const fs = createMemoryFileSystem();
const shell = new Shell({ fs }).use(imagemagickCommands());

await shell.exec("magick -size 120x80 xc:#3b82f6 -resize 50% /banner.png");
const info = await shell.exec("magick identify -format '%m %wx%h' /banner.png");
console.log(info.stdout); // PNG 60x40
```

Read and write XBM C byte arrays with least-significant-bit-first pixels and byte-padded scanlines, including widths that are not multiples of eight. QOI destinations (`out.qoi` or `QOI:out.bin`) preserve 8-bit RGB and RGBA samples, including colors under fully transparent pixels.

Read native ImageMagick pixel enumerations by signature or with `txt:input.dat`. RGB and grayscale samples preserve alpha and 16-bit precision. Concatenated enumerations produce images in order: `magick txt:input.dat out-%d.png`; use `txt:input.dat[1]` to select the second image.

ICO and CUR inputs read images in directory order, including PNG and uncompressed DIB entries with transparency. Use `icons.ico[1]` to select the second image, `icons.ico out-%d.png` to extract all images, or `icons.ico -append strip.png` to stack them.

ICO output joins input images in directory order, preserving their dimensions and transparency. `.ico`, `.cur`, and `ICO:` write an ICO container with 32-bit DIB entries (1–256 pixels per dimension). Use `+adjoin` or a scene filename pattern to write separate icons. `-define icon:auto-resize=64,32,16` derives square icons from the first input image in the requested order; omit the value for standard sizes from 256 down to 16, or use `+define icon:auto-resize` to clear it.

BMP output defaults to a 124-byte header. Use `BMP2:out.bmp` or `BMP3:out.bmp` for 12-byte or 40-byte headers; `-define bmp:format=bmp2|bmp3|bmp4` also selects the version. Coder prefixes take precedence over the define. Use `-define bmp:subtype=RGB565|RGB555` for opaque 16-bit BMP output or `ARGB4444|ARGB1555` for 16-bit output with alpha. Indexed BMP output supports `-compress RLE` (8-bit BI_RLE8) and `-compress None`; BMP2 remains uncompressed.

GIF rewrites retain ICC and opaque application profiles on their original frames; `-strip` removes them. Use `GIF87:out.gif` to write GIF87a without transparency, timing, loop or comment extensions. WebP output preserves every frame, delay and loop count, including `-write animation.webp`. WebP uses lossy encoding controlled by `-quality`; quality 100 defaults to lossless. `-define webp:method=0..6` controls lossy encoding effort (default 4); higher methods sample more blocks to optimize coefficient coding without changing decoded pixels. `+define webp:method` restores the default. Use `-define webp:use-sharp-yuv=true` for sharp RGB-to-YUV conversion in lossy output; alpha is preserved. False or `+define webp:use-sharp-yuv` restores the default conversion; lossless output is unaffected. Use `-define webp:target-size=1200` for an approximate lossy byte target and `-define webp:pass=6` to bound the quality search (1–10 passes, default 6 when targeting size). Dimensions and alpha are preserved; targets below the minimum encoded size can be exceeded. A zero target or `+define webp:target-size` disables the search; explicit lossless output is unchanged. Override either mode with `-define webp:lossless=true` or `false`, and remove the override with `+define webp:lossless`. Use `-define webp:alpha-quality=20` to reduce alpha precision independently of RGB quality in lossy WebP (0–100, default 100); `+define webp:alpha-quality` restores full precision. Use `-define webp:alpha-compression=0` for raw alpha storage or `1` (default) for compressed alpha; both preserve alpha precision. `+define webp:alpha-compression` restores compression. Use `-define webp:exact=true` to preserve hidden RGB in fully transparent pixels; the default discards it without changing alpha or visible colors.

Truecolor GIF output uses Riemersma dithering by default. Select `-dither FloydSteinberg` for Floyd–Steinberg, or `-dither None` / `+dither` to disable dithering, including intermediate `-write` outputs.

Use `-transparent-color color` to choose the transparent GIF palette color without changing opaque pixels or which pixels are transparent.

Lossless animated WebP inputs read every frame in order with their delays and loop count. Use `animation.webp out.png` to extract PNG frames or `animation.webp[1] out.png` to select the second frame.

Use `APNG:input.apng` to read all animation frames with their delays, blending and disposal; for example, `magick APNG:input.apng out.gif` or `magick APNG:input.apng -append strip.png`. An unprefixed PNG input still reads only its default image.

`-set filename:key still` with `v%[filename:key].png` or `v%[filename:key].gif` writes each frame to its resolved path, including with `-write`. Frames sharing that path overwrite it in order, leaving the last frame. Plain GIF output still joins frames into an animation. Unsupported percent tokens in animated GIF names keep their literal text and receive the starting scene suffix (`v%Q-0.gif`, or `v%03X-15.gif` with `-scene 15`).

`-define filename:literal=true` preserves scene placeholders such as `%d` in output filenames, including `-write`. Multiple PNG frames receive numeric suffixes (`frame%d-0.png`); joined GIF frames use one file (`frame%d-0.gif`). `+define filename:literal` or `-define filename:literal=false` restores placeholder expansion. Use `-set filename:key '%s' 'frame%[filename:key].png'` to name each frame by its scene; property values also support image substitutions such as `%w` and `%h`, including with `-write`.

Output parent directories must already exist, including directories selected with `mogrify -path`. Mogrify expands quoted filename patterns (`*`, `?`, and character classes such as `[ab]`) against the command filesystem, including literal SDK arguments. Unmatched patterns fail; parent directory names remain literal.

Conversion accepts `-extract 2x2+1+0` to crop subsequent inputs while preserving their original page; dimensions alone (`-extract 2x2`) resize them. Earlier images remain unchanged, and `+extract` clears the setting before later reads. Conversion accepts `-quiet` to suppress subsequent warnings and `+quiet` to restore them; errors remain visible. A filename crop such as `input.png[1x1+4+4]` that misses the image warns with the input filename, writes a transparent white 1×1 image, and succeeds. `-regard-warnings` and `+regard-warnings` are accepted, and an empty `-trim` still writes its 1×1 output and succeeds.

Use `ftxt:out.dat` or `out.ftxt` for plain pixel channel rows with Q16 values, or `ftxt:-` for stdout. Customize rows with `-define 'ftxt:format=\x/\y=\c\n'`; `+define ftxt:format` restores the default `x,y:channels` lines.

`+append` and `-append` retain the first image’s comment, label and named text properties. `-extent` retains the source image’s density, resolution units and text properties, including its comment. Use `-comment text` or `-label text` before an input to set its text metadata when it is read; settings after an input leave that image unchanged. Use `-set comment 'width=%w'` to write an expanded comment to PNG, JPEG, GIF or TIFF. PNG also stores named text properties such as `-set label` and `-set asset`. Wildcard lookups such as `%[no*]` expand stored properties into sorted `key=value` lines, each ending with a newline; no matches produce an empty string. Property names expand against the current image too: `-set '%[note]' copied` writes `original=copied` when `note` is `original`. Use `-define png:preserve-colormap=true` to retain an indexed PNG’s palette order, bit depth and pixel indices. Valid compressed PNG iTXt comments are preserved, including when language and translated keyword fields are empty. This intentionally differs from ImageMagick 7.1.2-35 Q16-HDRI (also observed in 7.1.2-31), which drops those comments on read and rewrite; the equivalent uncompressed comments survive in both.

Use `identify -format '%#' image.png` or `magick image.png -format '%[signature]' info:` to compute the ImageMagick pixel signature. Both tokens produce the same SHA-256 digest, independent of comments and page metadata. `%[size]` reports `0B` in `info:` output and the input byte count in `identify`; `%b` and `%B` retain the input size in either context. Use `identify -format '%[bounding-box]' image.png` for the foreground bounds as `left,top right,bottom`, with exclusive right and bottom coordinates in the raster. An empty bound repeats the image width and height (`3,2 3,2` for a uniform 3×2 image). Use `magick animation.gif -format '%T/%D/%c;' info:` to report each frame’s delay in centiseconds, disposal name and comment. Set each frame’s delay with `-set delay '%[fx:t+10]'`, where `t` is its index; `-set delay '%T'` preserves its existing delay. The input setting `-delay '%[fx:t+10]'` expands once before reading subsequent images. Undefined FX identifiers, including bare `%[fx:entropy]`, return a nonzero exit status; use assigned variables or supported FX symbols. Use `%[entropy]` for normalized image entropy, averaged across selected channels (`-channel R` selects red; `+channel` resets). Invalid conversion channel masks fail without replacing the destination, including mixed masks such as `R,unknown`. Use `Red,Blue` or `R|B` to select red and blue. Conversion channel names are case-insensitive whole tokens: `Green,Alpha` selects only green and alpha, and `All,Alpha` selects RGBA. `Cyan/C`, `Magenta/M`, and `Yellow/Y` select R, G, and B respectively; `Gray` and `Hue` select R, `Saturation` selects G, and `Lightness` selects B. Each channel is normalized by its distinct sample count; constant channels contribute zero. Use `%[fx:kurtosis]` and `%[fx:skewness]` for image distribution statistics, or append a channel selector such as `%[fx:kurtosis.r]` for red. Constant channels return zero; `%[fx:entropy.r]` is invalid.

Use `+set comment` (or another property name) to remove that property from the current images while preserving other properties.

`-level` and `+level` require a current image; put the input before the operator. An empty image stack returns exit status 1 and leaves the destination untouched. `-level '25%,75%!'` applies inverse levels, equivalent to `+level '25%,75%'`; an optional gamma is preserved (`-level '25%,75%,2!'`). `-level-colors 'black,white'` expands color endpoints to the full range; `+level-colors` maps into those endpoints. Both honor `-channel`, including alpha. `-depth 4` quantizes existing pixels to 16 channel levels (for example, `#c8591e` becomes `#cc5522`); `-set depth 4` changes the image depth property without quantizing pixels or adding a PNG text key. PNG output coders select indexed 8-bit (`PNG8:`), 8-bit RGB/RGBA (`PNG24:`/`PNG32:`), or 16-bit RGB/RGBA (`PNG48:`/`PNG64:`). `PNG00:` retains the image depth and color mode. After `-alpha copy`, ordinary PNG preserves intensity-derived alpha, while `PNG32:` and `PNG64:` make alpha opaque; add `-alpha activate` to preserve copied alpha with those coders. `-alpha remove` preserves 16-bit compositing precision over the selected background, including for statistics and `PNG48:` output; use `PNG24:` for rounded 8-bit RGB. `-alpha associate` and `-alpha disassociate` preserve 16-bit RGB precision for `PNG48:` output and round to 8 bits for `PNG32:`. `-alpha off` disables alpha without blending the colors. Ordinary opaque 8-bit RGB output uses an exact indexed palette when it has at most 256 colors, with the smallest matching bit depth. For ordinary PNG output, `-define png:color-type=6` requests RGBA even when every pixel is opaque; invalid color types warn and use the default encoding. Prefixes select the encoder and are removed from the destination filename, including `-write` and stdout destinations.

Use `-encipher key.txt` to produce pixels that native ImageMagick can recover with `-decipher key.txt`. Use `magick cipher.png -decipher key.txt recovered.png` to recover native ImageMagick ciphertext with the same passphrase-file bytes. For RGB PNG output, use `-define png:color-type=2` to prevent palette conversion from changing the encrypted samples. Keep the original sample depth and channel layout when saving encrypted images.

PNG and JPEG preserve embedded ICC profiles. `+append` and `-append` retain only the first image’s ICC profile. Use `-profile color.icc` to attach an ICC profile to an untagged image, `+profile icc` to remove it, or `+profile '*'` to remove profiles while keeping text properties. `-strip` removes both profiles and text properties. Converting between different ICC profiles is unsupported and returns an error.

`-swirl`, `-implode`, and `-wave` weight interpolated RGB by alpha, including transparent virtual pixels. They support `-interpolate spline` with native cubic B-spline smoothing, retaining premultiplied RGB. They support `-interpolate blend`, selecting one, two, or four neighbors using quarter-pixel boundaries and weighting RGB by alpha. All three accept colon ratios: `3:4` produces the same pixels as `0.75`. They require a current image; placing them before the first input or after deleting all images fails without replacing the destination. `-interpolate average4` aliases `average`; `average9` and `average16` sample 3×3 and 4×4 neighborhoods for all three warps. Swirl and implode preserve pixels outside their effect ellipse. Implode also preserves original pixels when large strengths exceed native pixel-cache coordinate limits. Both default to edge virtual pixels; `-background` alone does not change that sampling. `-wave` honors `-interpolate nearest-neighbor|integer|bilinear|average|mesh|catrom`, including alpha and 16-bit samples; `+interpolate` restores bilinear sampling. Swirl and implode honor `-interpolate mesh|nearest-neighbor|integer|average|bilinear|catrom`; `+interpolate` restores bilinear sampling. Catrom uses a 4×4 Catmull–Rom kernel and preserves native premultiplied RGB interpolation. Mesh selects triangles by luminance and divides interpolated RGB by alpha. `-wave 3/7` and `-wave 3,7` are equivalent to `-wave 3x7`; swirl and implode use the first value with either separator. It defaults omitted amplitude to 0 and omitted wavelength to 1 (`-wave 3` means `3x1`; `-wave x4` means `0x4`). It preserves native grayscale background handling, including PNG background metadata. Wave resamples external write masks with the image and preserves native RGB alpha activation for PNG32/PNG64 output. Use `-virtual-pixel background` to retain a colored `-background` on grayscale input. `-virtual-pixel` supports horizontal/vertical tiling (`horizontal-tile`, `vertical-tile`), checker tiling (`checker-tile`), and edge-filled axis tiling (`horizontal-tile-edge`, `vertical-tile-edge`). Axis and checker gaps use `-background`. Sequence evaluation extends smaller images using `-virtual-pixel`; the default repeats edge pixels, and `+virtual-pixel` restores that default. `-statistic` also uses the selected virtual pixels for neighborhoods crossing the image border.

`-colors` weights reduced palette RGB by alpha while averaging opacity by pixel count. Fully transparent source colors are grouped as transparent black before palette reduction, even when the palette has spare slots. `-remap` uses alpha-weighted color comparisons for palettes with transparency. Remapped images keep the full reference palette, including unused colors, for subsequent `-cycle N` operations. `-remap` honors `-define dither:diffusion-amount=50%` (or `0.5`) for Floyd–Steinberg and Riemersma dithering. Use `0%` to disable error diffusion; `+define dither:diffusion-amount` restores full diffusion.

`-random-threshold 25x75%` thresholds each selected channel independently. Omit `-seed` or use `-seed -1` for fresh randomness; other integer seeds, including `0` and `-2`, produce repeatable results. Grayscale images use one gray channel and stay monochrome, with alpha thresholded separately. Bounds accept percentages or Q16 values; a single bound uses the same minimum and maximum. Ranges accept `x`, `/`, or `,` separators and trailing offsets (`20x80%+1+2`). Omitted bounds work too: `x80%` equals `80%`, and `20x%` equals `20%`. Colon ratios normalize to a first bound divided by the second and an upper bound of one (`20:80` means `0.25x1`). Both `-random-threshold` and `-range-threshold` expand image properties, options and FX operands for each current image, such as `-random-threshold '%[fx:20]x80%'` and `-range-threshold '%[fx:10],30,60,90%'`. Range thresholds accept abbreviated bounds (`10%`, `10,30%`, `10,30,60%`) and slash separators (`10/30/60/90%`); missing bounds inherit the preceding bound. Only the first `x` separates bounds, so `10x30x60x90%` behaves like `10,30%`. Extra fields after the fourth bound are ignored.

`-color-threshold '#800000-#ff2020'` creates an opaque black-and-white mask for an inclusive color range, including alpha by default. Use `-channel RGB` to ignore alpha when selecting pixels. `-auto-threshold OTSU|Kapur|Triangle` computes a histogram-based black-and-white mask. Read the computed percentage with `-format '%[auto-threshold:threshold]' info:`. `-black-threshold` and `-white-threshold` promote indexed inputs to direct color, including neutral cutoffs (`0%` and `100%`, respectively), so later channel selections apply to individual pixels.

`-ordered-dither` applies the built-in ImageMagick threshold, checkerboard, ordered, halftone and circle maps (including their aliases). Append a level count, such as `o8x8,4`, to quantize each channel to that many levels; `-channel` selects the channels to change. Map names and levels expand image properties, options and FX expressions for each input image, such as `-ordered-dither '%[option:matrix],%[fx:w/2]'`. An empty first count (`o8x8,`) keeps the default two levels. Channel overrides accept commas or spaces (`o8x8,3,4,5` or `o8x8,3 4 5`); a trailing comma after a count disables dithering for the next channel. Use `-channel 'All,!Alpha'` to change every channel except alpha; exclusions remove earlier selections, so `-channel '!Red'` selects none. Use commas or pipes between channel names (`-channel 'Red, Blue'` or `-channel 'Red | Blue'`); whitespace alone ends the name, so `-channel 'Red Blue'` selects only red. `-channel Default` includes alpha for Polynomial functions and sigmoidal contrast; use `-channel RGB` to preserve alpha. With `-threshold`, `Default` and `+channel` apply one intensity mask to RGB and alpha; explicit `RGB` or `RGBA` thresholds each selected channel independently. `-threshold` cutoffs expand image and option properties such as `%[cut]` and FX expressions such as `%[fx:QuantumRange/2]` for each image. Both `-sigmoidal-contrast` and `+sigmoidal-contrast` accept colon ratios: `6:25%` is equivalent to `0.24x1%`. A lone percentage such as `10%` also scales the default midpoint; use `10` or `10x50%` for strength 10 at the midpoint. Unsupported maps return an error. `-remap palette.png` uses Riemersma error diffusion by default; use `-dither FloydSteinberg` for Floyd–Steinberg or `+dither` to disable diffusion.

Use `-region WIDTHxHEIGHT+X+Y` to limit subsequent pixel edits, including `-clut` and `-hald-clut` color lookups, to a rectangle. Placement follows `-gravity`, and rectangles are clipped to the image. `-flip` and `-flop` mirror the whole image and move the active region with its pixels. `-transpose` and `-transverse` move the region with the pixels so subsequent edits follow the selection. Use `+region` to restore edits across the whole image.

Use `-write-mask mask.png` to restrict subsequent pixel edits on the current images: black permits edits, white protects pixels, and gray blends the result. Lookup operations `-clut` and `-hald-clut` honor the source image’s mask, including protected 16-bit samples. `-flop`, `-crop`, and `-roll` move the mask with the pixels so later edits protect the correct coordinates. `-crop 2x2@` divides each raster into a grid, honoring `-gravity` for tile overlap while preserving page offsets and output order. Offset-only crops such as `-gravity center -crop -2-1` use the virtual page dimensions after `-repage`. `-crop 16:9` fits the aspect ratio to each input and emits tiles; add offsets (`-crop 2:1+0+0`) for one crop. Percentage crops with defined gravity, such as `-gravity center -crop 50%`, select one region without requiring offsets; unset gravity (`+gravity` or `-gravity none`) keeps percentage tiling. `-crop '3x2<'` preserves the full image when both requested dimensions are smaller than the raster. An explicit bang crop such as `-crop '3x2+1+1!'` uses the requested viewport as its output page, with offsets relative to that viewport, including clipped or missed crops. `-crop` warns when a rectangle touches the right or bottom edge without containing pixels, preserving the full image and successful exit status. Fixed-size crop tiles start at the virtual canvas origin, intersect the positioned raster, and stop with a warning at an empty right or bottom edge while retaining earlier tiles. A filename crop whose width and height equal the raster keeps the full image and page regardless of offsets (`image.png[3x1+4+4]` for a 3×1 image), including palette inputs to `-remap`; explicit `-crop` still applies the offsets. Use `+write-mask` to remove the mask. The legacy `-clip-mask mask.png` and `+clip-mask` spellings are also supported. Missing mask files return an error.

Use `-interpolate nearest-neighbor -filter point -rotate ANGLE` to rotate using the nearest source pixel. `+interpolate` restores the default interpolation. Rotation angles expand image properties and FX expressions, for example `-rotate '%[fx:w*10+20]'` or `-set option:turn 90 -rotate '%[turn]'`.

Unknown image formats are discarded in bounded chunks before reporting the existing diagnostic, preserving read failures and cancellation. `identify -format '%@' image.png` reports trim bounds without changing the image or its canvas dimensions; a uniform image reports `0x0+width+height` with a geometry warning.

`%S` reports the default scene setting (`2147483647`), independently of the current frame (`%s`) and image count (`%n`).

`identify +format` restores the default description for subsequent images; earlier images keep their format. Nested image properties expand before formatted FX arithmetic, so `identify -format '%[fx:%[width]*2]' image.png` prints twice the image width.

Unknown properties such as `%a`, `%?`, and `%[missing_demo_property]` expand to an empty string and report an `unknown image property` warning; identify still exits successfully.
Empty or unclosed bracket properties fail without emitting the formatted text. Escaped properties such as `%%[width]` remain literal text.

Formatted `%[minima]` and `%[maxima]` (also `%[min]` and `%[max]`) use Q16 quantum units (0–65535); `%[fx:minima]` and `%[fx:maxima]` use normalized values. On a single image, FX statistics accept the explicit `u.` image qualifier, including channel suffixes: `%[fx:u.mean]` equals `%[fx:mean]`, and `%[fx:u.mean.r]` equals `%[fx:mean.r]`. Add `-moments -verbose` for channel and overall centroids, ellipse measurements, and Hu invariants. `-define identify:locate=maximum` reports each channel’s maximum and pixel coordinates in row order; `-define identify:limit=N` limits coordinates per channel (0 or omitted means all). `-define identify:convex-hull=true -verbose` reports the foreground convex hull and minimum-area bounding box. Format properties `%[convex-hull]` and `%[minimum-bounding-box]` report their coordinates directly, including point order and trailing spaces; solid images produce empty values and unknown-property warnings. `-precision digits` sets significant digits for formatted statistics and FX expressions (default 6). |

The workspace entrypoint exports `imagemagickCommands()` for plugin registration,
`createImagemagickCommands()` for the command collection, and
`createImagemagickCommand()` for a single command. Each accepts an optional
`ImagemagickCommandsOptions` object; existing factory names remain available.
`createImagemagickCommand` is the `createMagickCommand` factory; the collection
includes all seven tools registered by the ImageMagick plugin.

Configure `limits: { maxInputBytes: 16 * 1024 * 1024 }` to bound cumulative file and stdin input. Caller-provided input budgets also receive cumulative read totals; output is accounted separately. `ImagemagickLimits` is exported for typed configuration; omitted limits default to `Infinity`. Long-running command loops and image generation and pixel transforms yield to timers and cancellation, including Workers with frozen clocks.

Use `-page 12x12+2+3 input.png output.png` to set the virtual canvas without changing the raster pixels or dimensions. The setting applies to subsequent inputs and images already read; `+page` clears it for subsequent inputs. Use `+repage` to reset an existing image’s canvas. FX expressions expose the canvas as `page.width`, `page.height`, `page.x`, and `page.y`, including in `identify -format '%[fx:page.width]'`; images without page metadata use their raster dimensions and zero offsets.

`-shadow` expands image properties, options and FX geometry such as `%[fx:100-10*h]x0+2+1` for each image before resolving opacity, blur and offsets. It preserves unsigned 32-bit PNG page dimensions when negative offsets exceed the page size, matching ImageMagick 7.1.2. For example, a 5×4 image with `-shadow 60x0-9-8` saves a `4294967292x4294967292-9-8` page while retaining its 5×4 raster. These page dimensions are metadata only; shadow rendering does not allocate that virtual canvas. Use `+repage` to reset it to the raster dimensions.

Read default RGB FTXT records with `magick -size 2x1 ftxt:rgb.dat out.png`. Each line contains `x,y:red,green,blue` in raster order, with Q16 channel values (0–65535). The size is required; `ftxt:-` reads stdin.

Write portable half-float maps with `magick input.png output.phm` (or `phm:out.bin` / `phm:-`); output uses big-endian binary16 RGB or grayscale samples in bottom-to-top order, without alpha. Read portable half-float maps with `magick input.phm output.png`; RGB and grayscale inputs support both byte orders and retain the original row order.

Read RGB and RGBA QOI images with lossless 8-bit samples, including colors under fully transparent pixels.

`-alpha discrete` makes output opaque while retaining stored opacity for subsequent `-alpha extract` or `-alpha activate`, including 16-bit samples.

`-alpha deactivate` preserves alpha samples for later `activate` or `extract`. `associate` and `disassociate` also preserve those samples while transforming RGB. Disabled alpha writes opaque output; `off` clears stored alpha, while `set` initializes disabled alpha to opaque.
