# `safe-bash-command-imagemagick`

ImageMagick (`magick`, `convert`, `mogrify`, `composite`, `montage`, `compare`, `identify`) command-line tools for `safe-bash`, powered by `@poe-code/image-ast`.

Use `-filter` to select a resize or non-right-angle rotation filter, including `Lanczos`, `Lanczos2`, `LanczosSharp` and `Lanczos2Sharp`; `+filter` clears that selection and restores automatic default filtering. Rotation defaults to Robidoux; Point uses bilinear interpolation by default, and right-angle rotations preserve pixels without resampling. Use `-define filter:blur=1.5` to widen the filter, `-define filter:lobes=2` to select its lobe count, or `-define filter:support=1.5` to override its support radius. Support takes precedence over lobes; `+define filter:blur` (or the corresponding key) clears an override. Cubic-family filters include `Catrom`, `Cubic` (also `Spline`), `CubicSpline`, `Hermite`, `Quadratic`, `Robidoux` and `RobidouxSharp`, each using its native resize weights. `Gaussian`, `Jinc`, `Lagrange`, `Sinc`, `SincFast`, `MagicKernelSharp2013` and `MagicKernelSharp2021` also use their own filter weights and support. Tune BC cubic weights with `-define filter:b=B` and `-define filter:c=C` (an omitted coefficient follows `B + 2C = 1`), or Gaussian width with `-define filter:sigma=S`. `-define filter:window=Hann` selects a windowed Sinc filter; supported windows are Box, Bartlett, Blackman, Bohman, Cosine, Hamming, Hann, Kaiser, Parzen, Welch, Sinc and SincFast. `+define filter:b`, `+define filter:c`, `+define filter:sigma` and `+define filter:window` clear individual overrides.

Montage defaults to centered tiles in 120×120 cells, shrinking oversized images without enlarging smaller ones, with 4-pixel horizontal and 3-pixel vertical padding. Use `-geometry` to override the tile dimensions and spacing. `-frame 2x2+1+1` sets frame dimensions and bevels, and `+frame` removes frames. `-mode Frame` adds beveled frames and soft shadows; `-mattecolor` sets the frame color, and `-mode Unframe` restores ordinary tiles. Use `-shadow` to add shadows without frames and `+shadow` to disable them. Montage supports `-label` for subsequent images and `-set label` for images already read. Labels and titles use bundled bitmap glyphs. Explicit `-font` selections return an unsupported-font error because host fonts and custom font files are unavailable.

Use `-morphology Dilate:2 Diamond:1` to run two dilation passes, or `Erode:2` for two erosion passes. Nonnegative integer method counts also apply to compound methods and convolution; zero leaves the image unchanged. Compound methods repeat each primitive in order (`Open:2` erodes twice, then dilates twice). Negative convergence counts are unsupported. Explicit flat kernels such as `3x1+0+0:1,nan,1` preserve their dimensions and origin; `nan` cells are excluded. `HitAndMiss` matches explicit kernels with `1` for foreground, `0` for background, and `nan` for ignored cells; for example, `3x3:0,0,0,0,1,0,0,0,0` detects an isolated white pixel. `Ring:inner,outer` selects pixels outside the inner radius and within the outer radius, leaving the center out. `-morphology Distance Manhattan:1,64!` computes an interior Manhattan distance map; background pixels stay black. Manhattan radius 1 supports the default Q16 step of 100, an explicit step, or `!` scaling by `65535 / (scale + 1)`. Other distance kernels are unsupported. `Thinning` subtracts hit-and-miss matches using explicit `0`/`1`/`nan` kernels or the four sequential `Edges` kernels.

## Quickstart

```ts
import { Shell, createMemoryFileSystem } from "@poe-platform/safe-bash";
import { imagemagickCommands } from "@poe-platform/safe-bash/commands/imagemagick";

const fs = createMemoryFileSystem();
const shell = new Shell({ fs }).use(imagemagickCommands());

await shell.exec("magick -size 120x80 xc:#3b82f6 -resize 50% /banner.png");
const info = await shell.exec("magick identify -format '%m %wx%h' /banner.png");
console.log(info.stdout); // PNG 60x40
```

Read and write XBM C byte arrays with least-significant-bit-first pixels and byte-padded scanlines, including widths that are not multiples of eight.

Read native ImageMagick pixel enumerations by signature or with `txt:input.dat`. RGB and grayscale samples preserve alpha and 16-bit precision. Concatenated enumerations produce images in order: `magick txt:input.dat out-%d.png`; use `txt:input.dat[1]` to select the second image.

ICO and CUR inputs read images in directory order, including PNG and uncompressed DIB entries with transparency. Use `icons.ico[1]` to select the second image, `icons.ico out-%d.png` to extract all images, or `icons.ico -append strip.png` to stack them.

ICO output joins input images in directory order, preserving their dimensions and transparency. `.ico`, `.cur`, and `ICO:` write an ICO container with 32-bit DIB entries (1–256 pixels per dimension). Use `+adjoin` or a scene filename pattern to write separate icons. `-define icon:auto-resize=64,32,16` derives square icons from the first input image in the requested order; omit the value for standard sizes from 256 down to 16, or use `+define icon:auto-resize` to clear it.

BMP output defaults to a 124-byte header. Use `BMP2:out.bmp` or `BMP3:out.bmp` for 12-byte or 40-byte headers; `-define bmp:format=bmp2|bmp3|bmp4` also selects the version. Coder prefixes take precedence over the define. Use `-define bmp:subtype=RGB565|RGB555` for opaque 16-bit BMP output or `ARGB4444|ARGB1555` for 16-bit output with alpha. Indexed BMP output supports `-compress RLE` (8-bit BI_RLE8) and `-compress None`; BMP2 remains uncompressed.

Use `GIF87:out.gif` to write GIF87a without transparency, timing, loop or comment extensions. WebP output preserves every frame, delay and loop count, including `-write animation.webp`. WebP uses lossy encoding controlled by `-quality`; quality 100 defaults to lossless. `-define webp:method=0..6` controls lossy encoding effort (default 4); higher methods sample more blocks to optimize coefficient coding without changing decoded pixels. `+define webp:method` restores the default. Use `-define webp:use-sharp-yuv=true` for sharp RGB-to-YUV conversion in lossy output; alpha is preserved. False or `+define webp:use-sharp-yuv` restores the default conversion; lossless output is unaffected. Use `-define webp:target-size=1200` for an approximate lossy byte target and `-define webp:pass=6` to bound the quality search (1–10 passes, default 6 when targeting size). Dimensions and alpha are preserved; targets below the minimum encoded size can be exceeded. A zero target or `+define webp:target-size` disables the search; explicit lossless output is unchanged. Override either mode with `-define webp:lossless=true` or `false`, and remove the override with `+define webp:lossless`. Use `-define webp:alpha-quality=20` to reduce alpha precision independently of RGB quality in lossy WebP (0–100, default 100); `+define webp:alpha-quality` restores full precision. Use `-define webp:alpha-compression=0` for raw alpha storage or `1` (default) for compressed alpha; both preserve alpha precision. `+define webp:alpha-compression` restores compression. Use `-define webp:exact=true` to preserve hidden RGB in fully transparent pixels; the default discards it without changing alpha or visible colors.

Use `-transparent-color color` to choose the transparent GIF palette color without changing opaque pixels or which pixels are transparent.

Lossless animated WebP inputs read every frame in order with their delays and loop count. Use `animation.webp out.png` to extract PNG frames or `animation.webp[1] out.png` to select the second frame.

Use `APNG:input.apng` to read all animation frames with their delays, blending and disposal; for example, `magick APNG:input.apng out.gif` or `magick APNG:input.apng -append strip.png`. An unprefixed PNG input still reads only its default image.

`-set filename:key still` with `v%[filename:key].png` or `v%[filename:key].gif` writes each frame to its resolved path, including with `-write`. Frames sharing that path overwrite it in order, leaving the last frame. Plain GIF output still joins frames into an animation. Unsupported percent tokens in animated GIF names keep their literal text and receive the starting scene suffix (`v%Q-0.gif`, or `v%03X-15.gif` with `-scene 15`).

`-define filename:literal=true` preserves scene placeholders such as `%d` in output filenames, including `-write`. Multiple PNG frames receive numeric suffixes (`frame%d-0.png`); joined GIF frames use one file (`frame%d-0.gif`). `+define filename:literal` or `-define filename:literal=false` restores placeholder expansion. Use `-set filename:key '%s' 'frame%[filename:key].png'` to name each frame by its scene; property values also support image substitutions such as `%w` and `%h`, including with `-write`.

Output parent directories must already exist, including directories selected with `mogrify -path`. Mogrify expands quoted filename patterns (`*`, `?`, and character classes such as `[ab]`) against the command filesystem, including literal SDK arguments. Unmatched patterns fail; parent directory names remain literal.

Conversion accepts `-quiet` to suppress subsequent warnings and `+quiet` to restore them; errors remain visible. `-regard-warnings` and `+regard-warnings` are accepted, and an empty `-trim` still writes its 1×1 output and succeeds.

Use `ftxt:out.dat` or `out.ftxt` for plain pixel channel rows with Q16 values, or `ftxt:-` for stdout. Customize rows with `-define 'ftxt:format=\x/\y=\c\n'`; `+define ftxt:format` restores the default `x,y:channels` lines.

Use `-comment text` or `-label text` before an input to set its text metadata when it is read; settings after an input leave that image unchanged. Use `-set comment 'width=%w'` to write an expanded comment to PNG, JPEG, GIF or TIFF. PNG also stores named text properties such as `-set label` and `-set asset`. Use `-define png:preserve-colormap=true` to retain an indexed PNG’s palette order, bit depth and pixel indices.

Use `identify -format '%#' image.png` or `magick image.png -format '%[signature]' info:` to compute the ImageMagick pixel signature. Both tokens produce the same SHA-256 digest, independent of comments and page metadata. Use `magick animation.gif -format '%T/%D/%c;' info:` to report each frame’s delay in centiseconds, disposal name and comment. Use `%[entropy]` for normalized image entropy, averaged across selected channels (`-channel R` selects red; `+channel` resets). Each channel is normalized by its distinct sample count; constant channels contribute zero.

Use `+set comment` (or another property name) to remove that property from the current images while preserving other properties.

PNG output coders select indexed 8-bit (`PNG8:`), 8-bit RGB/RGBA (`PNG24:`/`PNG32:`), or 16-bit RGB/RGBA (`PNG48:`/`PNG64:`). `PNG00:` retains the image depth and color mode. Ordinary opaque 8-bit RGB output uses an exact indexed palette when it has at most 256 colors, with the smallest matching bit depth. For ordinary PNG output, `-define png:color-type=6` requests RGBA even when every pixel is opaque; invalid color types warn and use the default encoding. Prefixes select the encoder and are removed from the destination filename, including `-write` and stdout destinations.

Use `-encipher key.txt` to produce pixels that native ImageMagick can recover with `-decipher key.txt`. Use `magick cipher.png -decipher key.txt recovered.png` to recover native ImageMagick ciphertext with the same passphrase-file bytes. For RGB PNG output, use `-define png:color-type=2` to prevent palette conversion from changing the encrypted samples. Keep the original sample depth and channel layout when saving encrypted images.

PNG and JPEG preserve embedded ICC profiles. Use `-profile color.icc` to attach an ICC profile to an untagged image, `+profile icc` to remove it, or `+profile '*'` to remove profiles while keeping text properties. `-strip` removes both profiles and text properties. Converting between different ICC profiles is unsupported and returns an error.

`-wave` preserves native grayscale background handling, including PNG background metadata. Use `-virtual-pixel background` to retain a colored `-background` on grayscale input. Sequence evaluation extends smaller images using `-virtual-pixel`; the default repeats edge pixels, and `+virtual-pixel` restores that default.

`-remap` honors `-define dither:diffusion-amount=50%` (or `0.5`) for Floyd–Steinberg and Riemersma dithering. Use `0%` to disable error diffusion; `+define dither:diffusion-amount` restores full diffusion.

`-ordered-dither` applies the built-in ImageMagick threshold, checkerboard, ordered, halftone and circle maps (including their aliases). Append a level count, such as `o8x8,4`, to quantize each channel to that many levels; `-channel` selects the channels to change. Unsupported maps return an error. `-remap palette.png` uses Riemersma error diffusion by default; use `-dither FloydSteinberg` for Floyd–Steinberg or `+dither` to disable diffusion.

Use `-region WIDTHxHEIGHT+X+Y` to limit subsequent pixel edits to a rectangle. Placement follows `-gravity`, and rectangles are clipped to the image. Use `+region` to restore edits across the whole image.

Use `-write-mask mask.png` to restrict subsequent pixel edits on the current images: black permits edits, white protects pixels, and gray blends the result. Use `+write-mask` to remove the mask. The legacy `-clip-mask mask.png` and `+clip-mask` spellings are also supported. Missing mask files return an error.

Use `-interpolate nearest-neighbor -filter point -rotate ANGLE` to rotate using the nearest source pixel. `+interpolate` restores the default interpolation.

Use `-cycle N` to rotate indexed GIF or PNG colors by a signed number of palette entries.
Use `-unique-colors` to extract a one-row palette in ImageMagick color-tree order, preserving alpha, hidden RGB and distinct 16-bit colors.
Use `-quantize gray -colors N` to reduce colors in grayscale; two colors produce black and white. The setting applies to subsequent `-colors` operations until `+quantize` resets it.

Read headerless RGB with `magick -size 2x1 rgb:input.dat output.png` (or `rgb:-` for stdin). Input defaults to 16-bit little-endian samples; use `-depth 8` or `-depth 16` and `-endian MSB` or `-endian LSB` before the input to override it. Radiance HDR destinations (`out.hdr`, `hdr:out.bin`, or `hdr:-`) write linear RGBE pixels without alpha. OpenEXR destinations (`out.exr`, `exr:out.bin`, or `exr:-`) write uncompressed float32 RGB or RGBA scanlines. OpenEXR scanline input supports uncompressed, RLE, ZIPS and ZIP RGB/RGBA or grayscale channels, preserving negative and above-white samples for PFM output. Tiled, multipart, deep and other compression modes are rejected. Radiance RGBE (`.hdr`) input supports flat pixels and both RLE encodings, preserves float samples, and matches native ImageMagick’s 16-bit PNG colors. PFM input honors the declared byte order and bottom-to-top rows, preserving unclamped floats when converted back to PFM and 16-bit precision when converted to PNG. PFM destinations (`out.pfm`, `pfm:out.bin`, or `pfm:-`) write normalized big-endian float32 RGB or grayscale samples in bottom-to-top row order, without alpha. PNM destinations (`out.pnm`, `pnm:out.bin`, or `pnm:-`) select PBM for black-and-white pixels, PGM for grayscale, and PPM for color. PAM input preserves alpha; use `out.pam` or `pam:out.bin` for binary P7 output with alpha. For PAM, PPM and PGM output, `-depth 4`, `-depth 8`, or `-depth 16` sets both MAXVAL and the encoded pixel samples; `+depth` restores the default output depth. For PPM, PGM and PBM, `-compress None` writes ASCII samples; `-compress Zip` or `+compress` restores binary output.

Raw RGB, RGBA, BGR, BGRA and grayscale output supports extensions (`out.rgb`) and explicit coders (`rgba:out.bin`, `gray:-`), including intermediate `-write` outputs.

`-colorspace HSB`, `-colorspace HSL`, and `-colorspace HWB` convert pixels and report hue with saturation/brightness, saturation/lightness, or whiteness/blackness; converting back to `sRGB` restores RGB pixels.

`-colorspace Lab` converts to working CIELab values for pixel inspection and connected-component analysis; converting back to `sRGB` restores RGB pixels.

`-colorspace XYZ`, `-colorspace YCbCr`, and `-colorspace YUV` convert sRGB pixels to CIE XYZ, YCbCr, or YUV, preserve alpha, and expose converted values in pixel and channel expressions. Converting back to `sRGB` restores RGB pixels.

Use `TIFF64:out.tif` to write BigTIFF at `out.tif`, including intermediate `-write` outputs; ordinary `TIFF:` output stays classic TIFF. TIFF input reads all pages for sequence operations and `identify`; use `file.tiff[1]` to select the second page with its own dimensions and metadata. Use `-define tiff:rows-per-strip=N` to set TIFF strip height for final output and `-write`; `+define tiff:rows-per-strip` restores the default. Use `-define tiff:endian=msb|lsb` to select TIFF byte order, including intermediate `-write` outputs; `+define tiff:endian` restores little-endian output. Use `-define tiff:tile-geometry=32x16` for tiled TIFF output, including partial edge tiles; dimensions must be positive multiples of 16. `+define tiff:tile-geometry` restores strips. Use `-define tiff:alpha=associated|unassociated|unspecified` to select alpha metadata and sample encoding; associated output multiplies every sample, including alpha, by alpha. `+define tiff:alpha` restores unassociated output.

`-colorspace CMYK` converts to working cyan, magenta, yellow, and black samples for pixel inspection and connected-component analysis, preserving alpha separately. Convert back with `-colorspace sRGB`. CMYK JPEG output writes four components, including progressive output. CMYK and Lab TIFF output remain unsupported and return an error before writing the requested output.

Use `+antialias` for hard-edged drawing and `-antialias` to restore smoothing for subsequent draws. Filled circles preserve untouched 16-bit source pixels.

Unsupported `-draw` primitives, including the old `matte` primitive, return an error without replacing the output. Use `-alpha on -fill none -draw 'alpha 0,0 floodfill'` to remove a connected background while preserving RGB values and enclosed details. Alpha floodfill uses four-connected neighbors and alpha-aware `-fuzz` matching (percentages or Q16 units); `color x,y floodfill` replaces all RGBA channels.

`-connected-components 4` and `-connected-components 8` label regions of equal color. Numeric connectivity values are truncated: 0 through 4 use edge neighbors; larger or negative integers also connect diagonal neighbors, matching native ImageMagick. Add `-define connected-components:verbose=true` or `-set option:connected-components:verbose true` to print each region’s bounding box, centroid, area, and mean color in the working colorspace (including hue angles and percentages for HSL), sorted by area. `-precision N` controls significant digits in component mean colors and floating-point measurements (default 6); centroids retain one decimal place. Verbose accepts `true`, `1`, `yes`, or `on` to enable reporting and `false`, `0`, `no`, or `off` to disable it (case-insensitive); the last setting wins. Use `+define connected-components:verbose` to clear reporting without changing other definitions. Use `-define connected-components:sort=x` to order report rows by their leftmost x coordinate without changing component labels; `+define connected-components:sort` restores area ordering. Explicitly select area with `-define connected-components:sort=area`. Set `-define connected-components:sort-order=increasing` or `decreasing` to choose report direction without changing labels or equal-area ID ordering; `+define connected-components:sort-order` restores the default direction (decreasing area, increasing x). Add `-define connected-components:mean-color=true` to render each region in its mean color instead of its label; `false` or `+define connected-components:mean-color` restores labels. Use `-define connected-components:minor-axis-threshold=min-max` to retain regions within a minor-axis range (inclusive minimum, exclusive maximum) and include the metric in verbose output. A single minimum has no upper bound; `+define connected-components:minor-axis-threshold` clears it. Use `-define connected-components:eccentricity-threshold=min-max` to retain regions within an eccentricity range (inclusive minimum, exclusive maximum) and report their original eccentricity: 0 for circular regions and 1 for lines or single pixels. A single minimum has no upper bound; `+define connected-components:eccentricity-threshold` clears it. `null:` discards the image. Label PNGs preserve distinct 16-bit component IDs (up to 65536 regions). Use `-fuzz` (percentages or Q16 units) to connect neighboring colors within an alpha-aware color distance. Use `-define connected-components:area-threshold=N` to merge regions smaller than N pixels into neighboring regions, preserving destination IDs and colors; `+define connected-components:area-threshold` clears it. Use `-define connected-components:keep=0,2` or `connected-components:remove=1-3` to merge unwanted component IDs into neighboring regions; lists, inclusive ranges and negative IDs (counting from the end) are supported. `+define connected-components:keep` or `+define connected-components:remove` clears the selector. The largest region is retained by default. Use `-define connected-components:background-id=ID` to protect an explicit region during filtering instead; `+define connected-components:background-id` restores the default. Use `-define connected-components:keep-colors=red` to retain regions whose mean color matches red, plus the background; separate multiple colors with semicolons. Matching honors `-fuzz`, and `+define connected-components:keep-colors` clears the selection. Use `-define connected-components:remove-colors=blue` to merge regions whose mean color matches blue; separate multiple colors with semicolons. Matching honors `-fuzz`, and `+define connected-components:remove-colors` clears the selection. Use `-define connected-components:keep-top=N` to retain the N largest foreground regions plus the largest background region, merging smaller regions into neighbors; ties follow component ID order. `+define connected-components:keep-top` clears it. Use `-define connected-components:perimeter-threshold=MIN` (or `MIN-MAX`, with an exclusive maximum) to merge regions outside the perimeter range and add the native perimeter metric to verbose reports. `0` reports perimeters without filtering; `+define connected-components:perimeter-threshold` clears it. Perimeters describe the original regions before merging. Use `-define connected-components:circularity-threshold=MIN` (or `MIN-MAX`, with an inclusive minimum and exclusive maximum) to filter by circularity (4π × area / perimeter²) and report the original metric. A single minimum has no upper bound; `+define connected-components:circularity-threshold` clears it. Use `-define connected-components:major-axis-threshold=MIN` (or `MIN-MAX`, with an exclusive maximum) to merge regions outside the major-axis range and report their original major-axis lengths. `0` reports the metric without filtering; `+define connected-components:major-axis-threshold` clears it. Use `-define connected-components:angle-threshold=MIN` (or `MIN-MAX`, with an exclusive maximum) to merge regions outside the principal-axis angle range in degrees and add the original angle to verbose reports. For example, `80-100` retains vertical regions and the background. `+define connected-components:angle-threshold` clears it. Use `-define connected-components:exclude-header=true` to omit the report header and `-define connected-components:exclude-ids=true` to omit the ID column. Set either to `false` or clear it with `+define` to restore it. Use `-define connected-components:exclude-header=true` to omit the report header and `-define connected-components:exclude-ids=true` to omit the ID column. Set either to `false` or clear it with `+define` to restore it. Use `-define connected-components:diameter-threshold=MIN` (or `MIN-MAX`, with an exclusive maximum) to merge regions outside the diameter range and report their original diameters, computed as the rounded diameter of a circle with the same area. `0` reports diameters without filtering; `+define connected-components:diameter-threshold` clears it. Other connected-components defines are explicitly unsupported. Retained execution keeps labels and traversal scratch in caller storage.

Async `runIdentifyCli(args, { filesystem, cwd, stdin, stdout, stderr })` uses the supplied filesystem for retained input and scratch storage. Ordinary raster metadata and verbose statistics use bounded reads and caller-backed pixels; streamed stdin is retained once for repeated `-` operands. Optional output sinks receive bounded UTF-8 chunks as each input finishes and apply backpressure before the next input is read. Without sinks, the SDK returns the collected output strings. Custom metadata, statistical properties and pixel expressions share retained inspection; expressions read only the samples they reference. Async `runCompareCli(args, { filesystem, cwd, stdin, stdout })` also retains raster inputs and diff pixels in caller backing, streams encoded stdout to the optional sink, and safely publishes diff files. PDF raster input is passed to the shared file adapter with the same filesystem and pixel storage. Generated labels and captions use the same caller-backed SVG renderer; gradients, checkerboards and tiled patterns generate bounded pixel chunks directly into caller backing. Tiled conversion preserves final-frame selection and reads patterns through a bounded row cache. Async `runConvertCli`, `runMogrifyCli`, `runCompositeCli`, `runMontageCli` and `runMagickCli` accept the same filesystem input with optional stdout/stderr sinks. Conversion retains resize, flip/flop, orientation, rotation, gamma, grayscale, blur/sharpen, crop, extent, shave, trim, median, splice, chop, roll, border/frame and pointwise color operations (including negation, contrast, levels, modulation, thresholding, tint, alpha modes, color matrices, opacity, evaluate and function) in caller backing, preserving frame selection and guarded output publication. Intermediate file writes retain encoded snapshots for later reads and defer publication until the pipeline finishes, preserving overwritten targets and cancellation. Intermediate `-write png:-` and `+write gif:-` outputs go to stdout in pipeline order, followed by any final stdout image; they do not create a file named `-`. Remapping retains its bounded palette and Float32 error-diffusion state through caller-backed caches, preserving dithering and alpha. Flood fill keeps traversal and visited state in caller backing behind a fixed page cache. Drawing retains direct shapes and SVG overlays in caller backing and blends bounded pixel chunks. Text annotation rasterizes glyphs into bounded pixel chunks, preserving density, gravity, offsets and alpha blending. Multi-image `-fx` expressions read demanded samples through bounded caller-backed caches and write pixel chunks, preserving channel masks and local assignments. Shadow and vignette effects stream bounded source/output spans, with shadow blur retaining its intermediate canvas in caller backing. Vignettes render at the page offset onto the virtual canvas, preserve 16-bit samples, and reset the output page origin; use `+repage` first to vignette only the raster. Shear, swirl, implode, wave and distortion use bounded caller-backed caches. `-distort Arc` and `+distort Arc` return an unsupported-method error without replacing output. Distortion defaults to edge virtual pixels; `-virtual-pixel edge|background|transparent|black|white|gray|tile|mirror` selects out-of-bounds samples for distortion, swirl, implode and wave, and `+virtual-pixel` resets the setting. Other virtual-pixel methods return an unsupported-method error. SRT and Barrel use native-style Robidoux elliptical filtering with alpha-weighted colors; other warp sampling remains bilinear. Morphology and neighborhood statistics use sliding four-channel histograms and bounded source caches, including rectangular median windows and compound filters. Blur and Gaussian blur honor radius and sigma with distinct native kernels and bounded row caches. Convolution and edge/emboss filters share bounded RGB row-span processing with unchanged alpha. `-evaluate GaussianNoise` and `-evaluate PoissonNoise` apply native Q16 noise to the selected channels; `-seed` makes it repeatable (default `0`), including across retained pixel chunks. Sketch honors radius, sigma and angle, using a floating-point noise texture and color dodge; `-seed` selects repeatable strokes (default `0`). Charcoal honors radius and sigma, blurs clamped edges, normalizes contrast and produces opaque grayscale through bounded row spans. Normalization, equalization, auto-level and auto-gamma collect fixed-size channel histograms before applying bounded pixel lookups. Mogrify batches reuse the same conversion path for each target, including in-place writes and format/directory outputs, with cumulative input accounting. Frame selection, nested stacks, cloning, duplication, reordering, append, flatten and composite keep pixels and frame metadata in caller storage. Input scene lists skip empty middle entries (`in.gif[2,,1]` selects frames 2 and 1); a trailing comma selects frame 0 (`in.gif[1,]` selects frames 1 and 0). Frame index lists accept comma or whitespace separators, for example `-clone "1 2"`, `-delete "1 2"`, and `-duplicate "1,1 2"`. XPM output (`out.xpm` or `XPM:out.xpm`) writes a C string array with RGB palette entries and `None` for transparent pixels, including intermediate `-write` output. XPM uses binary transparency. TGA output (`out.tga` or `TGA:out.tga`) writes true-color RGB/RGBA data; `-compress None` is the default and `-compress RLE` enables run-length packets, including intermediate `-write` output. TGA input reads uncompressed and RLE true-color images (24-bit RGB or 32-bit RGBA), preserving origin and transparent colors. MNG input reads native full-canvas PNG frame sequences with delays, loop counts and scene selection. MNG object operations and partial frames are unsupported. MNG output (`out.mng` or `MNG:out.mng`) joins frames into one animation with frame delays and loop metadata. Animated GIFs, APNGs (`out.apng` or `APNG:out.png`) and numbered scenes use bounded encoding and deferred publication. APNG output joins frames into one RGBA animation with frame delays and loop metadata; `+adjoin` or a scene filename pattern splits frames. Scene filename fields support decimal `%d`, octal `%o` and hexadecimal `%x`, with optional width and zero padding (for example, `%03x`). Numbered output starts at the first selected input scene (otherwise `0`); `-scene N` overrides that starting number, including filename patterns, `+adjoin` split files and intermediate `-write` outputs. GIF output honors `-delay` in centiseconds and `-loop`. Use `-coalesce` or `-layers Coalesce` to render full-canvas animation frames. Use `-layers CompareAny` to crop changed regions, `CompareOverlay` for changed opaque pixels, or `CompareClear` for pixels becoming transparent; comparisons preserve frame offsets and delays. Use `-layers TrimBounds` to fit the shared canvas to the union of frame rectangles, preserving relative offsets, pixels and timing. Use `-layers RemoveZero` to drop zero-delay frames without combining duplicates; animations with only zero delays are preserved with a warning. Use `-coalesce -layers OptimizeFrame` to crop GIF frames while preserving playback, delays and loop counts; `OptimizeFrame` rejects frames that do not fill the same canvas at zero offset. Use `-layers OptimizePlus` to crop GIF frames and combine duplicate delays while retaining the first transition, including an unchanged frame. Use `-layers OptimizeTransparency` to make unchanged GIF pixels transparent while preserving frame rectangles, timing and loop metadata. Use `-layers RemoveDups` to combine adjacent duplicate frames, adding their delays while preserving playback order and loop metadata. `-units PixelsPerInch|PixelsPerCentimeter|Undefined` sets resolution units, and `-density XxY` retains independent axes in JPEG, PNG and TIFF output. `-resample XxY` resizes each raster axis using its input resolution and updates the output density in the existing units. JPEG output honors `-sampling-factor` (for example, `2x2`, `2x1`, or `1x1`), including `-write`; `+sampling-factor` restores the quality-dependent default. Use `-define jpeg:extent=4KB` to lower JPEG quality until a feasible byte limit is met without resizing, including intermediate `-write` and numbered outputs. `-quality` caps the search; an infeasible limit produces quality 1. `+define jpeg:extent` removes the limit. `sparse-color:-` prints opaque pixel coordinates and colors; `sparse-color:out.dat` writes that text to a file, preserving 16-bit samples. Text, info and histogram color tables stream to optional sinks, and text files use guarded publication; histogram counts stay in caller backing and preserve distinct 16-bit samples in full-width color bins. `histogram:out.png` writes a 256×200 RGB frequency plot; `-format %c histogram:info:-` prints the source color table. Other INFO formats describe the 256×200 histogram image; `histogram:info:out.txt` writes the text to a file. Composite SDK and command entry points share this retained conversion path, including blend modes, placement and cumulative input limits. Montage snapshots inputs once in caller storage and renders selected frames, resized thumbnails, borders and contact sheets through bounded pixel spans and metadata caches. Color lookup, channel separation/combination, frame interpolation and sequence evaluation also use caller-backed stacks and bounded pixel kernels. Median evaluation preserves stable frame order using fixed-size radix histograms. `-raise` and `+raise` honor explicit `-channel` selections, including alpha, at 8- and 16-bit depth. Transpose/transverse, raised borders and layer aliases use the same retained path; query and missing-input diagnostics use bounded admission probes. Unknown image formats are discarded in bounded chunks before reporting the existing diagnostic, preserving read failures and cancellation. Filesystems without the required retained capabilities currently use buffered compatibility paths.

`identify -format` and `magick ... -format FORMAT info:` support literal `%%`,
geometry (`%g`, `%P`), compression (`%C`, `%Q`), and named properties including
`%[channels]`, `%[width]`, `%[height]`, `%[depth]`, `%[bit-depth]`, `%[opaque]`,
`%[type]`, `%[size]`, `%[orientation]`, `%[exif:Orientation]`, `%[standard-deviation]`, `%[skewness]`, and `%[kurtosis]`. Skewness and excess kurtosis use sample standard deviation and average the selected channels; constant channels contribute zero.
Use `-read-mask mask.png` after an input to measure mean and standard deviation only where the mask is brighter than 50%; `+read-mask` restores measurement of all pixels. Read masks do not protect pixels from edits.
`-orient RightTop` sets orientation metadata without changing pixels; `-auto-orient` transforms pixels using that tag. Explicit `-orient` settings persist, so repeated `-auto-orient` operations repeat the transform. `+orient` resets the active setting without changing existing image tags. Without an explicit setting, auto-orientation resets the source tag to TopLeft.
Orientation reports the EXIF name (such as `RightTop`) and numeric value (`6`),
respectively; absent orientation yields `Undefined` and an empty EXIF value. Use `%[hex:p{0,0}]` for an
uppercase RGB or RGBA hex value, or `%[fx:EXPRESSION]` and `%[pixel:EXPRESSION]`
for calculated values. Named properties are case insensitive. Missing `%[comment]` expands to empty text; INFO output warns unless `-quiet` is set. Filenames and
escaped percent signs are inserted literally; pixel statistics are calculated
only when requested. `%q` reports the compatible ImageMagick quantum depth (`16`),
while `%z` reports source bit depth and `%[bit-depth]` reports effective pixel depth.
`%[median]` reports the average of channel medians in Q16 quantum units (0–65535), honoring `-channel` selections in `info:` output; `%[fx:median.r]` reports the normalized red-channel median.

JPEG output accepts `-define jpeg:dct-method=integer|float|fastest` to select the encoding transform; `+define jpeg:dct-method` restores `fastest`. JPEG output supports `-define jpeg:arithmetic-coding=true` for arithmetic entropy coding, including progressive scans, restart markers and intermediate `-write` outputs; `false` or `+define jpeg:arithmetic-coding` restores Huffman coding. Arithmetic coding takes precedence over Huffman table optimization and requires an arithmetic-capable decoder. JPEG output supports `-define jpeg:optimize-coding=true` to optimize Huffman tables without changing decoded pixels; `false` or `+define jpeg:optimize-coding` restores standard tables. JPEG output accepts `-define jpeg:restart-interval=2` to insert restart markers every two MCUs; `0` or `+define jpeg:restart-interval` disables them. JPEG output accepts `-interlace Plane` or `-interlace Line` for progressive scans, including intermediate `-write` outputs; `-interlace None` or `+interlace` restores baseline output with the same decoded pixels. GIF output accepts `-interlace GIF` for four-pass interlacing, including intermediate `-write` outputs; `-interlace none` or `+interlace` restores noninterlaced output. PNG output accepts `-interlace PNG` for Adam7 encoding; `-interlace none` or `+interlace` restores noninterlaced output. This also applies to intermediate `-write` outputs. TIFF output accepts `-interlace plane|none` for separate channel planes or contiguous samples (default); `+interlace` restores contiguous output. Plane mode supports uncompressed, LZW, Zip and RLE strips and tiles; JPEG compression with plane mode returns an error. TIFF integer output accepts `-depth 8|16|32` and `-define quantum:format=signed|unsigned`, scaling byte samples to the requested width and preserving their bit patterns for signed output. TIFF output accepts `-define quantum:format=floating-point -depth 16|32|64` for normalized IEEE samples; `+define quantum:format` restores unsigned output. Floating-point output supports strips, tiles and separate channel planes, except with JPEG compression. TIFF output accepts `-compress None|LZW|Zip|RLE|JPEG`, including intermediate `-write` outputs. `+compress` restores uncompressed output. JPEG compression discards alpha; the other methods preserve pixels.

MIFF input supports uncompressed DirectClass RGB and grayscale images at 8 or 16 bits, retaining alpha and 16-bit samples. MIFF output (`out.miff` or `MIFF:out.bin`) preserves the image list as uncompressed frames by default, with `-compress RLE` selecting run-length compression or `-compress BZip` selecting lossless BZip compression (`-compress None` or `+compress` restores uncompressed output), preserving each frame’s RGB or grayscale channel layout, alpha channel, animation delay, disposal mode, and loop count. Use `-compress Zip` for lossless Zip compression.

The workspace entrypoint exports `imagemagickCommands()` for plugin registration,
`createImagemagickCommands()` for the command collection, and
`createImagemagickCommand()` for a single command. Each accepts an optional
`ImagemagickCommandsOptions` object; existing factory names remain available.
`createImagemagickCommand` is the `createMagickCommand` factory; the collection
includes all seven tools registered by the ImageMagick plugin.

Configure `limits: { maxInputBytes: 16 * 1024 * 1024 }` to bound cumulative file and stdin input. Caller-provided input budgets also receive cumulative read totals; output is accounted separately. `ImagemagickLimits` is exported for typed configuration; omitted limits default to `Infinity`. Long-running command loops and image generation and pixel transforms yield to timers and cancellation, including Workers with frozen clocks.

Use `-page 12x12+2+3 input.png output.png` to set the virtual canvas without changing the raster pixels or dimensions. The setting applies to subsequent inputs and images already read; `+page` clears it for subsequent inputs. Use `+repage` to reset an existing image’s canvas.

`-shadow` preserves unsigned 32-bit PNG page dimensions when negative offsets exceed the page size, matching ImageMagick 7.1.2. For example, a 5×4 image with `-shadow 60x0-9-8` saves a `4294967292x4294967292-9-8` page while retaining its 5×4 raster. These page dimensions are metadata only; shadow rendering does not allocate that virtual canvas. Use `+repage` to reset it to the raster dimensions.

Read default RGB FTXT records with `magick -size 2x1 ftxt:rgb.dat out.png`. Each line contains `x,y:red,green,blue` in raster order, with Q16 channel values (0–65535). The size is required; `ftxt:-` reads stdin.

Write portable half-float maps with `magick input.png output.phm` (or `phm:out.bin` / `phm:-`); output uses big-endian binary16 RGB or grayscale samples in bottom-to-top order, without alpha. Read portable half-float maps with `magick input.phm output.png`; RGB and grayscale inputs support both byte orders and retain the original row order.
