# `safe-bash-command-imagemagick`

ImageMagick (`magick`, `convert`, `mogrify`, `composite`, `montage`, `compare`, `identify`) command-line tools for `safe-bash`, powered by `@poe-code/image-ast`.

Montage defaults to centered tiles in 120×120 cells, shrinking oversized images without enlarging smaller ones, with 4-pixel horizontal and 3-pixel vertical padding. Use `-geometry` to override the tile dimensions and spacing. `-frame 2x2+1+1` sets frame dimensions and bevels, and `+frame` removes frames. `-mode Frame` adds beveled frames and soft shadows; `-mattecolor` sets the frame color, and `-mode Unframe` restores ordinary tiles. Use `-shadow` to add shadows without frames and `+shadow` to disable them. Montage supports `-label` for subsequent images and `-set label` for images already read. Labels and titles use bundled bitmap glyphs. Explicit `-font` selections return an unsupported-font error because host fonts and custom font files are unavailable.

## Quickstart

```ts
import { Shell, createMemoryFileSystem } from "@poe-platform/safe-bash";
import { imagemagickCommands } from "@poe-platform/safe-bash/commands/imagemagick";

const fs = createMemoryFileSystem();
const shell = new Shell({ fs }).use(imagemagickCommands());

await shell.exec("magick -size 120x80 xc:#3b82f6 -resize 50% /banner.png");
const info = await shell.exec("magick identify -format '%m %wx%h' /banner.png");
console.log(info.stdout); // PNG 60x40
```

Output parent directories must already exist, including directories selected with `mogrify -path`. Mogrify expands quoted filename patterns (`*`, `?`, and character classes such as `[ab]`) against the command filesystem, including literal SDK arguments. Unmatched patterns fail; parent directory names remain literal.

Conversion accepts `-quiet` to suppress subsequent warnings and `+quiet` to restore them; errors remain visible. `-regard-warnings` and `+regard-warnings` are accepted, and an empty `-trim` still writes its 1×1 output and succeeds.

Use `-comment text` or `-label text` before an input to set its text metadata when it is read; settings after an input leave that image unchanged. Use `-set comment 'width=%w'` to write an expanded comment to PNG, JPEG, GIF or TIFF. PNG also stores named text properties such as `-set label` and `-set asset`.

Use `identify -format '%#' image.png` or `magick image.png -format '%[signature]' info:` to compute the ImageMagick pixel signature. Both tokens produce the same SHA-256 digest, independent of comments and page metadata.

Use `+set comment` (or another property name) to remove that property from the current images while preserving other properties.

PNG output coders select indexed 8-bit (`PNG8:`), 8-bit RGB/RGBA (`PNG24:`/`PNG32:`), or 16-bit RGB/RGBA (`PNG48:`/`PNG64:`). `PNG00:` retains the image depth and color mode. Ordinary opaque 8-bit RGB output uses an exact indexed palette when it has at most 256 colors, with the smallest matching bit depth. For ordinary PNG output, `-define png:color-type=6` requests RGBA even when every pixel is opaque; invalid color types warn and use the default encoding. Prefixes select the encoder and are removed from the destination filename, including `-write` and stdout destinations.

Use `-encipher key.txt` to produce pixels that native ImageMagick can recover with `-decipher key.txt`. Use `magick cipher.png -decipher key.txt recovered.png` to recover native ImageMagick ciphertext with the same passphrase-file bytes. For RGB PNG output, use `-define png:color-type=2` to prevent palette conversion from changing the encrypted samples. Keep the original sample depth and channel layout when saving encrypted images.

PNG and JPEG preserve embedded ICC profiles. Use `-profile color.icc` to attach an ICC profile to an untagged image, `+profile icc` to remove it, or `+profile '*'` to remove profiles while keeping text properties. `-strip` removes both profiles and text properties. Converting between different ICC profiles is unsupported and returns an error.

`-wave` preserves native grayscale background handling, including PNG background metadata. Use `-virtual-pixel background` to retain a colored `-background` on grayscale input. Sequence evaluation extends smaller images using `-virtual-pixel`; the default repeats edge pixels, and `+virtual-pixel` restores that default.

`-ordered-dither` applies the built-in ImageMagick threshold, checkerboard, ordered, halftone and circle maps (including their aliases). Append a level count, such as `o8x8,4`, to quantize each channel to that many levels; `-channel` selects the channels to change. Unsupported maps return an error.

Use `-region WIDTHxHEIGHT+X+Y` to limit subsequent pixel edits to a rectangle. Placement follows `-gravity`, and rectangles are clipped to the image. Use `+region` to restore edits across the whole image.

Use `-write-mask mask.png` to restrict subsequent pixel edits on the current images: black permits edits, white protects pixels, and gray blends the result. Use `+write-mask` to remove the mask. Missing mask files return an error.

Use `-unique-colors` to extract a one-row palette in ImageMagick color-tree order, preserving alpha, hidden RGB and distinct 16-bit colors.
Use `-quantize gray -colors N` to reduce colors in grayscale; two colors produce black and white. The setting applies to subsequent `-colors` operations until `+quantize` resets it.

Read headerless RGB with `magick -size 2x1 rgb:input.dat output.png` (or `rgb:-` for stdin). Input defaults to 16-bit little-endian samples; use `-depth 8` or `-depth 16` and `-endian MSB` or `-endian LSB` before the input to override it. PNM destinations (`out.pnm`, `pnm:out.bin`, or `pnm:-`) select PBM for black-and-white pixels, PGM for grayscale, and PPM for color. PAM input preserves alpha; use `out.pam` or `pam:out.bin` for binary P7 output with alpha. For PAM, PPM and PGM output, `-depth 4`, `-depth 8`, or `-depth 16` sets both MAXVAL and the encoded pixel samples; `+depth` restores the default output depth. For PPM, PGM and PBM, `-compress None` writes ASCII samples; `-compress Zip` or `+compress` restores binary output.

Raw RGB, RGBA, BGR, BGRA and grayscale output supports extensions (`out.rgb`) and explicit coders (`rgba:out.bin`, `gray:-`), including intermediate `-write` outputs.

`-colorspace HSB`, `-colorspace HSL`, and `-colorspace HWB` convert pixels and report hue with saturation/brightness, saturation/lightness, or whiteness/blackness; converting back to `sRGB` restores RGB pixels.

`-colorspace XYZ`, `-colorspace YCbCr`, and `-colorspace YUV` convert sRGB pixels to CIE XYZ, YCbCr, or YUV, preserve alpha, and expose converted values in pixel and channel expressions. Converting back to `sRGB` restores RGB pixels.

`-colorspace CMYK` and `-colorspace Lab` are unsupported and return an error before writing the requested output, including TIFF, rather than silently producing RGB pixels.

Use `+antialias` for hard-edged drawing and `-antialias` to restore smoothing for subsequent draws. Filled circles preserve untouched 16-bit source pixels.

Unsupported `-draw` primitives, including the old `matte` primitive, return an error without replacing the output. Use `-alpha on -fill none -draw 'alpha 0,0 floodfill'` to remove a connected background while preserving RGB values and enclosed details. Alpha floodfill uses four-connected neighbors and alpha-aware `-fuzz` matching (percentages or Q16 units); `color x,y floodfill` replaces all RGBA channels.

`-connected-components 4` and `-connected-components 8` label regions of equal color. Add `-define connected-components:verbose=true` to print each region’s bounding box, centroid, area, and mean color, sorted by area. Use `-define connected-components:sort=x` to order report rows by their leftmost x coordinate without changing component labels; `+define connected-components:sort` restores area ordering. Add `-define connected-components:mean-color=true` to render each region in its mean color instead of its label; `false` or `+define connected-components:mean-color` restores labels. `null:` discards the image. Label PNGs preserve distinct 16-bit component IDs (up to 65536 regions). Use `-fuzz` (percentages or Q16 units) to connect neighboring colors within an alpha-aware color distance. Use `-define connected-components:area-threshold=N` to merge regions smaller than N pixels into neighboring regions, preserving destination IDs and colors; `+define connected-components:area-threshold` clears it. Use `-define connected-components:keep=0,2` or `connected-components:remove=1-3` to merge unwanted component IDs into neighboring regions; lists, inclusive ranges and negative IDs (counting from the end) are supported. `+define connected-components:keep` or `+define connected-components:remove` clears the selector. The largest region is retained by default. Use `-define connected-components:background-id=ID` to protect an explicit region during filtering instead; `+define connected-components:background-id` restores the default. Use `-define connected-components:remove-colors=blue` to merge regions whose mean color matches blue; separate multiple colors with semicolons. Matching honors `-fuzz`, and `+define connected-components:remove-colors` clears the selection. Use `-define connected-components:keep-top=N` to retain the N largest foreground regions plus the largest background region, merging smaller regions into neighbors; ties follow component ID order. `+define connected-components:keep-top` clears it. Use `-define connected-components:perimeter-threshold=MIN` (or `MIN-MAX`, with an exclusive maximum) to merge regions outside the perimeter range and add the native perimeter metric to verbose reports. `0` reports perimeters without filtering; `+define connected-components:perimeter-threshold` clears it. Perimeters describe the original regions before merging. Use `-define connected-components:exclude-header=true` to omit the report header and `-define connected-components:exclude-ids=true` to omit the ID column. Set either to `false` or clear it with `+define` to restore it. Use `-define connected-components:exclude-header=true` to omit the report header and `-define connected-components:exclude-ids=true` to omit the ID column. Set either to `false` or clear it with `+define` to restore it. Other connected-components defines are explicitly unsupported. Retained execution keeps labels and traversal scratch in caller storage.

Async `runIdentifyCli(args, { filesystem, cwd, stdin, stdout, stderr })` uses the supplied filesystem for retained input and scratch storage. Ordinary raster metadata and verbose statistics use bounded reads and caller-backed pixels; streamed stdin is retained once for repeated `-` operands. Optional output sinks receive bounded UTF-8 chunks as each input finishes and apply backpressure before the next input is read. Without sinks, the SDK returns the collected output strings. Custom metadata, statistical properties and pixel expressions share retained inspection; expressions read only the samples they reference. Async `runCompareCli(args, { filesystem, cwd, stdin, stdout })` also retains raster inputs and diff pixels in caller backing, streams encoded stdout to the optional sink, and safely publishes diff files. PDF raster input is passed to the shared file adapter with the same filesystem and pixel storage. Generated labels and captions use the same caller-backed SVG renderer; gradients, checkerboards and tiled patterns generate bounded pixel chunks directly into caller backing. Tiled conversion preserves final-frame selection and reads patterns through a bounded row cache. Async `runConvertCli`, `runMogrifyCli`, `runCompositeCli`, `runMontageCli` and `runMagickCli` accept the same filesystem input with optional stdout/stderr sinks. Conversion retains resize, flip/flop, orientation, rotation, gamma, grayscale, blur/sharpen, crop, extent, shave, trim, median, splice, chop, roll, border/frame and pointwise color operations (including negation, contrast, levels, modulation, thresholding, tint, alpha modes, color matrices, opacity, evaluate and function) in caller backing, preserving frame selection and guarded output publication. Intermediate file writes retain encoded snapshots for later reads and defer publication until the pipeline finishes, preserving overwritten targets and cancellation. Intermediate `-write png:-` and `+write gif:-` outputs go to stdout in pipeline order, followed by any final stdout image; they do not create a file named `-`. Remapping retains its bounded palette and Float32 error-diffusion state through caller-backed caches, preserving dithering and alpha. Flood fill keeps traversal and visited state in caller backing behind a fixed page cache. Drawing retains direct shapes and SVG overlays in caller backing and blends bounded pixel chunks. Text annotation rasterizes glyphs into bounded pixel chunks, preserving density, gravity, offsets and alpha blending. Multi-image `-fx` expressions read demanded samples through bounded caller-backed caches and write pixel chunks, preserving channel masks and local assignments. Shadow and vignette effects stream bounded source/output spans, with shadow blur retaining its intermediate canvas in caller backing. Vignettes render at the page offset onto the virtual canvas, preserve 16-bit samples, and reset the output page origin; use `+repage` first to vignette only the raster. Shear, swirl, implode, wave and distortion use bounded caller-backed caches. `-distort Arc` and `+distort Arc` return an unsupported-method error without replacing output. Distortion defaults to edge virtual pixels; `-virtual-pixel edge|background|transparent|black|white|gray|tile|mirror` selects out-of-bounds samples for distortion, swirl, implode and wave, and `+virtual-pixel` resets the setting. Other virtual-pixel methods return an unsupported-method error. SRT and Barrel use native-style Robidoux elliptical filtering with alpha-weighted colors; other warp sampling remains bilinear. Morphology and neighborhood statistics use sliding four-channel histograms and bounded source caches, including rectangular median windows and compound filters. Blur and Gaussian blur honor radius and sigma with distinct native kernels and bounded row caches. Convolution and edge/emboss filters share bounded RGB row-span processing with unchanged alpha. `-evaluate GaussianNoise` and `-evaluate PoissonNoise` apply native Q16 noise to the selected channels; `-seed` makes it repeatable (default `0`), including across retained pixel chunks. Sketch honors radius, sigma and angle, using a floating-point noise texture and color dodge; `-seed` selects repeatable strokes (default `0`). Charcoal honors radius and sigma, blurs clamped edges, normalizes contrast and produces opaque grayscale through bounded row spans. Normalization, equalization, auto-level and auto-gamma collect fixed-size channel histograms before applying bounded pixel lookups. Mogrify batches reuse the same conversion path for each target, including in-place writes and format/directory outputs, with cumulative input accounting. Frame selection, nested stacks, cloning, duplication, reordering, append, flatten and composite keep pixels and frame metadata in caller storage. Animated GIFs and numbered scenes use bounded encoding and deferred publication. `-scene N` starts numbered output at N (default `0`), including filename patterns, `+adjoin` split files and intermediate `-write` outputs. GIF output honors `-delay` in centiseconds and `-loop`. Use `-layers CompareAny` to crop changed regions, `CompareOverlay` for changed opaque pixels, or `CompareClear` for pixels becoming transparent; comparisons preserve frame offsets and delays. Use `-layers RemoveZero` to drop zero-delay frames without combining duplicates; animations with only zero delays are preserved with a warning. Use `-layers OptimizePlus` to crop GIF frames and combine duplicate delays while retaining the first transition, including an unchanged frame. Use `-layers OptimizeTransparency` to make unchanged GIF pixels transparent while preserving frame rectangles, timing and loop metadata. Use `-layers RemoveDups` to combine adjacent duplicate frames, adding their delays while preserving playback order and loop metadata. `-units PixelsPerInch|PixelsPerCentimeter|Undefined` sets resolution units, and `-density XxY` retains independent axes in JPEG, PNG and TIFF output. `-resample XxY` resizes each raster axis using its input resolution and updates the output density in the existing units. JPEG output honors `-sampling-factor` (for example, `2x2`, `2x1`, or `1x1`), including `-write`; `+sampling-factor` restores the quality-dependent default. Text, info and histogram output stream to optional sinks, and text files use guarded publication; histogram counts stay in caller backing. Composite SDK and command entry points share this retained conversion path, including blend modes, placement and cumulative input limits. Montage snapshots inputs once in caller storage and renders selected frames, resized thumbnails, borders and contact sheets through bounded pixel spans and metadata caches. Color lookup, channel separation/combination, frame interpolation and sequence evaluation also use caller-backed stacks and bounded pixel kernels. Median evaluation preserves stable frame order using fixed-size radix histograms. `-raise` and `+raise` honor explicit `-channel` selections, including alpha, at 8- and 16-bit depth. Transpose/transverse, raised borders and layer aliases use the same retained path; query and missing-input diagnostics use bounded admission probes. Unknown image formats are discarded in bounded chunks before reporting the existing diagnostic, preserving read failures and cancellation. Filesystems without the required retained capabilities currently use buffered compatibility paths.

`identify -format` and `magick ... -format FORMAT info:` support literal `%%`,
geometry (`%g`, `%P`), compression (`%C`, `%Q`), and named properties including
`%[channels]`, `%[width]`, `%[height]`, `%[depth]`, `%[bit-depth]`, `%[opaque]`,
`%[type]`, `%[size]`, `%[orientation]`, `%[exif:Orientation]`, and `%[standard-deviation]`.
Use `-read-mask mask.png` after an input to measure mean and standard deviation only where the mask is brighter than 50%; `+read-mask` restores measurement of all pixels. Read masks do not protect pixels from edits.
`-orient RightTop` sets orientation metadata without changing pixels; `-auto-orient` transforms pixels using that tag.
Orientation reports the EXIF name (such as `RightTop`) and numeric value (`6`),
respectively; absent orientation yields `Undefined` and an empty EXIF value. Use `%[hex:p{0,0}]` for an
uppercase RGB or RGBA hex value, or `%[fx:EXPRESSION]` and `%[pixel:EXPRESSION]`
for calculated values. Named properties are case insensitive. Filenames and
escaped percent signs are inserted literally; pixel statistics are calculated
only when requested. `%q` reports the compatible ImageMagick quantum depth (`16`),
while `%z` reports source bit depth and `%[bit-depth]` reports effective pixel depth.
Statistics use the command's 0–255 RGB sample scale.

MIFF output (`out.miff` or `MIFF:out.bin`) preserves the image list as uncompressed 8-bit RGBA frames.

## Available Commands

| Command | Highlights |
| --- | --- |
| `magick` / `convert` | Left-to-right image stack pipeline supporting `xc:`/`canvas:`/`gradient:`/`radial-gradient:`/`pattern:checkerboard`/`label:`/`tile:filename` generators, `-resize` (`!`, `>`, `<`, `^`, `%`, `@`), `-crop`, `-extent`, `-border`, `-shave`, `-splice`, `-chop`, `-roll`, `-trim` (with `-define trim:percent-background=50%` to discard sparse edge noise and `-define trim:minSize=WxH` to retain minimum dimensions), `-rotate`, `-deskew threshold` (with `-define deskew:auto-crop=1` to crop the rotated image), `-flip`, `-flop`, `-auto-orient`, `-shear`, `-distort` (`SRT`, `Perspective`, `Affine`, `Barrel`), `-swirl`, `-implode`, `-wave`, `-shadow`, `-vignette`, `-negate`, `-grayscale`, `-colorspace`, `-sepia-tone`, `-solarize`, `-posterize`, `-colors`, `-modulate`, `-gamma`, `-level`, `-normalize`, `-threshold`, `-tint`, `-colorize`, `-opaque`/`+opaque`, `-transparent`/`+transparent`, `-evaluate`, `-function`, `-clut` / `-hald-clut` with `-interpolate nearest` (or `nearest-neighbor`), `integer`, `average`, or `bilinear` (default; reset with `+interpolate`), `-fx`, `-channel-fx` channel copying (`red=>blue`, comma-separated assignments; R/G/B/A or full names), `-blur`, `-gaussian-blur`, `-rotational-blur angle`, `-mean-shift widthxheight+color-distance` (use `%` for a percentage threshold), `-wavelet-denoise threshold[xsoftness]` (Q16 threshold or percentage; default softness 0, preserves alpha), `-sharpen`, `-unsharp radius{xsigma}{+amount}{+threshold}` (defaults: sigma 1, amount 1, threshold 0.05), `-median`, `-edge`, `-emboss`, `-charcoal`, `-sketch`, `-seed`, `-draw` (`rectangle`, `roundRectangle`, `circle`, `ellipse`, `line`, `point`, `polygon`, `polyline`, `bezier`, `path`, `text`, `color x,y floodfill`, `alpha x,y floodfill`), `-annotate`, `( ... )` substacks, `-clone`, `-swap`, `-delete`, `-morph` (uses the active `-filter` when resizing intermediate frames), `-composite`, `-flatten`, `-append`, `+append`, `-smush gap` / `+smush gap` (vertical / horizontal packing with transparent-edge removal, gravity and signed spacing), `[0-2]` scene selectors, `out-%d.png` multi-frame output, and stdin/stdout pipes (`-`, `png:-`). |
| `mogrify` | In-place batch transformation (`-resize`, `-quality`, `-strip`, `-rotate`, etc.) or format/directory conversion via `-format` and `-path`; read settings such as `-density` apply before decoding. |
| `composite` | Overlay composition with `-tile` to repeat the overlay across the base, `-gravity`, `-geometry WxH+X+Y`, `-compose`, and `-dissolve` / `-blend` / `-watermark` (brightness and chroma modulation preserving base alpha). |
| `montage` | Contact-sheet grid generation with `-tile MxN`, `-geometry WxH+X+Y`, `-thumbnail WxH`, `-trim` to remove input borders before sizing tiles, `-flip` / `-flop` to mirror input pixels vertically / horizontally, `-transpose` to swap input pixel axes before layout, `-background`, and `-border` / `-bordercolor`. Add `-label '%f'` before inputs for filename captions; `-pointsize` and `-fill` control the text, and `+label` clears the label for subsequent inputs. `-title` adds centered text above the grid at twice the point size, with additional space for each line; `+title` clears it. |
| `compare` | `-list channel` and `-list metric` print available names without reading images or writing output. Perceptual and pixel diffing (`-metric AE\|MAE\|MEPP\|MSE\|RMSE\|Fuzz\|PAE\|PSNR\|SSIM\|DSSIM\|NCC\|DPC\|PDC\|PHASH`), `-channel` selection (`R`, `G`, `B`, `A`, combinations or channel names; `+channel` resets), `-fuzz` tolerance, `-highlight-color`, `-lowlight-color`, and visual diff output. The first two frames in the combined input sequence are compared; use explicit selectors such as `a.gif[0] b.gif[0]` to compare one frame from each animation. `-quiet` suppresses color warnings while retaining the metric; `-regard-warnings` treats color warnings as errors; `-verbose` reports input/output geometry and comparison details (without elapsed times). Their `+` forms reset these settings. Metrics go to stderr; `-precision digits` controls their significant digits (default 6); `-format '%[distortion]'` writes the normalized distortion to stdout (and supports the usual image format properties); PHASH reports the mean squared distance between perceptual hashes in xyY and HSB as two equal, unscaled values and ignores fuzz tolerance; PDC reports the number and fraction of pixels with a channel exceeding fuzz tolerance; AE reports channel-weighted error magnitude and its normalized value; MEPP reports mean error, normalized mean error, and normalized peak error and ignores fuzz tolerance; Fuzz reports mean squared error over channels exceeding the fuzz tolerance; SSIM, NCC, and DPC report distortion as scaled and normalized values, with `0 (0)` for identical nonuniform images (NCC and DPC report `32767.5 (0.5)` for solid images with zero variance); perfect PSNR reports `120 (1)` with exit status 1; otherwise identical images return 0 and differing images return 1 (with `-fuzz` tolerance). `-subimage-search` finds the best candidate-sized region in the reference, reports its `@ x,y` offset and search score, and preserves the reference canvas for visual diffs. Search also emits a grayscale similarity map after the comparison image: single-image formats use numbered filenames (for example, `diff-0.png` and `diff-1.png`), while GIF, TIFF, and MIFF retain both frames. Search uses bounded pixel reads in both execution modes. `-similarity-threshold` stops search after a qualifying row (`-1` disables early termination); unsearched similarity-map rows remain black. `-dissimilarity-threshold` controls search warnings and does not change ordinary comparison exit status. Unknown or unsupported dash options, including `-alpha`, return exit status 2 before comparison. |
| `identify` | Image metadata and statistics inspection (`-ping`, `-format`, `-verbose`). |

The workspace entrypoint exports `imagemagickCommands()` for plugin registration,
`createImagemagickCommands()` for the command collection, and
`createImagemagickCommand()` for a single command. Each accepts an optional
`ImagemagickCommandsOptions` object; existing factory names remain available.
`createImagemagickCommand` is the `createMagickCommand` factory; the collection
includes all seven tools registered by the ImageMagick plugin.

Configure `limits: { maxInputBytes: 16 * 1024 * 1024 }` to bound cumulative file and stdin input. Caller-provided input budgets also receive cumulative read totals; output is accounted separately. `ImagemagickLimits` is exported for typed configuration; omitted limits default to `Infinity`. Long-running command loops and image generation and pixel transforms yield to timers and cancellation, including Workers with frozen clocks.

`-shadow` preserves unsigned 32-bit PNG page dimensions when negative offsets exceed the page size, matching ImageMagick 7.1.2. For example, a 5×4 image with `-shadow 60x0-9-8` saves a `4294967292x4294967292-9-8` page while retaining its 5×4 raster. These page dimensions are metadata only; shadow rendering does not allocate that virtual canvas. Use `+repage` to reset it to the raster dimensions.
