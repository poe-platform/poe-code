   original P25/P26 lexical-path expectations (2). Preserve those original
   expectations: lexical syntax/conflicts -> 2, observed target safety -> 1.
   This is a specificity interpretation, not a newly discovered product defect.
2. The fixed work/line/FS-call ceilings are normative, but an exact end-to-end
   boundary needs accounting checkpoints. “Aggregate retained” line records
   does not specify whether shared original/output records count once or twice;
   scanning/copying “units” does not enumerate every internal pass. The matrix
   freezes checkpoint probes and independent observable constraints, not invented
   success predictions for an unknowable counter implementation. Later review
   must bind these probes to source and disclose unreachable joint boundaries.
3. The proposal counts “update hunks plus named anchor records.” Bare-hunk limits
   can be tested directly; whether an anchor-headed hunk counts both its hunk and
   its anchor needs a precise accounting witness. No cap is changed here.
4. Failure prose is not specified byte-for-byte. Require bounded, human-readable
   diagnostics retaining operation/path/error meaning, no success summary, and
   partial-publication qualification when relevant. Exact text assertions require
   later diagnostic source review. Specified success summary bytes remain exact.
5. Cross-realm controls concern the future review-data/tool-role transport, not
   a new product JSON interface or cross-realm Uint8Array promise. This preparation
   supplies a finite own-data rehearsal record and malformed transformations;
   root separately owns route/admission binding. No new runner is introduced.

## Limits of preparation

CAS, namespace atomicity or an ABA defense. Read-side atime/overlay housekeeping
is separate from command-issued writes. A failing write may have changed bytes;
no rollback, parent cleanup or source unlink after uncertain Move write is allowed.
Opaque host work is not forcibly preempted or awaited as cooperative cleanup.
No remote service, real adapter, public export, shared-budget integration or
performance acceptance is established by these data or their synthetic checker.
