# Handoff gate: not executable preparation work

## Required authorization and frozen inputs

1. Stop after preparation. Do not poll, wait indefinitely, import a candidate,
   perform product benchmarks, run the product build or run a full gate.
2. Obtain explicit author handoff with the column source/test commit, profile
   documentation and ownership of any allowed column-local fixes. Shared reader,
   table helpers, runtime and root exports remain Root/integration-owner work.
3. Verify the frozen corpus/evidence hashes before viewing the candidate. Preserve
   this original cohort. Hash the actual handed-off source/tests and record dirty
   versus committed state and the exact package consumer inventory. A HEAD alone
   cannot authenticate concurrent untracked source or a later built artifact.
4. Resolve documented scalar ranges, whitespace membership, tab origin, work-unit
   counting and limit boundary questions without using observed candidate behavior
   as the expected result. Any discrepancy needs a new explicitly linked annotation,
   not retroactive alteration of original inputs, native outputs or expectations.

## Narrow execution order after authorization

First implement scoped holdouts in this owned directory against the confirmed
entrypoint and authoritative public contracts. Execute common native-eligible rows
separately from documented-profile differences and contract safety schedules.
Retain complete byte/status/stderr results, including all original oracle failures.
Unsupported, unknown, blocked and unmeasured remain distinct from passes.

Use deterministic controlled sources/sinks, acquisition counters and gates for
producer reuse, cancellation, cleanup and backpressure. Never assert that abort
undoes completed effects or that public settlement awaits opaque uncooperative
host work. Registered cooperative acquisition/release is different: it must drain
before public exec/dispose settlement. Always release harness gates and remove
listeners in finally, with a bounded child-process fallback for pathological cases.
Observe delayed next/write/return rejections. Do not run infinite producers.

Probe expansion and argument limits before width-sized allocations. Use an isolated
bounded-memory process only after authorization; a native giant-width run is not
needed. Runtime allocation evidence and a column-local source review complement
functional output bounds; a small output or a single RSS sample is not proof of
preallocation order. Performance ranking and superiority claims remain out of scope.

## Actual Shell and pipeline

Inspect public root Shell/registry/FS declarations only after the freeze. Register
the confirmed internal column command via actual public registration. Exercise
literal argv both through the parser and actual `CommandContext.invoke`, including
producer -> column -> collector pipelines, VFS redirects, multiple operands and
the shared stdin cursor. Keep middleware, signals, byte ownership, stdin provenance
and enclosing invocation budgets intact; a callback-only stub is insufficient.

Replay relevant safety cases through actual Shell exec and overlapping dispose so
direct command cleanup results are not mislabeled as public runtime guarantees.
Route a shared reader/runtime defect with a minimal reproduction to Root; do not
edit shared source, author-owned tests, or root exports under verifier ownership.

## Moved packed standalone consumer

Coordinate build/pack with the integration owner instead of building over an active
author. Hash source, tests, packed manifest, emitted declarations, packed column
JavaScript, archive, helper and consumer. Record Node/OS, pack scripts/effects,
package export map and the exact committed/dirty candidate identity.

In isolated tmp, extract then move the package to a different directory. Ensure
the consumer cannot fall back to the repository, original extraction or workspace
dependencies. Import Shell from the package root. Since column root/subpath exports
are not integrated at this preparation stage, import its actual packed internal
module using a file URL resolved within that moved package. Report this explicitly
as a packed internal-module smoke test, not public column subpath acceptance.
If that internal file is absent, record the missing prerequisite; do not fake it,
copy workspace product source, or change the export map.

Replay the frozen literal table/pipeline bytes and VFS effects in this standalone
consumer. Separately inspect and record whether a supported public column subpath
exists in that candidate. No claim of public support follows merely from root
Shell plus an internal file URL. No new runtime dependency or private checkout is
allowed. Keep exact scope/counts/caveats and stop after the authorized bounded phase.
