## Minimal implementation and proof taxonomy

factory descriptors change. The saved original iterator factory executes once on
the original receiver. next/return return the EXACT original Promise; no then,
await, catch or scheduling is inserted by the adapter. Other codec methods and
properties are untouched, including write/end overloads and listener identities.
Exact descriptors are restored after known owned notification completion.

SOURCE-TRANSFORMS.json binds original blobs, byte offsets/lines, exact replacements,
prefixes, transformed hashes and complete transformed bytes as base64 DATA. Five
candidate modules plus the historical case helper are instrumented; three further
modules are source-only call-chain context. Reversal restores originals exactly.
The source/code/fixture changes have NOT been parsed as TypeScript, imported,
transpiled or evaluated. Same await/then/catch token counts are a narrow static
check, not a general proof of equivalent scheduling or performance.

Private written is recorded by reference immediately AFTER its actual assignment.
Only the probe AFTER the existing finally await of written.catch records a join.
No raw write callback count substitutes for this Promise. Its failure is not
silently assigned a new meaning: the original catch/join behavior is unchanged.
Acquisition rejection before codec-acquired does not fabricate written/finalizer
work. Synchronous preallocated probes add no Promise continuations. They can
perturb timing through synchronous work and allocation at stream enrollment;
instrumented observations are mechanical evidence, not byte-identical execution.

Three close-hook callsites have separate labels: acquire release, writer fallback,

## Causal/error criterion

Use the accepted v8 identity rule, not AbortError name/code/message. A token starts
synchronously before the saved iterator.return call on a known yielded iterator,
with no next pending. Only its first destroy argument on the SAME stream can be
enrolled before original destroy forwarding. Token retirement is source-linked to
the codec finally entry after language-level iterator retirement. It is NOT an
independent return-Promise settlement timestamp. This intentionally keeps original
Promise identity and inserts no settlement then. It cannot authenticate malicious
or reentrant JavaScript origins during that narrow return interval. Ordinary owned
fixture trust, not hostile-host isolation, is the admitted profile.

Cause-only ownership never crosses resources. Unowned error events remain HOLD.
The sole extra expected-primary classification is the exact pinned codec branch
mapping its recorded codecError by reference before invocation settlement. Only
earlier events matching that mapping are classified; the same reason emitted
later is still HOLD. A fulfilled status128 alone grants no acknowledgement.
Secondary/lookalike errors, cleanup rejection, true pending work, unknown states,
overflow and hook tamper cannot pass. Error identity remains in bounded reference
tables; JSON uses identity integers rather than structural Error equality.
