the historical Apple Git binary is this version or that these are latest docs.

- `https://git-scm.com/docs/git/2.39.0.html` and tagged
  `https://raw.githubusercontent.com/git/git/v2.39.0/Documentation/git.txt`:
  GIT_CONFIG_GLOBAL/SYSTEM replace the
  normal config locations; NOSYSTEM skips system config; TERMINAL_PROMPT suppresses
  terminal prompts; NO_REPLACE_OBJECTS disables replacement refs; OPTIONAL_LOCKS=0
  suppresses optional lock-taking work, including status index refresh.

  redirect those paths; fsmonitor=false needs a sufficiently recent version

  isolation. Exact-bound neutral config avoids protocol-specific overrides.
- `https://git-scm.com/docs/git-diff/2.39.0.html`: no-ext-diff and no-textconv disable
  the respective external diff/text conversion routes; no implied arbitrary-repo
  filter, transport or hostile-native sandbox guarantee.
- `https://raw.githubusercontent.com/git/git/v2.39.0/Documentation/gitattributes.txt`
  and `https://raw.githubusercontent.com/git/git/v2.39.0/attr.c`: attribute search
