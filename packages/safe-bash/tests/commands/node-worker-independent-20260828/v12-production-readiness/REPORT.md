## Smallest production boundary — PROPOSED, not existing API

1. Keep zero core runtime dependencies. Provide a Node-family command with an **explicitly injected trusted provider** and no host fallback when absent. Host selects an exact static Worker entry and legitimate public engine installation; no auto-resolution/deep import, downloader, npm/npx, host eval/Function/subprocess, or implicit private checkout access. Provider functions stay parent-side; only bounded data crosses into the Worker. The static trusted entry loads its approved public engine itself—functions cannot be supplied as a transfer shortcut.
2. Module-local typed source/request contract: immutable bounded source bytes, selector (.cjs/eval/primitive-print/stdin), logical filename, argv, virtual cwd/env and explicit VFS grants. Reject .js/ESM/TLA, asyncfs, exit, package search and unlisted facilities according to a frozen grammar before guest admission; preserve supported Promise statics but refuse constructor use as declared. Source text must never become native executable code. Parse/admit user syntax and protect private bridge/cache names and scopes; current hardcoded6995-byte fixture is not that implementation. No unapproved private parser import; use an independently specified module-owned closed grammar or approved public capability.
3. Module-local **inert session** interface: trusted createSession(request, hostServices) returns an owner without acquiring Worker/resources. Register the same idempotent retirement cleanup with existing CommandContext.registerCleanup BEFORE start; retain finally fallback for direct hosts. start admits/starts; stop closes only this invocation and wakes blocked sync transport; retire confirms actual exit (or proved-none) AND all enrolled parent operation settlements. Unknown acquisition/unsettled cleanup never becomes a clean receipt. Separate failure presence/provenance/raw values from numeric completion; do not substitute status0 for null.
4. Parent host services adapt actual context.fs/stdin/stdout/stderr, not fixture Map. Use bounded asynchronous VFS work behind genuinely blocking Worker RPC, complete payload/grant validation before effects, writes deny by default with explicit virtual-path grants, fresh module/JSON authorization, and guest-owned cache identity. Register every operation before acquisition and await its result/close; validate source/request context before admitting effects. Root stdin is borrowed, not arbitrarily returned/disposed; output uses existing awaited sinks/ownedOutput contracts. A closed destination must not abort caller/siblings or erase already admitted independent work.
5. Reuse existing core lifecycle/IO contracts: CommandContext already has fs/signal/registerCleanup and ByteSink ownedOutput; createOutputOperation supplies enrollment/close helpers. No new shared core field is shown necessary. **New Node-module provider/source/session types are necessary:** existing SafeJsRuntime.run/createBudget/makeFsModule cannot attest actual Worker exit or parent-operation retirement. Public names/signatures require ROOT/type review. Preserve core caller>escaping execution>cleanup>numeric ordering and exact falsy reasons; never turn the experiment's matched-failure parent exit0 into a command success. Engine Budget/command ledger are separate from the shared Shell budget; do not reset or replace it.

This is not a request to widen the profile. Existing core APIs should remain unchanged unless implementation demonstrates a precise seam. A provider self-label is not qualification; bind the actual implementation/entry/profile. No upstream engine vendoring/distribution until license audit and explicit authorization; public source availability alone is not permission. Development copies in these archives are not a production packaging decision.
