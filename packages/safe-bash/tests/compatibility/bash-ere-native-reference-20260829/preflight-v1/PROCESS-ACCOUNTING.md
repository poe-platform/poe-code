# Preparation process and resource accounting

This is the fresh 20-minute / 40-known-start / peak-three preparation grant,
not the proposed 600-second actual-reference grant. No runtime authority issued.

Known direct starts through the twelve-control run: twelve tool-shell starts and
nineteen explicitly requested utility/helper starts (31 total). Utilities comprise
two cats, one find, one sed, two Git metadata calls, one mkdir, four apply_patch
invocations, and eight Node invocations. Instruction reads are context only and
are not copied into evidence. Node invocations: inspect syntax/body, materializer
syntax/body, qualifier syntax/failed body, qualifier R1, controls. The failed
qualifier retired before any controls ran.

Publication reserves seven additional known direct roles: one tool-shell,
apply_patch, publisher syntax/body, Git diff-check, commit, and full-hash lookup:
**38 known direct roles**, below 40. They execute sequentially; peak two explicit
roles (tool shell plus utility), with peak-three allowance for an editing-tool
implementation helper. This is a known-role ledger, not an OS-wide census or a
kernel process quota; tool implementation internals are not represented as native
case forks. No fixture children, Bash children, engines, Workers, or subagents.
Git hooks, signing, fsmonitor and automatic maintenance are disabled for the
publication commit to avoid unrelated hook/tool launches.

Captures are per-invocation files. The admitted helpers are bounded to small
regular text inputs and stream-hash only the four already pinned tools. No tool
binary is buffered wholesale/decoded. Tool binary reads are not copied into
working storage. Final exact publication bytes and closed capture totals appear
in PUBLICATION.json, against 256 MiB work / 64 MiB capture. No runtime namespace
or GO was created. All temporary DATA descriptors close; the only scratch
directory is removed after the single control run. Preserved evidence is owned
publication, not leaked scratch. No cleanup of historical archives was attempted.

The twelve controls ran from epoch milliseconds 1787995640750 to 1787995640802
(52 ms owner wall time; not a native performance benchmark). Their internal
120-second finite DATA cap is not a reset or extension of the encompassing grant.
Initial context reads precede the first captured helper; raw capture filesystem
timestamps and publication timestamp provide preparation chronology, not a claim
of an externally enforced all-process deadline. All administration/publication
belongs inside the encompassing grant.
