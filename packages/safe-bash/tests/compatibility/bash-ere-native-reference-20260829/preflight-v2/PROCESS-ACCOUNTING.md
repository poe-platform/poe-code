# Fresh correction-grant accounting

Root allowance: 12 minutes including publication, 32 known starts, peak two,
32 MiB capture and 128 MiB working storage. No native/fixture children are allowed.

Known direct roles through controls: 12 starts. First tool command: shell, cat,
Git status and Git cached-name metadata (4). Preparation command: shell, sed,
apply_patch, mkdir, Node syntax and Node prepare (6). Control command: shell and
Node controls (2). The Node controls helper starts no children.

Publication command reserves eight more: shell, apply_patch, Node syntax, Node
publisher, Git add, Git diff-check, Git commit and Git full-hash lookup. Total:
**20 known direct starts**, peak two explicit roles, sequential tool commands.
This is a known-role ledger, not an OS-wide census or kernel process quota. Editing
tool internals are not represented as native case processes. Git hooks/signing/
fsmonitor/automatic maintenance are disabled for publication.

The preparation deadline is constructed once from the first syntax capture's
creation time, conservatively charging two minutes before that capture, plus the
12-minute allowance. It is sealed in CONTROL-PRESEAL.json and checked again by
publication. There is no retry, old-clock renewal or active native grant. The
single control helper also has its existing two-minute DATA cap; it completed
within the encompassing deadline. The twelve controls ran from epoch milliseconds
1787996061129 to 1787996061173 (44 ms), not a native timing benchmark.

All syntax/helper processes start with outer-owned file captures already opened.
The Node binary and other three admitted tools are stream-hashed using a 1 MiB
buffer; their binary bytes are not copied into work artifacts. Actual control
scratch contains only owned regular files and an empty directory, all removed.
Every descriptor closes; no Worker, Bash, engine, fixture child or lingering timer
exists. No runtime namespace, GO or approval request is created.

PUBLICATION.json records exact final work/capture bytes and hashes. Its own live
stdout/stderr are excluded from recursive self-hashing and retained as commit-bound
raw capture after the publisher retires. Historical v1 artifacts are rechecked,
not deleted or rewritten. Instruction reads remain context-only, outside evidence.
