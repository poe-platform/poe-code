# Fresh activation-preparation accounting

Fresh allowance: 15 minutes including publication; 32 known OS starts; peak three;
32 MiB capture; 128 MiB work. No native/entry/approval call is permitted here.

| Batch | Known starts | Roles |
|---|---:|---|
| Context/index inspection | 4 | tool shell, cat, two Git metadata calls |
| R0 metadata preparation | 6 | shell, apply_patch, mkdir, Node syntax/body, one Git child |
| Corrected R1 retrieval | 6 | shell, apply_patch, Node syntax/body, two Git children |
| Committed non-runtime receipt | 3 | shell, Git size, Git blob |
| Existing protocol/template read | 1 | shell builtins only |
| Authority preparation | 4 | shell, apply_patch, Node syntax/body |
| Publication | 8 | shell, apply_patch, Node syntax/body, Git add/diff/commit/hash |
| Total | **32** | all known direct roles, no native/fixture children |

Peak three occurs only during a metadata Git child beneath Node beneath its tool
shell. Calls are sequential. This is a known-role ledger, not an OS-wide census
or enforcement quota; source/runtime fork reservations are separate. Git metadata
children use five-second bounded synchronous waits with pre-opened raw captures;
all returned normally. Their actual retirement is separate from the R0 helper's
subsequent incorrect EOF assertion. Publication hooks/signing/fsmonitor/automatic
maintenance are disabled. No subagents, Workers, Bash, engines or fixture children.

The single preparation deadline derives from first syntax-capture creation time,
with two minutes conservatively charged before that marker, plus 15 minutes.
It is recorded in PREFLIGHT.json and checked through publication. No old clock
was renewed. The 45-minute issued GO is a separate fixed activation validity
window, not extra preparation time or current native execution authority.

All Node syntax/helper calls have outer-owned captures established before launch.
Binary tools are stream-hashed and never decoded or copied into work storage.
Physical staging has four owned directories and one zero-byte journal. No process
is attached to that staging. Exact artifact bytes, capture bytes and source hashes
are published; active publisher stdout/stderr are excluded from recursive self-
hashing and retained as commit-bound raw files after publisher retirement.
