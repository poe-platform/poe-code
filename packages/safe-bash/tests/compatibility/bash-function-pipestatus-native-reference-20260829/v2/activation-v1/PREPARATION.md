# Native26 authorization binding preparation

This is the fresh ROOT-authorized binding phase, not native activation. The
initial capture birthtime anchors 10 minutes including publication; limits are
24 known starts, peak2, capture32MiB/work128MiB. All old holds and the prior
review's >=52/48 noncompliance remain historical and are not rescored.

`bind.mjs` runs once after a separately captured syntax check. It admits the
accepted independent receipt SHA0233f450... and author executable/ready seals,
authenticates every listed file before decoding metadata, and stream-hashes the
four existing tools. It imports only authenticated admission.mjs, never entry or
lifecycle, and owns no child processes. No Bash, version probe, Worker, product,
native observation or tool approval request may run.

It refuses an existing actual root and creates only the declared physical root,
outer/cases/captures parents and empty0600 JOURNAL.jsonl. Bootstrap stdout/stderr
must remain absent because the sealed noclobber wrapper creates them and opens
read-write FDs later. Their future inode/FD identity cannot be claimed now.
The runtime retains its exact positional-read/type/mode/inode guards.

Only three predeclared runtime slot files are created: REVIEW-ACCEPTANCE.json,
PREPROVISION.json, GO.json, all exclusive0600 writes with fsync/close and owner
checks. Authority is acyclic: authenticated independent receipt -> runtime ROOT
review projection -> fixed-window GO -> sole hash-slot command resolution.
The command/args/environment/entry/modules/scripts are not rewritten.

Fresh UTC issuance is recorded once after admission/provision; expiry exactly
2700000ms later, latest full-window start expiry minus600000ms. No renewal. A
separate reviewer must inspect resolved bytes before any later actual request.
The helper records exact objects, modes, source/tool bindings, all closed owned
FDs and preflight result, and preserves raw captures before assertions.
