# Bash reference feasibility: metadata-only preseal

Date: 2026-08-29. This sidecar is not the Faraday oracle provider and grants no
Bash/version/compiler/configure/make/patch/GPG execution. Product runtime
dependencies, public exports and other review scopes remain untouched.

ROOT ceiling: 30 minutes including publication/cleanup,64 all owned starts,
peak3,128MiB capture/256MiB working. The local survey is one self-contained
Node controller with no children and a120s sub-cap. It examines only the
explicit paths in survey.mjs, without directory enumeration or a home/private
crawl. It reads regular executable files only as bounded hash streams; it never
decodes them. Per-file256MiB and cumulative768MiB read ceilings do not claim
RSS or native execution bounds. Hash stream chunks are64KiB; metadata capture
is capped4MiB. Oversized/unadmitted targets stay explicitly unqualified.

The dispatch shell establishes stdout/stderr capture before loading survey.mjs.
The controller creates STARTUP.json before any candidate/tool lookup and owns
catch/finalization. No cross-call REPL state supplies launch authority. Every
path records absent/present/link/unadmitted and, where admitted, stable mode,
size and streaming SHA256. Neither pathname nor bytes prove executed version.
Instruction reads stay context-only and are not copied into evidence.

Official GNU website/directory/announcement and signature metadata reads are
separate PRIMARY web observations. No source archive or binary is acquired,
and no downloaded code executes. Web timeouts remain access failures, not
missing-release/security findings. A final proposal must distinguish source
provenance, cryptographic verification still needed, executable version still
unknown, and future provider/fence/runtime qualification still unrun.
