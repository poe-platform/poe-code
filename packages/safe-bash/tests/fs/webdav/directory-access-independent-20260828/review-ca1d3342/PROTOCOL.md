# ca1d implementation review protocol v1

This is post-source-inspection runner binding, not a new precode claim. The seven
original c65 files and all 102 case expectations remain immutable. ROOT routed
ca1d source and 899 evidence; no source or runtime change is authorized here.

Composition is complete5137 src plus original package/package-lock/build configs
and README, with ONLY webdav.ts and its README replaced by the declared ca1d
blobs. Composition archive includes regular-file bytes/modes, commit raw objects,
source tree proofs and the derived full Git tree identity. It does not import the

inputs copied verbatim; dynamic world generation and public await instrumentation
implement the existing protocol without changing outcomes. No actual service.

## Execution and ownership

prepare.mjs copies authenticated local Node/TypeScript/npm/Node types/undici types
as regular files into this version's scratch only. Full tool membership/modes and
hashes are pinned before build. No runtime dependencies, scripts or downloads.
Build uses the unchanged baseline tsc configuration and the complete src closure.
Npm pack/install use offline/ignore-scripts/no-audit/no-fund, isolated HOME,
config/cache/TMPDIR. The original package manifest/exports remain byte-identical.

All 102 run separately against composed TypeScript source, an actual npm-installed
complete public package, and the same consumer/package physically renamed to a
different path with the original absent. Source mode uses a sealed TypeScript
transpile loader for .ts; installed/moved use normal bare public package resolution
and reject any source fallback. The loader hashes every loaded module and checks
file membership before reading. This loader is an audit boundary, not a host JS
security sandbox. Public root and WebDAV export class identity must match.

Both original and polarity-inverted frozen type controls run with strict exact
optional semantics: original consumer zero diagnostics, each of ten inversions
exactly TS2344 at its own line. Missing imports are never a successful negative.
Installed/moved compile against actual declarations, without source aliases.

## Failure and cleanup rules

Each call has an eight-second guard; parent children have a finite watchdog.
Mock bodies are HWM0 streams with exact original pull/cancel schedules. Late
fetches are explicitly released after outward settlement, then observed. An
ordinary assertion mismatch may continue only after all current streams, deferred
fetches and calls are terminal and unhandled-rejection count is zero. Guard/leak
failure stops that layout and marks remaining cases blocked. No cleanup failure
is relabeled an ordinary oracle mismatch. Parents retain stdout/stderr/status
even for failed children; failures are never overwritten by a corrected run.

The original 102 are always reported as their original results. If an oracle is
wrong, preserve its raw failure and bind a separately labeled corrected control.
No original expectation weakening. Five exact source mutants cover admission,
final cancellation, raw path bound, output bound and response identity; each
requires its candidate witness to pass first. Loader errors are not mutant kills.
Three load-admission negatives separately prove outside-source, hash-tampering
and missing-entry refusal; they are not provider behavior tests.

Eight invariants are mapped in final evidence: request traces/flags/errors/resource
counts are measurements; absence of ACL/lease/future-access promises and future cd
requirements also require source/doc review and are not universal runtime proofs.
No cd runtime, directory-stack, native oracle, SafeJS runtime, service or broad
680/108 cohort executes. Root retains release and stage2 runtime authority.

## Reproduction and seals

Drivers/controls/composition/tool bindings are committed before candidate execution.
run.mjs accepts no moving source inputs. Its materialized source is checked against
composition.json.gz before execution; all import/type closures are checked against
that materialization or the produced artifact. Reproduction needs the archived
selected bytes and matching pinned local tool bytes, not loose Git source objects.
Do not reuse an existing run directory or overwrite evidence. Reproduction after
handoff requires a new authorized evidence version; original seals are immutable.
For a separately authorized clean copy of the pre-execution driver commit, run
`node recreate.mjs`, `node verify.mjs --pre`, then `node run.mjs` from this directory.
recreate uses composition/FROZEN archives plus exact pinned local tool bytes, not
Git source objects; changed/missing tools fail instead of falling back/downloading.

The append-aware verifier compares original parent membership excluding ONLY this
exact review directory; it authenticates this directory separately. It never
edits/runs the old append-rejecting verifier against a changed source baseline.
Unknown additions, symlinks and modified originals fail. Scratch is explicitly
enumerated/hashes sealed before cleanup; after durable evidence is verified the
exact owned scratch root is removed and its absence recorded. Live-source
preservation is measured separately from historical composition equality.
