## Declared host boundary and remaining requirements

Provider-marked metadata asserts the backing used by content operations. A remapper
or cache must omit/rebind old provenance when changing that backing. Forwarding
MockMap provenance but accessing another local resource violates that contract.
Faithful Memory/Real/WebDAV aliases remain legitimate and must preserve bytes.
Function identity is not a sandbox for host-supplied JavaScript.

HTTP serialization/Response cloning does not carry the private Map observation.
Strict RFC resource identity can compare qualified WebDAV resources, but UUID
versus native/Memory identity is not mixed-store disjointness. Generic HTTP/SDK
binding remains OPEN. Existing optional compareEntry can supply actual host-owned
peer/path authority; no new API is implemented. Source TOCTOU/ABA/snapshot and
remote empty-only-rmdir limits are unchanged. No rmdir/SGID scope expansion.
