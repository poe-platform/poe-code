imports, loader threads, Workers, installs or tests. No AGENTS materialization.

no dist input. The producer writes only its new unique owned root.

individually hashed regular-file row. No general symlink/outside-import policy
is granted. These aliases are not executed; child-process permission is absent.
Node permission mode grants only owned-root file reads/writes and the admitted
Node binary read. Child-process/Worker/addon permissions are not granted.
Offline operation relies on the trusted pinned npm local-pack route; this is
NOT an OS network sandbox or untrusted-tool guarantee. No network is requested.
