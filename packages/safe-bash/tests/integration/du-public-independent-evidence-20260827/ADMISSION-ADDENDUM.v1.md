# Version 1 additive admission policy

## Distinct mode and unchanged contract

The authorized new literal is **scoped-committed-archive**, not committed-archive.
It means the entire explicitly selected committed build/fixture input tree,
authenticated by the pinned handoff's complete771 entries and exact selector.
It explicitly does not mean full-history or entire-repository archive proof.
The original `binding-contract.mjs` accepts only committed-archive/strict-live;
the old static verifier also rejects extra files. Neither file is changed, copied,
patched, evaluated or bypassed with a temporarily relabeled mode. This wrapper
is a preparation inspector, not an adapter implementing `assertReplayBindings`.

All original common requirements survive. The original schemaVersion1 replay
state, exact fixedScope, exact required-key set, nonnull identities, unique safe
source paths/blob/hash bindings, HTML74 checkpoint and exact74 names, root-approved
exact75=HTML74+du (HTML required; getopts builtin; curl/SafeJS optional; no expr),
aggregate option identity/property, exact diagnostics, all eight lifecycle
identities, independent supervisor, versioned tools, post-run new-entry detection,
and candidate/freeze-bound root authorization remain required. README obligations
also survive: approvals/authenticity beyond shape, full input completeness,
actual tarball, real install and physical move, actual ESM-load bytes and public
resolutions, compiler resolution, unchanged fixtures, guard controls and all29
reconciliation. The original diagnostic requirement includes status1, empty stdout
and exact unknown-allocation stderr. No structural assertion is acceptance.

The mapping records author assertions without promoting `declared75Inventory`
to approval, `authorSupervisor` to independent supervisor, or author HTML evidence
to accepted HTML74. Version1 intentionally cannot dispatch any replay. A future
implementation must preserve these common checks without passing the new literal
through the old function, and must be separately reviewed/frozen before execution.

## Specific preservation findings

The original binding function checks shape, not authenticity or actual HTML
acceptance; its README provides those stronger obligations. The handoff has
declared names and author evidence, not root-approved bindings. The eight policy
sections explain mappings but explicitly leave overlapping disposal and sibling
holdouts for independent work. The author supervisor's ambient dependency copy
and external temporary writes do not satisfy this recipe, so it is authenticated
as reference only and must not be silently reused as the future executor.
Version1 freezes these limitations instead of inventing an authorization schema.
