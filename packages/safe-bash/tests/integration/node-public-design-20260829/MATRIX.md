## Types — planned, not compiled

- Positive T01 root imports/options/provider contract; T02 exact subpath and
  NodeCommandsOptions assignability; T03 concrete engine default export contract.
- Negative T04 missing provider/wrong profile/async prepare or wrong session shape;
  T05 invalid grants/replace/limit overrides; T06 extra Worker options/private
  subpath or exported-private-internal attempts. Expand into exact diagnostic
  identities at preseal, not arbitrary compiler failure.
- Match exact consumer path/location/code/export and no unexpected diagnostics.
  Success means intended diagnostics/success with noEmit and observable output
  integrity, not emitSkipped===true or a universal CLI exit2 convention.
- Validate all public declaration dependency closure from the actual package, not
  a workspace alias; source/installed/moved receipts remain distinct.

## Finite loaded controls — planned

M01 remove subpath/export; M02 wrongly add node to aggregate; M03 ignore collision
replacement; M04 fake entry-return/no real guest execution. Each mutant must be
actually loaded, fail its targeted test and restore exact bytes before the positive
companion. Never mutate the original module acceptance evidence. Also reject
missing/changed package/source/adapter binding; controls must distinguish an
admission failure from guest semantics. Engine-authority tampering uses harmless
owned fixtures, not private code, network or unbound tools.

## Execution admission and observation boundaries

- No actual launch now. Reuse qualified loader policy only for byte-identical
  components. Predeclare internal-loader admissions separately from application
  Node and Regex Workers; no blanket worker grant. Bind source maps/declarations,
  package entries, static Worker URL/options and trusted adapter/engine closure.
- Outer capture must exist before admission/bootstrap; enroll owned child/listener
  state before fallible helpers. Scope all OS/tool/compiler/npm/admin children and
  Worker starts within the future explicit budget; nodeLimits.admissionMs is not
  the test campaign timeout or cleanup budget.
- Offline scripts-disabled build/pack/install and physically move the package;
  original install must become unusable. No native-Node oracle, private engine,
  package discovery, ambient engine imports or fallback. Approved engine is supplied
  explicitly, externally authenticated, not vendored into product/tests by this design.
- Retain actual raw exits/captures/errors/effects, exact loaded paths and declared
  postguards. Distinguish constructor/start/refusal, guest entry, entry return,
  application Worker exit and host cleanup. Internal-loader individual exits may
  remain unobserved; process retirement does not substitute for an acquired
  application Worker's required retirement.
- Preserve author-v5 historical171/183, old loop/diagnostic observations and all
  earlier holds. No new result here; no global/live-HEAD/Node-native certification.
