in one known bounded child at a time. The original cached TypeScript source loader

outside owned log/TMP paths; they do not pretend to be an OS sandbox. All guest

The actual statement/Promise controls and exact error outcomes are frozen, not
calibrated by a preliminary guest. Invalid syntax or unreachable predicates are
preserved as invalid/unproved, not security passes. Missing positive prerequisites
or failure containment stops subsequent admission as the plan requires.

and at finalization: additions, removals, bytes, file metadata and symlinks are
checked. Empty-directory additions are not detected or described as append-proof.
