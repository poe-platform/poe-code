## Twelve grouped executable obligations

E01 inert owned preparation: one options lookup, zero native controller/listener
acquisition, no parent capacity reservation; original options/control/snapshot
copies survive caller mutation before activation.

E02 admission: ancestor pre-abort skips getter; staged exact getter/brand/container
failure and parent-close precedence; invalid owned snapshots fail without resource
acquisition. Ordinary caller getters/proxies are not claimed side-effect-free.

E03 TEST-LOCAL synchronous registrar: registration precedes every activation
acquisition; failed registration leaves preparation inert. Idempotent local cleanup
closes the acquired boundary. The helper cannot enforce arbitrary host registration.

E04 deferred activation: parent closure/abort and local/control pre-abort rechecked
before resources. Ancestor > local invoke > configured pre-observation controls.

E05 one-shot activation: success, borrowed success and failure consume preparation;
every repeat throws that preparation's stable replay error, without reacquisition.

E06 omitted/explicit undefined/absent signal without controls: borrowed activation,
no cancellation resources, supplied snapshot ignored, borrowed close not parent close.

E07 nested controls: ancestor lineage and original signal/role/frame survive;
observed first delivery differs from invoke settlement rank; control-only frames
do not invent invoke-option rank; exact control failure resists invoke replacement.

E08 conservative selector: unproven equal/falsy/NaN escaping throws stay unrelated;
authentic observed origin is obtained only from subscribeCancellation, not guessed
from reason. Trusted origin assertion permits invoke ranking. Root caller wins;
accepted Stage1 selector remains unchanged. Undefined uses the disclosed inherited
native-branded own-reason fixture, not ordinary abort(undefined) semantics.

E09 descendant report: exact target/reason route accepted; wrong sibling target,
missing report and mismatched reason do not authenticate. No reason-keyed records.

E10 close: fixed outcome despite later ancestors, stable close identity, exact
ordered callback failures including undefined, dormant control listeners detached.

E11 partial initialization failure: admitted listeners/subscription rolled back,
exact primary failure retained, replay consumed, parent capacity reusable.

E12 finite admission: owned controller plus non-aborted local/control listeners,
separate parent subscription capacity, no reservation in preparation, activation
capacity recheck, closed child capacity reusable.
