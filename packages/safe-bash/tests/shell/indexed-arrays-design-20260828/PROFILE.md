## Foundation: proposed first useful profile

| Concern | Proposed behavior / explicit gap |
| --- | --- |
| Representation | Internal discriminated scalar/string versus indexed/Map<number,string> binding; never JSON or sentinel strings in variables. Store kind, attributes and sparse entries; no dense allocation by maximum index. Keep absence, empty array, missing element, and present empty string distinct. |
| Creation | Support assignment-only arr[2]=value, arr=(values), arr=([2]=value value), arr+=(values), and arr[2]+=value. Preserve scalar arr=value/arr+=value as element-zero operations once indexed; scalar-to-indexed conversion retains the prior scalar at zero unless compound replacement clears it. |
| Literal indices | Recommend syntax 0 or [1-9][0-9]* and range 0..2147483647, with single/double-quoted literal digits accepted as syntax, not evaluated strings. Reject signs, leading-zero multi-digit forms, whitespace, empty indices, interpolation, substitutions, base notation and expressions. Ceiling is a proposed virtual profile, not Bash's limit or an existing contract. |
| Sparse order | Enumerate ascending numeric keys, not Map insertion order. Implicit compound indices follow the previous explicit index; append starts at old maximum+1. Replacing/deleting entries updates count, retained bytes and maximum; removing maximum may scan only existing entries with charged work, never the numeric range. |
| Negative indices | GNU A supports relative negatives, including assignment/unset. First profile refuses them; no wrapping/clamping. Later support must resolve maximum+1+index once against the correct binding, then reject a still-negative result. Arithmetic modification must not re-resolve after a write. |
| Read expansion | Add actual subscript AST for ${arr[2]}, ${arr[@]}, ${arr[*]}, ${#arr[2]}, ${#arr[@]}, ${#arr[*]}; scalar references remain element-zero-compatible. Keep missing-element expansion distinct from present empty in internal state. |
| Quoted aggregates | GNU A: quoted @ produces one field per member and zero for no members; quoted * joins into one field with the first IFS character. Prefix joins first member, suffix last. Proposed empty * remains one empty field; unset IFS uses space, empty IFS uses no separator, consistent with current positional policy. Empty @ with surrounding literal text retains that text. |
| Unquoted aggregates | Feed element boundaries through existing splitting/globbing semantics, not a flattened JSON/string sentinel. Freeze field-boundary cases independently; no dotglob change. |
| Length/bytes | Element length retains current Array.from Unicode-code-point policy; member count is not maximum+1. Preserve quoted string content and existing UTF-8/NUL policies, without promising arbitrary binary shell strings. ByteSource payload ownership remains Uint8Array. |
| Deletion | GNU A distinguishes unset arr (remove binding) from unset 'arr[2]' (element), and unset 'arr[@]'/'arr[*]' (clear members, retain kind). Last-element removal retains array identity. Reclaim charges and maximum metadata; readonly blocks all four. Quote arguments to avoid pathname expansion. |
| Attributes | Readonly is binding-wide, never an independently mutable element flag. Foundation supports readonly arr after creation and local arr with typed save/restore; -a declaration options are later. Empty arrays retain attributes; whole unset removes eligible attributes. Root must freeze shadowing an outer readonly binding without weakening today's local refusal. |
| Scope | Implicit writes target the visible dynamic binding; otherwise create global bindings unless explicitly localized. Save kind, members, export/readonly and existing OPTIND metadata in SavedVariable/locals. Restore exactly on return/error/cancellation, including local unset. Source/eval share the active binding frame. Child/subshell/pipeline/substitution/invoke isolates mutable maps via admitted copies or genuine COW; new Shell.exec starts fresh. |
| Prefix assignments | Retain scalar ordering/restoration before builtin/function/registry command and local's transfer from temporary assignments. Recommend initially refuse indexed/compound prefixes before any command with status 2 before expansions/redirections; do not silently export arrays. This is an explicit profile gap, not Bash parity. |
| Export boundary | dispatchScoped's exported-env loop (runtime.ts:1380), middleware overlays, invokeScoped replaceEnv and interpreter/script state remain scalar records. Retain array export attribute if needed for later removal/conversion, but never serialize arrays or implicitly export element zero. Reject reserved scalar-control-variable conversion initially (PWD, OLDPWD, PATH, IFS, HOME, OPTIND, OPTERR, OPTARG); exact list needs root approval, including locale controls. |
| Exclusions | Associative arrays, namerefs, multidimensional syntax, indirect/index-key expansion, array slicing/pattern/default/assignment parameter operators, integer/case-conversion array attributes and arithmetic indexed lvalues are refused, not accepted as successful no-ops or literal variable names. No new builtin advertising in foundation. |

### Errors, admission and root decisions (not implemented)

- Syntax/profile forms: use existing ShellSyntaxError status 2 at parse time where syntactically knowable. Runtime invalid index/readonly: CommandFailure status 1 or the existing assignment Flow policy, with human-readable path/line diagnostics. Unsupported builtin options: status 2. Preserve current expansion-fatal and sh-special distinctions, cancellation precedence and ShellLimitError behavior; do not flatten all errors into 1 or errno text.
- Existing Budget (runtime.ts:29,62) counts commands, loops, source and output; expansion bytes/fields are mainly per-word checks. It does not admit aggregate persistent variables, saved maps or clone metadata. Command count is not a retained-state bound; maxOutputBytes in read is a per-line limit, not array storage admission.
- Root contract proposal: one invocation-shared internal ledger, no new public options initially. Cap simultaneously retained array values/name bytes by maxExpansionBytes and entries/binding/saved-frame metadata units by maxExpansionFields; count empty entries. Cap cumulative array index/entry/clone work by a root-ratified finite derivation, proposed 4*maxExpansionBytes+maxExpansionFields with safe saturation. Separate the index ceiling from these caps. All phases/children share the ledger, never reset it per element or builtin.
- Reserve before string concatenation, sparse entry creation, field-array push, sorting scratch, COW detachment and clone/saved-state retention. Charge actual owned copies and transient join capacity; immutable shared values need truthful reference accounting. Quoted @ checks count before allocating fields; * computes admitted size before constructing one joined value, without a second uncharged whole payload. These are logical accounting limits, not RSS proofs.
- Check cancellation at entry and bounded source/entry checkpoints; keep synchronous index work bounded. Publish errors through existing invocation cleanup/settlement paths. Preserve completed effects, observe late failures, and reject stale binding identity rather than reevaluating expansion on reentrancy.
- Compound failure policy remains a root blocker: recommend parse all syntax first, then sequential visible element writes (replacement clears after target validation), retaining earlier writes if later RHS/bounds fails. Do not claim Bash transactional or partial-error parity. Alternative staged all-or-nothing binding publication costs additional admitted storage and still cannot roll back RHS effects; approve one policy before code.

## Later stages, separately authorized

1. Declaration stage: declare-a/typeset-a/local-a/readonly-a use the same mutator and real declaration AST, with function-local default, explicit -g decision, and readonly applied after permitted initialization. Unknown options/attributes refuse. Display serialization and -p require their own accurate shell quoting, not JSON output claimed reusable. Existing scalar builtins remain compatible.
2. Mapfile stage: a shell builtin writes parent bindings; ordinary registry modules receive scalar env and cannot implement that contract. GNU B specifies default MAPFILE, -t removes trailing delimiter, -n bounds lines (0 means all), -s skips lines, -O starts at origin (default zero), -d uses first character (empty means NUL). readarray is a synonym. No explicit -O clears the array; explicit origin preserves other entries. Reject -C/-c and initially -u before input acquisition; callbacks/host FDs are not simulated.
3. Before that stage freezes: specify UTF-8 versus byte-delimiter policy (initial ASCII/NUL is an explicit potential gap), delimiter retention when -t is absent, empty lines, final unterminated record, empty EOF, ignored NULs outside NUL-delimited mode, index fill versus append, count/skip limits and origin overflow. Preserve read-ahead remainder for subsequent consumers and distinguish borrowed from owned input; producer-buffer reuse must not corrupt stored lines. Pull only as downstream admission allows, with backpressure/cancellation and existing read limits; prevalidate target/options/readonly before acquiring input. Freeze truncation timing and source-error partial state after foundation, not here.

Read-only test-source support: at the bound 5137 revision, tests/shell/variable-scope.test.ts:6 declares prefix/export/local restoration cases; tests/shell/positional-ifs.test.ts:6 declares unset/empty/multicharacter IFS joining cases. They were read, not run; their embedded native-oracle calls were never invoked. Preserve those scalar cases and add independently specified array cases only after authorization.

Independent review prerequisites: exact approved source composition, declared exclusions/error classes, scope/alias identity and mutation-order cases, sparse high-index/empty-field/Unicode cases, preallocation and clone charges, readonly/no-read-on-argument-error, reused-buffer/read-ahead and cancellation settlement cases. All execution requires a new explicit release; no harness or acceptance is supplied here.
