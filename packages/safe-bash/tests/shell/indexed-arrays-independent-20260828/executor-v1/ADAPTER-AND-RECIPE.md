source. It invokes actual public Shell/MemoryFileSystem, checks argv/status/bytes,
after-members and side effects, and disposes every instance. These bodies have
**not run on arrays**. O11's fatal ParameterExpansionFailure exits127 in the bound

## Reviewer-only adapter contract (no product API request)

Stage one reviewer-authored ESM adapter inside the isolated harness, censused and
hash-bound like all other control files. It exports:

```text
candidate: exact40-char integrated candidate commit
supportedIds: explicit implemented IDs, never a catch-all
observeTerminalState(shell, O11row) -> { after(): indexed [index,value] pairs, close() }
execute({id,row,api,manifest,emit}) -> {
  category: 'actual-candidate-mechanism' | 'candidate-source-proof',
  assertionsCompleted: true, disposed: true,
  requiredLoads: [{path,sha256}], ...measured traces/source evidence
}
```

`observeTerminalState` must capture the **executing** invocation state at terminal
failure and restore its test instrumentation on close. A bound Runtime.runUnit
observer is one possible location; the eventual private state representation must
come from the candidate, not be invented now. It may use a separately labelled
instrumented copy; no public Shell option, getter or production testing hook is
requested. A returned copy of the expected row is forbidden.

`execute` contains independent assertions against the unchanged M/P requirements;
the returned completion flag is a receipt from those assertions, not itself a
proof. Every private module it cites must appear in the actual load-hook records.
Assertions reject ordinarily after owned cleanup; cleanup/integrity failures carry
`unsafe: true` and stop the cohort. No inherited opaque host promise ownership.
Adapter source, hook placements, source/instrumented deltas, and the assertion
mapping must be sealed additively before use. Current author helper094d2ba1 alone
does not supply these integrated bindings and has not been inspected here.

Near-ticket-end and small reference-graph tests may inject exact counter states
into labelled copies. Record that injection, source hashes and actual constructor/
helper calls. Do not label it a naturally reached public-input boundary, lower
private caps, or treat E_command allocations as private. Public boundary checks
use actual configured B/F and distinguish an earlier parent Budget failure.
