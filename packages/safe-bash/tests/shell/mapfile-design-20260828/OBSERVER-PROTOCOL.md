## Required NEW supervisor controls — do not reuse the old one

The old array observer's five static gaps remain unchanged, not newly observed
escapes. A future implementation must prove each correction with synthetic
fixtures before ROOT separately authorizes native recipes:

1. **Finite terminal path:** deadline covers missing close and group-survivor
   polling. Never wait indefinitely after signalling. Distinguish actual close,
   terminal deadline and uncertain survivors; stop rather than claiming reaping.
2. **Complete integrity:** admission manifest includes observer/config/ROOT
   authorization/seals/rows/source identities. Authenticate before every launch
   and again after the final row and cleanup; catch final-row drift/new entries.
   No log/live-source whitelist that silently permits protected drift.
3. **Directory ownership:** register prospective unique path/cleanup authority
   before mkdir, mark successful acquisition immediately, then inspect identity.
   If inspection fails, do not delete a replacement/unowned inode. Report the
   retained path/uncertainty explicitly and stop; never leave it unaccounted.
4. **Launch accounting:** irreversible in-memory launch-attempt record exists
   before spawn; record actual PID/spawn event independently from durable receipt
   writes. Inject post-spawn write failure: launched row remains launched, group
   is terminated/observed, and it is not labelled unexecuted or retried.
5. **Honest close events:** synchronous spawn throw and async spawn error do not
   synthesize a child-close event. Track attempts, successful spawn, actual close,
   cleanup and status separately. Error controls cannot count phantom executions.

Also require stdout/stderr overflow, whole-run admission expiry, missing native
hash, absent/mismatched ROOT authorization, late stream rejection, attempted
outside-root receipt, replaced fixture entry and natural-success controls.
No native cases during supervisor controls; synthetic workers are separately
authorized task-owned implementations, not an excuse to run the old supervisor.
