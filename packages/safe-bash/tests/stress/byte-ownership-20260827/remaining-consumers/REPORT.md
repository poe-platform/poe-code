## Defect 1: jq program-file aliases survive source finalization

- Public repro: `jq -f /program /input`, through packed `Shell` and
  `structuredCommands()`.
- `/program` is `.x` (`2e78`); immutable `/input` is `{"x":7}\n`.
  VFS chunks are `.`, empty view, `x`, sharing an offset Buffer window. The
  producer zeros its window only when its finalizer runs after the last pull.
- Expected: status 0, stdout `7\n` (`370a`), empty stderr, no FS changes.
- Actual: status **3**, empty stdout, stderr
  **`jq: unexpected character at offset 0\n`**, no FS changes.
- Retention path: `src/commands/structured/jq.ts:81` stores
  `chunks.push(chunk.slice())`; `:88` concatenates after producer completion.
  Buffer.slice aliases the producer; native Uint8Array.slice copies. Both
  fragments become zeros before parsing. Native control passes unchanged.
- The earlier raw/JSON routes detach to strings/values and pass; this is the
  separate program-file consumer, not another common collect-helper row.

## Defect 2: curl mixed-body replay caches VFS Buffer aliases

- Public repro:
  `curl -sS -L --data-binary @- --data-binary @/upload https://fixture.invalid/start`,
  packed `Shell` with explicit `networkCommands({ authorize, transport })`.
- Shell stdin is immutable `S`. `/upload` bytes `a0ff00c3280a` arrive in reused
  Buffer views `a0ff`, empty, `00c3`, `280a`. The injected trusted transport
  copies each received body chunk before the next pull and NEVER mutates it.
  It returns one 307 to `/next`, then one 200; no socket or external upload exists.
- Expected both POST bodies: `5326a0ff00c3280a` (`S&` + payload).
- Actual first body: **`5326a0ff00c3280a`**; actual second body:
  **`5326000000000000`**. Command still reports **status 0**, empty stdout/stderr.
  VFS `/upload` stays exactly `a0ff00c3280a`.
- Both hops are authorized, including the exact redirectFrom binding. Each
  response is disposed once. The VFS source opens once, fully resumes and
  finalizes; its guard/no-mutation checks pass. Native Uint8Array control replays
  the expected body on both hops.
- Retention path: `src/commands/network/body.ts:142` caches `chunk.slice()` when
  `hasStdin` is true, including VFS chunks belonging to other body parts;
  `:124` yields cached slices later. Buffer entries still alias finalizer-zeroed
  storage. Shell InputCursor's initial stdin copy does not protect these VFS
  entries. No claim is based on an illegal transport mutation.

Public contract basis for both findings: ByteSource/FS readStream are shared
Uint8Array iterable APIs, with no stated transfer for these operations;
readBytes advances only when its consumer requests the next item. The project's
accepted producer-reuse convention requires retained fragments to be owned before
next/finalizer, now explicit in current AGENTS.md. Curl's custom transport contract
requires byte preservation, backpressure, signal respect and disposal, all honored
here. Findings do not imply arbitrary concurrent host-JavaScript mutation safety.

The requested findings marker was written synchronously as each reproduction was
observed, before subsequent matrix rows. Its verbatim retained copy is
`evidence/first-findings.txt`.

## Preserved fixture mistake, not a green rewrite

The jq abort fixture calls `controller.abort(reason)` in afterRead but does not
throw. Its generator therefore proceeds to yield the next (empty) view before
readBytes closes it. Actual state is `{yielded:2,resumed:1,finalized:true,
unchangedChecks:2}`; the frozen assertion wrongly expected yield/check counts 1.
Exact caller reason identity, empty accepted output and unchanged files were
asserted before that mismatch. Finalization is visible in the assertion's actual
state. This does not establish an extra product bug or a passing test row.
No fix/re-run was made. The cancellation row remains a raw failure and does not
certify general cancellation behavior.

Two pre-freeze utility guards also rejected HEAD drift and a newly created foreign
directory before writing a freeze. Both are recorded under preparationErrors;
neither executed product tests. The concurrent `direct-curl/**` subtree was
excluded from this leaf's explicit fixture/staging list and left untouched.
