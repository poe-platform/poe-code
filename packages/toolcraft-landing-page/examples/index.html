Define a command once. Run it everywhere.

acme ships your operations as a terminal CLI, an MCP server, and a typed SDK — from a single command tree.

$ npm install -g acme

One definition

Every surface, no duplication

The same command tree powers all three runtimes. Schema, secrets, and approvals are declared once and inherited everywhere.

CLI

argv parsing, --help, exit codes.

# terminal
acme deploy prod \
  --target api

MCP

JSON-RPC over stdio for agents.

# claude desktop
acme mcp

SDK

typed, in-process function calls.

await sdk.deploy
  .prod({ target })

deploy

Ship services to an environment.
acme deploy prod approval cli mcp sdk

Deploy a service to production. Gated on a human approval.

Parameter Type Description
target string required Service name to deploy.
--wait boolean optional Block until rollout is healthy. default: true

secrets DEPLOY_API_KEY — required for the /deploy endpoint 

$ acme deploy prod api --no-wait
acme deploy preview cli sdk

Spin up an ephemeral preview environment for a branch.

Parameter Type Description
branch string required Git branch to preview.
--ttl number optional Hours before teardown. default: 24 
$ acme deploy preview feature/login --ttl 48

issues

Read and triage the issue tracker.
acme issues list cli mcp sdk

List open issues, newest first.

Parameter Type Description
--limit number optional Maximum issues to return. default: 20
--label string optional Filter by label. 
$ acme issues list --label bug --limit 5
acme issues create cli mcp sdk

Open a new issue.

Parameter Type Description
title string required Issue title.
--body string optional Markdown body.

secrets ACME_TOKEN — API token with write scope 

$ acme issues create "Login is broken" --body "Steps to repro..."

Get started

Quickstart

Install the binary, then call it from your terminal, wire it into an MCP client, or import the SDK. 

# install
npm install -g acme

# run a command
acme issues list --limit 5

# expose every mcp-scoped command to an agent
acme mcp

# call it from code
import { createSDK } from "acme/sdk";
const sdk = createSDK(root);
await sdk.deploy.preview({ branch: "main" });
