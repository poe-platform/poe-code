Read the full frozen `../remaining-harness-v4/CALLGRAPH.md`; its bytes are bound.
Its supervisor, controller, admin materialize/seal-runtime, guard, static TS
launcher, bootstrap/loaders, archive/finalization and Git-platform/helper routes

| Route | Ownership and limits |
| --- | --- |
| Authoring | author.mjs -> builtin fs/path/crypto/assert/zlib; prints apply_patch input. No spawn/import of product/compiler/frozen helpers. Runs before epoch. |
| Outer bootstrap | exec replaces shell with absolute authenticated Node -> owner.mjs -> builtin modules only until capture registration and seal authentication. |
| Administration | owner.mjs -> local primitives.mjs in process, hash/read/JSON/zlib/write/fsync/inventory; no administrative Node or archive utility. |

| Positive startup/DATA | owner -> child.mjs -> exact env assertion -> dynamic ./data-controls.mjs -> ./primitives.mjs and ./fixture-data.mjs; only inert data/fake provider. Child cannot spawn. |
| Refusal startup | owner -> child.mjs -> exact actual env record -> intentionally unequal expected env assertion; fails before dynamic control import; outer already owns raw pipes/cleanup. |
| G01 | owner directly -> /Library/Developer/CommandLineTools/usr/bin/git built-in ls-tree -rz; no intermediate Node/platform shim. Tiny isolated config/objects created in process. |
| P01 | owner -> child.mjs nested -> spawnSync attempt denied by Node ChildProcess permission; no actual grandchild. Parent's occupied lease refusal happens during handshake, before spawn. |
| Finalization | same owner, after known exact child retirement, inventories/removes only identity-checked owned scratch; postguards/raw memberships and outcome written in process. |
| Evidence commit | only after owner tool confirms terminal exit; explicit-owned-path Git, no overlapping epoch. Not qualified by isolated G01. |

All five child starts use one lease and all closes precede the next start. Peak2
is supported by direct handles, PID/PPID handshakes, exact denial and the finite
inspected graph, not an unrestricted OS census. No ps helper, native oracle,
compiler, candidate, network, private runtime, worker, watcher, shell callback,
Git wrapper or general-purpose subprocess callback is reachable in this graph.

Git is bound to real executable bytes/mode, not /usr/bin/git's platform selection.
Tiny metadata Git uses finite env and explicit hooks/fsmonitor/maintenance/GC/
signing/credentials/protocol/attributes settings. No aliases, filters, remotes,
promisor objects or configured helper paths exist in that created repository.
Real-repository commits are NOT qualified. The old waiting controller + admin
Node + Git topology is forbidden and the committed runtime barrier remains.

The outer launch read permissions name this exclusive subtree, the finite bound
historical DATA files and two tool files, not the repository/home/root. Write
permission names attempt-01 only. Child read/write permissions narrow further.
All Node subprocess envs equal the observed finite Darwin map exactly. Git adds
only its explicitly listed finite settings. No ambient env allowlist wildcard.
