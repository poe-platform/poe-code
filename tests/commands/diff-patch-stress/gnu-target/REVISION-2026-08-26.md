## Executable proof and API routing

`oracle.ts` exports `oraclePath(tool, profile?)`, `oracleIdentity(tool, profile?)`,
`pins`, `OracleTool`, and `OracleProfile`. The default profile is `gnu`.
`DIFF_PATCH_NATIVE_DIFF` / `DIFF_PATCH_NATIVE_PATCH` may relocate the exact pinned
executables; relative, empty, absent, non-executable, hash-mismatched or
version-mismatched paths fail closed. There is no `/usr/bin` GNU fallback.
The only alternate is the explicitly named `apple-calibration` profile, with
its own version/hash proof and `DIFF_PATCH_APPLE_DIFF/PATCH` override names.
Stat identity is rechecked at each lookup; unchanged proof is cached. This
is executable identification, not a defense against hostile host races.

GNU binary hashes and build provenance remain recorded in the untouched
`../oracle/provenance.json`. Calibration evidence is an independently captured
native-only projection of the classifier's evidence, whose original hash is
recorded in `calibration-2026-08-26.json`. Its own SHA-256 is
`f10b84f6000f7c68eaae12fc726c828b913c97cc5c0e49d5108bee1a49774c28`,
asserted by `calibration.ts`. Product outputs were not copied into expectations.
All native launches use literal argv, isolated target files, and time/output caps.

Outside ownership, route author `diff-formats.test.ts` (its separate
`DIFF_WHITESPACE_ORACLE` launcher) and `hunk-regressions.test.ts` (direct
