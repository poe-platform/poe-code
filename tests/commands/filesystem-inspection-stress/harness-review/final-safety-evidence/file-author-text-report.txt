fields, but no unrestricted backend string is scanned/expanded before admission.

maxSteps, permits reporting an exhausted work quota. It is not a normal-work
reset or unlimited error allowance. Command execution uses it only for terminal
known short limit messages. The helper bounds/slices text BEFORE encoding, takes
whole codepoints, admits UTF-8 bytes before encoding, and obeys the shared output

reserve. Scratch encoding is at most192 UTF-8 bytes and no more than remaining
output. Direct tests cover reserve exhaustion and valid whole-codepoint output
under a17-byte quota. No ordinary metadata/output scan is exempt from admission.
