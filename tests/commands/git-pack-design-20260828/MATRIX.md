## Actual implementation proof still required after module GO

- Source, compiled, installed and moved public leaf against an authenticated full
  package; no source fallback or changed aggregate count. M1A regressions unchanged.
- Direct/tree/commit/tag reconstruction; idx hash/OID/CRC/offset mutant kills;
  checksum-correct bad payloads cannot succeed through an unselected/loose path.
- Node22 actual stream member consumption, appended member, bounded decompression,
  abort/backpressure and awaited engine close. The DATA checker is synchronous
  and cannot certify any of these production lifecycle properties.
- Pack read chunk ownership and source-read counters; resident owner and view
  lifetimes, duplicate coexistence, release before allocation and cumulative caps.
- Admission/metadata-only queries and all six unchanged useful workflows. No
  successful `--version` stub or host repository inspection counts as evidence.
- Different verifier holds out malformed and ownership cases; native recipes
  require fresh execution authorization and authenticated executable/tool closure.

One status row per family must distinguish DATA, author product, independent
product and native qualification. Unsupported/out-of-profile entries remain in
