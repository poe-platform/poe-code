# Observed-host environment guard controls

One source/data controller, no children,30seconds/64KiB capture/1MiB scratch.
No second platform probe and no compiler/product load. The exact new guard
span is executed against twelve finite synthetic process records only.
Qualified Darwin UID501 plus the seven existing fields and exact observed
UID text encoding is accepted. Missing/wrong metadata, unknown keys,
wrong declared values, NODE_OPTIONS/NODE_PATH and unqualified hosts refuse.

The previous predicate remains strict; only the independently observed
intrinsic-startup metadata key/value is added for this exact pinned host.
The probe proves appearance with an explicit seven-field spawn environment
and harmless program. It does not identify the precise OS/libc initializer
or retroactively capture the original failed child's environment. Other
platforms/UIDs remain unqualified, not silently accepted.
