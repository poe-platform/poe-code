## Exact observations by role

Raw provider tests preserve values in a parent-held identity table, with a
separate presence bit, phase and origin. JSON cannot encode undefined or certify
object identity. Compare finite own-data keys, primitive values and sequence;
reject accessors/holes/extras without coercion, not by prototype equality. A
cross-realm success claim requires an actual cross-realm input later, not JSON
parsing during preparation. Trusted host callbacks are not a malicious-host
JavaScript containment promise.

Actual-engine cases require fixed public source/emission/entry hashes and real
loaded-code witnesses before guest entry. Worker exit, termination request,
terminal message, ACK, postcopy marker and parent cleanup are distinct facts.
P mock/instrumented assertions never stand in for E engine effects. Parent
publisher faults are separate from guest diagnostic text and stderr sink faults.
No absence of a diagnostic is evidence of an absent raw failure.

Public-Shell cases use the accepted invocation cleanup barrier and Budget, not a
new Shell, Promise.race timeout substitute or reset private/global counter.
Caller > actual escaping execution rejection > cleanup > numeric is the existing
selection rule. Existing errors already mapped into status/diagnostics are not
retroactively upgraded to escaping rejections. Module-private source/operation
limits are not fictional CommandContext debit methods. Caller reasons remain
live during cooperative drain; no child/consumer abort may poison a sibling.
