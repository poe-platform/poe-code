# Attempt02 source/data-only review

Root authority: current narrow review, 12 minutes including publication,
24 all-owned processes, peak2, 64 MiB capture, 128 MiB work. No real owner,
launcher, workers, engines, native probe, compiler, staging or control replay.

The self-contained `review-data.mjs` imports only Node data/metadata facilities.
Before its three serialized Git inventories it opens exclusive owned capture
files. Git commands are `ls-tree -r -z --full-tree` against exactly the repair
preseal, evidence and publication-tail commits supplied by root, restricted to
the attempt02 preparation directory. Each has a 10-second watchdog and 1 MiB
combined output ceiling. No candidate module is evaluated. Source selections,
byte/mode/blob identities and close/exit observations are written to DATA.json.
No retries. A source/helper error with known retirement remains a literal HOLD;
safety/capture/integrity/unknown retirement stops dependent work.

Inspected source before the helper: wrapper, owner01/02, inactive interfaces,
host-environment guard, private capture preparer and descriptor guard. Bindings
must prove the sole owner literal and unchanged three other executable bodies.
This does not replay 416 inputs or convert retained author results into new passes.
One exec-replaced Node helper plus one serialized Git child has peak2; metadata
inspection/editing/publication tool processes also count toward the total24.
