## What is implemented

- `observer.mjs`: forwards the original URL and options objects to the real
  constructor, retains the returned actual Worker before fallible identity/event
  observation, records identity/exit/stream events, and refuses another admission.
  It never replaces methods, rewrites options/limits/messages, changes entrypoints,
  invokes terminate, restores the constructor, or performs recovery. Independent
  stdout/stderr enrollment is attempted even if another enrollment fails.
- `cell.mjs`: future-only public consumer. Installs the constructor observer
  before importing **public `virtual-bash`**, verifies public resolution against
  the selected package root, makes one public Shell.exec call, and checks the
  unchanged oracle. Its constructor interception is explicitly **instrumented,
  not stock**. No private product module is imported or protocol message inspected.
- `process-owner.mjs`: retains actual native child references before fallible
  enrollment; requires exit, close and both pipe EOFs, not close alone. Separate
  prewrite-bounded pipes and a raw-presence failure ledger cover partial capture
  acquisition. A 10-second case / 60-second installer timeout uses explicitly
  proposed outer-process SIGTERM, then SIGKILL after 2 seconds, then UNKNOWN at
  3 seconds. These are native process signals, never Worker.terminate calls.
- `core.mjs`: exact 24-cell selector checks, grant admission, monotonic 1200-second
  clock with 180-second publication reservation, finite outcome validation,
  capture prewrite accounting and no next case after non-PASS/UNKNOWN. Falsy
  primary/cleanup reasons retain explicit presence. Secondary records are bounded
  to 32 with an explicit omitted count; this is not an unlimited raw-error log.
- `data.mjs`: regular-file/size/mode/hash admission, same-buffer compressed
  archive admission without inflation, exact package-file census, and quiescent
  working-tree sampling. ENOENT or a changing census is an error, not a missing
  row silently forgiven.
- `coordinator.mjs`: a small new fixed-pilot dispatcher, not the old 210-cell
  dispatcher. It prepares source-built data, two offline ignore-scripts installs,
  an actual moved installation, sealed per-cell public consumer configurations,
  native ownership, bounded journal and final publication. UNKNOWN native handles
  remain in `retainedInvocations`; process close does not prove Worker retirement.
