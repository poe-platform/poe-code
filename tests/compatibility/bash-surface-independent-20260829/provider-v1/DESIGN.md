## Narrow implementation

A generated default-deny Seatbelt profile is passed to the pinned /usr/bin/sandbox-exec, which launches only pinned Node for current harmless fixtures. Literal case source/config is copied to a new owned staging directory; no child repository/instruction/private reads. Child writable paths are one fresh case namespace; canaries and raw capture are siblings outside it. Only exact Node executable/stage files, enumerated system dyld cache files and listed system image paths are readable. No inherited environment, network rule, generic executable or provider-supplied shell string. All executable strings are absolute. Process-fork is denied except the3 presealed spawn-attempt/descendant cases. Same-Node executable access is not a promise against arbitrary re-exec; fixed hashed fixture code is part of authority.

The host enrolls capture and cleanup before spawn; spawn uses detached:true, no shell, no unref. It observes direct root spawn/exit/close and stdout/stderr/event EOF, owns TERM then KILL at5s+2s+1s maximum, checks owned group presence and stops on unknown retirement. Two cooperative descendant fixtures send enrolled PID/start/exit/close evidence through an inherited event pipe; these are source-trusted fixture notifications, not kernel-wide fork monitoring. Group absence is separately observed, NOT proof of each unobserved native fork/exit.

## Interface gap, not silent waiver

The original harness demands losslessDescendants and a complete regular-file dependency closure. Inspected historical native-bridge-v4 explicitly remained unqualified; JS/stream observers are not kernel fork observers. This provider must never assert those stronger facts. Native begin/run remains fail-closed until a different review and ROOT approve a versioned finite-source observation contract; old harness files are untouched. Future virtual adapter repo imports also need staged read-only harness binding, not a repository read exception. A process-group fence cannot supply universal descendant census or hard post-KILL settlement.

System image paths/shared-cache metadata are allowed-path bindings, not authenticated loaded-image identities. Full old dependency closure therefore remains unqualified. The author test may qualify this exact current-platform profile operationally only; no broader OS portability. Network denial is SOURCE-only: no listener or connection attempt.
