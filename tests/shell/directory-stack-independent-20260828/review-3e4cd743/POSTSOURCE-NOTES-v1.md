# Versioned post-source review notes

No product body or original49 files are edited. The following limitations were
identified during harness/source audit, before completing first case execution:

- L13 v1 constructs a public oversized cwd but its Memory-backed host does not
  truthfully represent that existing directory. Even if byte/status assertions
  pass, this is NOT the frozen scripted-existing-provider qualification. A later
  separately sealed scripted-host adapter must retain the v1 result and prove it.
- C06 v1 dynamically checks local falsy-reason identity and parent/sibling state.
  Its source-proof annotation is not execution of the separate equal-valued root/
  escaping/local precedence schedules; exact existing regressions remain required.
- U01/U02 v1 replacements may assign undefined to an exact-optional State field;
  U03 restoration has the same potential. A later presealed variant version uses
  an explicit empty fallback/deletion. Invalid builds are never mutant kills.
- The standalone types-review-v1 route targets source declarations and the moved
  actual package. Its installed label is explicitly post-move, not a genuine
  pre-move installed type compilation; a distinct installed-stage route is needed
  for full three-layout type acceptance. No compile has been run by this note.

These are harness qualifications, not discovered product bugs or changed frozen
expected values. Corrections must remain versioned and sealed before execution.
