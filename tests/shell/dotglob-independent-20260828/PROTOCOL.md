No product or native execution occurs in this phase. Root's latest message is
the ratification authority, overriding the author's stale awaiting-ratification
heading and resolving its off-state dot-entry blocker. Actual accepted STACK
source/package/tool binding and runtime GO are still held. Do not import a

## Cases and exact observations

`command-cases.json` is a literal tuple set, independently authored from the
ratified restricted profile, not generated by a candidate shopt implementation.
Each row runs in a fresh Shell/VFS. Setup on-state uses a successful silent
`shopt -s dotglob`; command execution and poststate query stay in the same exec.
Build a script from the frozen strings using literal single-quote escaping,
never native shell interpolation. A registered bounded receipt command may
record the immediately saved command status and subsequent `shopt -q dotglob`
status. Assert one receipt and wrapper0 separately from the command's recorded
status: wrapper printf/receipt success must not be counted as command success.
All setup/query/receipt calls count against real shared budgets. Dedicated
boundary tests omit that wrapper or use delegating state observations where
its extra commands would confound an exact limit.

Initial state has no ambient variable coupling. Rows use virtual LC_ALL=C/TZ=UTC;
no actual host environment is implicitly copied. Default diagnostics in tuples
are exactly `shell: line 1: ...\n`; any setup stays on the same source line.
Source-file/function/eval diagnostic provenance is tested separately against
the accepted base's existing Runtime.diagnostic behavior. Never substitute
native `dotglob-reference` prefixes. Capture stdout/stderr bytes, saved status,
poststate, VFS before/after, and ordered sink/provider events, including errors.

`unsupported-names.json` is a compact parameter matrix over58 captured native
option names other than dotglob, six modes and two initial states. All696 rows
must fail1 with exact diagnostics and unchanged flag. These names are negative
operands, not the project's supported inventory. `expand_aliases` is mandatory
in all modes; no supported-no-op unset/query shortcut. No-name stdout contains

`glob-cases.json` compares exact argv arrays from an actual registered recorder
after Shell pathname expansion, not a helper-only matcher. Preserve actual
quote syntax in `word`. Compare bytes as well as strings; no Unicode ordering
claim beyond the existing comparator. Every non-mutating fixture retains all

Do not invent a hostile-JavaScript sandbox or allow mismatched namespace claims.
Exclude names exactly `.`/`..` at every wildcard segment ON and OFF; `..keep`
must survive. Literal components and unmatched retention remain unchanged.

`state-cases.json` and `procedures.json` pin public lifecycle, effects, resources,

## Mutation, settlement and boundedness

Preseal concrete mutation hunks after candidate source is known. Build and load
each real mutated module in a fresh child; record activation at the changed
mechanism and failure of its designated unchanged predicate. Required controls:

- M0 remove shopt dispatch/discovery: actual command127/not-builtin vs positives.
- M1 ignore on-state during globbing: leading-dot positive/nested cases fail.
- M2 discard all leading-dot names or `..` prefixes: explicit-dot off/..keep fail.
- M3 skip `.`/`..` only when on: approved custom-provider OFF cases fail.
- M4 retain flag globally/reset clones: shared/fresh/cloned lifecycle controls fail.
- M5 mutate while scanning flags or last-s/u-wins: invalid/conflict no-effects fail.
- M6 rollback/prevalidate unknown names: partial mutation/order controls fail.
- M7 suppress errors under q or deduplicate listings: exact diagnostics/events fail.
- M8 bypass shared field/byte/output caps: exact resource controls fail.

Restore and rebuild candidate; require identical emitted/package bytes and
positive countercontrols. No helper/fixture JSON mutation earns code-mutant
credit. Ordinary assertion failures must aggregate through all scheduled cases
after dispose/reap. Reject missing/duplicate receipts, timeout/loader failure,
wrong module hash, missing activation, and all-PASS then nonzero child exit.
Use an actual-package late-exit control, not only synthetic receipt models.

Bound children to30s/256KiB receipts (build/types60s with explicit larger log
ceiling); split matrix batches rather than raising deadlines or truncating
results. Keep fixtures<=128 entries, individual names<=64 codepoints, scripts
<=16KiB and pattern-control work deliberately small. Await cooperative registered
cleanup; observe abandoned rejections without requiring opaque promises to
settle. Release all gates in finally, restore observers, dispose every Shell,
reap exact owned children, remove only owned temp data. No native execution,
oversized/pathological probes, CPU/RSS/preemption claim, or whole-product gate.
