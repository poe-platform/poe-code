Lifecycle proposal: a lazy executor closure per configured command factory,
at most two workers total including terminating workers. Request-only FIFO
leases across dispatch, validation and awaited failure cleanup; release before
source/sink/VFS awaits. Worker caches are bounded (one descriptor per worker),
descriptor plus byte rows travel as data, all dynamic RegExp construction and
matching (including invalid-UTF8 fragment variants) occurs in static workers.
Compile validation is an empty-row worker request before source consumption.
One invocation-scoped handle closes in finally; last invocation awaits idle
worker retirement. Cached idle workers and idle timers are unref'd, with bounded
idle retirement even while an invocation awaits uncooperative source/sink.
Abort applies only to the caller's queued/request work, never another shell.
No plugin dispose hook or new lifecycle contract appears necessary with this
self-retiring pool; will stop if inspection falsifies this.
